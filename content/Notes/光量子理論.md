# 1. 導論 (Introduction & Background)

**光量子理論 (Quantum Theory of Light)**是阿爾伯特·愛因斯坦 (Albert Einstein) 於 1905 年提出的物理理論。該理論指出，光在發射、傳播與吸收時非連續波動，而是由局域化的能量粒子——**[[光子|光子 (Photon)]]**所組成。

### 近代物理的雙柱
在近代物理中，[[特殊相對論|相對論]]與[[波粒二象性|波粒二象性 (Wave-Particle Duality)]]是核心思想。光量子理論的提出確立了波粒二象性。

### 歷史背景與物理學矛盾
19 世紀末，電磁學將光視為連續電磁波。然而，古典波動理論在微觀領域遭遇瓶頸：
1.  **[[普朗克量子理論|黑體輻射]]**：古典理論預言短波能量趨於無窮（即紫外災變），促使普朗克提出能量量子化。
2.  **[[光電效應]]**：古典理論無法解釋閾頻率與激發無時間延遲的現象。
3.  **康卜吞散射**：古典湯姆森散射預言波長不變，但實驗觀測到散射光波長變長。

### 思考模型：第一性原理思考 (First-Principles Thinking)
愛因斯坦採用**第一性原理思考 (First-Principles Thinking)**挑戰了光是連續波的假設。他將光的能量分佈去構建為離散的光量子。這一重建成功解釋了古典波動說無法說明的微觀現象。

# 2. 核心 (Core Framework)

### 光子的物理特徵量 (Physical Properties of Photons)
*   **光子能量 (Photon Energy, $E$)**：
    單個光子的能量與其頻率 $\nu$ 成正比，與波長 $\lambda$ 成反比：
    $$E = h\nu = \frac{hc}{\lambda}$$
    *   $h$ 為**普朗克常數 (Planck's Constant)**（$h \approx 6.626 \times 10^{-34} \text{ J} \cdot \text{s}$）。
*   **電子伏特 (Electron-volt, $\text{eV}$)**：
    微觀物理的能量單位。$1 \text{ eV}$ 為單一電子經過 $1 \text{ V}$ 電位差加速後所獲得的[[kinetic energy|動能]]：
    $$1 \text{ eV} \approx 1.602 \times 10^{-19} \text{ J}$$
    在實務計算中，光子能量 $E$ 可簡化估算為：
    $$E \text{ (eV)} \approx \frac{1240}{\lambda \text{ (nm)}}$$
*   **光子動量 (Photon Momentum, $p$)**：
    雖然光子的靜止質量為零（$m=0$），但它依然攜帶動量：
    $$p = \frac{E}{c} = \frac{h}{\lambda}$$
    該公式將光的粒子屬性與其波動屬性直接聯繫。

### 光電效應實驗 (Photoelectric Effect)
*   示意圖：![[光電效應示意圖.png]]
*   **光電子的最大動能 (Maximum Kinetic Energy, $K_{max}$)**：
    光電子逸出時的最大動能，可藉由截止電壓 $V_s$ 量測：
    $$K_{max} = e V_s$$
*   **古典波動理論的失敗之處**：
    *   **閾頻率 (Threshold Frequency, $\nu_0$)** 的存在：古典理論預言只要光強度夠大，任何頻率的光皆可激發電子。但實驗表明，若頻率 $\nu < \nu_0$，則無論光多強都無電子逸出。
    *   **瞬時發射**：古典理論預言弱光下電子需累積能量；實驗顯示若頻率大於 $\nu_0$ 則是瞬時的。
    *   **動能決定因素**：古典理論預言光強大則動能大；實驗顯示動能僅與頻率 $\nu$ 相關。
*   **光子理論的解釋**：
    愛因斯坦提出，入射光子與電子發生一對一碰撞，電子瞬時吸收其能量。根據能量守恆：
    $$h\nu = K_{max} + \Phi$$
    *   $\Phi$ 為金屬的**功函數 (Work Function)**（即將電子拉出金屬表面的最小能量門檻，$\Phi = h\nu_0$）。
    *   當 $h\nu > \Phi$ 時才會產生光電效應，剩餘能量轉化為光電子最大動能。

### 康卜吞散射實驗 (Compton Scattering)
*   示意圖：![[康卜吞散射示意圖.png]]
*   **古典波動理論的失敗之處**：
    古典理論預言電子受迫振動後輻射的電磁波，其波長應與入射光波長一致。但實驗中，散射光中出現了波長變長的成分。
*   **光子理論的解釋**：
    康卜吞將其視為高能光子與靶中靜止電子的二維彈性碰撞。光子失去部分能量與動量傳遞給電子，導致散射光子波長變長：
    $$\lambda' - \lambda = \lambda_C (1 - \cos\theta)$$
    *   $\theta$ 為光子的散射角。
    *   **康卜吞波長 (Compton Wavelength, $\lambda_C$)** 定義為：
        $$\lambda_C = \frac{h}{m_e c} \approx 2.43 \times 10^{-12} \text{ m}$$

# 3. 邏輯 (Operational Logic)

### 思考模型：思想實驗 (Thought Experiment)
在建立光量子物理模型時，科學家廣泛使用了**思想實驗 (Thought Experiment)**。他們在腦海中將微觀粒子作用類比為碰撞事件。這使繁複的電磁交互作用簡化為能量守恆與動量守恆推導。

### 愛因斯坦光電方程式的線性邏輯
愛因斯坦方程式 $K_{max} = h\nu - \Phi$ 呈線性關係：
1.  **斜率與截距**：以 $K_{max}$ 對頻率 $\nu$ 作圖，其斜率為普朗克常數 $h$，縱軸截距為 $-\Phi$，橫軸截距即為閾頻率 $\nu_0$。這說明普朗克常數 $h$ 確實是聯繫光的波動性與粒子性的普適常數。
2.  **光強的物理意義**：光的強度代表單位時間內通過單位面積的**光子數**。因此，光強增加只會等比例增加被激發的光電子數，而不會改變單個光電子的最大動能，這在微觀的一對一交互作用模型下是邏輯自洽的。

### 康卜吞散射公式的相對論推導
將碰撞視為二維彈性碰撞。入射光子動量為 $\mathbf{p}$（能量 $E = pc$），靜止電子能量 $E_e = m_e c^2$（動量 $\mathbf{p}_e = 0$）。碰撞後散射光子動量為 $\mathbf{p}'$（能量 $E' = p'c$），電子動量為 $\mathbf{p}_e'$（總能量 $E_e' = \sqrt{(m_e c^2)^2 + (p'_e c)^2}$）。

1.  **能量守恆**（各項同除 $c$）：
    $$p + m_e c = p' + \sqrt{m_e^2 c^2 + p_e'^2}$$
    $$(p - p' + m_e c)^2 = m_e^2 c^2 + p_e'^2$$
    $$p^2 + p'^2 + m_e^2 c^2 - 2pp' + 2m_e c(p - p') = m_e^2 c^2 + p_e'^2$$
    $$p^2 + p'^2 - 2pp' + 2m_e c(p - p') = p_e'^2 \quad \text{--- (式一)}$$
2.  **動量守恆**：
    $$\mathbf{p} = \mathbf{p}' + \mathbf{p}_e' \implies \mathbf{p}_e' = \mathbf{p} - \mathbf{p}'$$
    求其向量內積的平方：
    $$p_e'^2 = p^2 + p'^2 - 2\mathbf{p} \cdot \mathbf{p}' = p^2 + p'^2 - 2pp'\cos\theta \quad \text{--- (式二)}$$
3.  **聯立消去電子的末動量**（將式二代入式一）：
    $$p^2 + p'^2 - 2pp' + 2m_e c(p - p') = p^2 + p'^2 - 2pp'\cos\theta$$
    $$2m_e c(p - p') = 2pp'(1 - \cos\theta)$$
    $$m_e c(p - p') = pp'(1 - \cos\theta)$$
    兩邊同除以 $p p' m_e c$：
    $$\frac{1}{p'} - \frac{1}{p} = \frac{1}{m_e c}(1 - \cos\theta)$$
    代入德布羅意關係式 $p = h/\lambda$ 及 $p' = h/\lambda'$：
    $$\frac{\lambda'}{h} - \frac{\lambda}{h} = \frac{1}{m_e c}(1 - \cos\theta)$$
    $$\lambda' - \lambda = \frac{h}{m_e c}(1 - \cos\theta)$$
    推導完成。

# 4. 應用與脈絡 (Application & Context)

### 實際應用場景
*   **光電探測器與影像感測器 (CCD/CMOS)**：數位相機感光元件利用光電效應。入射光子激發半導體產生電氣訊號，進而重建影像。
*   **太陽能光伏產業 (Solar Photovoltaics)**：基於光電效應的延伸，將太陽光子能量直接轉換為直流電能。
*   **醫學影像與放射防護**：康卜吞散射是高能射線在軟組織中最主要的交互作用。精確計算散射機率是保護正常組織與提升造影品質的關鍵。
*   **光電倍增管 (PMT)**：利用光電效應釋放初始電子，並透過級聯放大以檢測微弱的單光子信號。

### 理論邊界與限制
1.  **能量閾值限制**：光電效應僅在入射光子能量大於功函數時發生。若光子頻率低於臨界值，則無論光照強度多大皆無效。
2.  **康卜吞散射觀測條件**：康卜吞波長變化量極小。對於長波長的可見光，此變化量難以察覺，古典湯姆森散射仍是極佳近似。只有當入射波長與康卜吞波長相當（如高能 X 射線）時，散射效應才顯著。
