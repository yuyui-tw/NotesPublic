# 資料探勘
> 從資料中找出有用的資訊

# 方法
- 分群
將相似屬性的資料分為同一組
- 購物籃分析
	- 分析某人購買商品時，會一併購買何物
- 連結分析
	- 定義兩項目的關係並收集資料(e.g. FB上某人跟某人是朋友)
	- **圖論**理論
- 文字探勘
	- 從大量文字資料(text)中找出有用的資料
	- 自然語言處理

# 機器學習與資料探勘的差別

|      | 機器學習       | 資料探勘        |
| ---- | ---------- | ----------- |
| 用途   | 預測數值走向或屬性  | 調查資料或屬性間的關聯 |
| 人類介入 | 自動選擇資料提取模式 | 人類選擇資料提取方法  |
| 應用例  | 圖像辨識       | 分析顧客行為模式    |
