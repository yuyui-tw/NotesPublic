## 試題解析與步驟拆解

### 1. 極限求值（Taylor 展開式與 L'Hôpital 應用）
**題目**：
For what values of $a$ and $b$, $a, b \neq 0$, is the following equation true?
$$\lim_{x\to 0} \left( \frac{e^{ax} - 1}{x^2} - ax + \frac{b}{x} \right) = \frac{1}{2}$$

#### 相關核心概念筆記
* [[Limit of a function and Limit laws]]
* [[泰勒級數]] 或 [[常見函數的泰勒級數]]
* [[羅必達法則]]

#### 步步拆解與分析
* **策略分析**：
  原極限式包含分式與整式項。為分析極限，我們可先將括號內的各項通分，結合成單一分式，再利用泰勒級數或羅必達法則分析在 $x \to 0$ 時的行為。

* **詳細解題步驟**：
  1. **通分整理**：
     將括號內的式子通分，以 $x^2$ 作為共同分母：
     $$\frac{e^{ax} - 1 - ax^3 + bx}{x^2}$$
     我們要探討此分式在 $x \to 0$ 時的極限：
     $$\lim_{x\to 0} \frac{e^{ax} - 1 - ax^3 + bx}{x^2} = \frac{1}{2}$$
     
  2. **泰勒級數展開 (推薦方法)**：
     為了將分子化簡，我們將指數函數 $e^{ax}$ 在 $x=0$ 處做泰勒展開：
     $$e^{ax} = 1 + ax + \frac{a^2}{2}x^2 + \frac{a^3}{6}x^3 + \mathcal{O}(x^4)$$
     將其代回分子的表達式中：
     $$\text{分子} = \left(1 + ax + \frac{a^2}{2}x^2 + \frac{a^3}{6}x^3 + \mathcal{O}(x^4)\right) - 1 - ax^3 + bx$$
     $$= (a + b)x + \frac{a^2}{2}x^2 + \left(\frac{a^3}{6} - a\right)x^3 + \mathcal{O}(x^4)$$
     
  3. **極限分析**：
     將分子代入極限式：
     $$\lim_{x\to 0} \frac{(a+b)x + \frac{a^2}{2}x^2 + \left(\frac{a^3}{6}-a\right)x^3 + \mathcal{O}(x^4)}{x^2}$$
     $$= \lim_{x\to 0} \left[ \frac{a+b}{x} + \frac{a^2}{2} + \left(\frac{a^3}{6}-a\right)x + \mathcal{O}(x^2) \right]$$
     由於分母為 $x^2$，當 $x \to 0$ 時，若要使極限值收斂為有限實數（即 $\frac{1}{2}$），則分式中 $1/x$ 項的係數必須為零（否則該項會發散）。因此：
     $$a + b = 0 \implies b = -a$$
     
  4. **求解 $a$ 與 $b$**：
     當 $b = -a$ 時，前述極限簡化為：
     $$\lim_{x\to 0} \left[ \frac{a^2}{2} + \left(\frac{a^3}{6}-a\right)x + \mathcal{O}(x^2) \right] = \frac{a^2}{2}$$
     題目給定此極限值為 $\frac{1}{2}$：
     $$\frac{a^2}{2} = \frac{1}{2} \implies a^2 = 1 \implies a = 1 \text{ or } a = -1$$
     已知 $b = -a$，且限制條件為 $a, b \neq 0$：
     * 若 $a = 1$，則 $b = -1$。
     * 若 $a = -1$，則 $b = 1$。

* **第二種解法（羅必達法則）**：
  若使用羅必達法則，對於 $\lim_{x\to0} \frac{e^{ax} - 1 - ax^3 + bx}{x^2}$：
  因為分母 $x^2 \to 0$，若要極限存在，分子也必須趨近於 0（此條件為 $e^0 - 1 - 0 + 0 = 0$，恆成立）。
  應用第一次羅必達：
  $$\lim_{x\to0} \frac{a e^{ax} - 3ax^2 + b}{2x}$$
  此時分母仍趨於 0，因此分子極限亦須為 0：
  $$\lim_{x\to0} (a e^{ax} - 3ax^2 + b) = a + b = 0 \implies b = -a$$
  此條件滿足後，極限式為 $\frac{0}{0}$ 不定型。應用第二次羅必達：
  $$\lim_{x\to0} \frac{a^2 e^{ax} - 6ax}{2} = \frac{a^2}{2}$$
  令 $\frac{a^2}{2} = \frac{1}{2}$，得 $a = \pm 1$，對應 $b = \mp 1$。兩方法結果完全一致。

* **答案**：$(a, b) = (1, -1)$ 或 $(-1, 1)$。

### 2. 反函數微分與多元連鎖律
**題目**：
(a) Let $f(x) = \sec^2 x$ on $(0, \frac{\pi}{2})$ and $f^{-1}$ be the inverse function of $f$. Find $(f^{-1})'(4) =$ \_\_\_\_\_\_\_.
(b) Let $f = f(x, y)$ be a differentiable function of $x$ and $y$, and let $x = rs, y = r + s$ and $h(r, s) = f(x, y) = f(rs, r + s)$. Assume $\frac{\partial f}{\partial x}(1, 2) = 2$, $\frac{\partial f}{\partial y}(1, 2) = 1$. Find $\frac{\partial h}{\partial s}(1, 1) =$ \_\_\_\_\_\_\_.

#### 相關核心概念筆記
* [[Derivative of inverse function & Logarithms]] 與 [[反函數]]
* [[Chain Rule]] 與 [[偏微分]]

#### 步步拆解與分析
* **(a) 小題拆解**：
  1. **反函數微分公式**：
     $$(f^{-1})'(y_0) = \frac{1}{f'(x_0)} \quad \text{其中 } y_0 = f(x_0)$$
  2. **尋找對應的自變數 $x_0$**：
     已知目標值 $y_0 = 4$，我們需要在定義域 $(0, \frac{\pi}{2})$ 內求解：
     $$\sec^2 x_0 = 4 \implies \sec x_0 = 2 \quad (\because x \in (0, \pi/2) \implies \sec x > 0)$$
     $$\cos x_0 = \frac{1}{2} \implies x_0 = \frac{\pi}{3}$$
  3. **求導 $f'(x)$**：
     $$f'(x) = \frac{d}{dx} (\sec^2 x) = 2\sec x \cdot (\sec x \tan x) = 2\sec^2 x \tan x$$
  4. **計算 $f'(x_0)$ 並帶入公式**：
     $$f'\left(\frac{\pi}{3}\right) = 2 \sec^2\left(\frac{\pi}{3}\right) \tan\left(\frac{\pi}{3}\right) = 2 \cdot (2)^2 \cdot \sqrt{3} = 8\sqrt{3}$$
     $$(f^{-1})'(4) = \frac{1}{f'(\frac{\pi}{3})} = \frac{1}{8\sqrt{3}} = \frac{\sqrt{3}}{24}$$
     
* **(b) 小題拆解**：
  1. **寫出多元偏微分連鎖律**：
     $$h(r, s) = f(x(r, s), y(r, s))$$
     $$\frac{\partial h}{\partial s} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial s} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial s}$$
  2. **計算中間變數的偏導**：
     已知 $x = rs$ 且 $y = r + s$，對自變數 $s$ 求偏導得：
     $$\frac{\partial x}{\partial s} = r, \quad \frac{\partial y}{\partial s} = 1$$
     因此：
     $$\frac{\partial h}{\partial s} = \frac{\partial f}{\partial x}(x, y) \cdot r + \frac{\partial f}{\partial y}(x, y) \cdot 1$$
  3. **找出 $(r, s) = (1, 1)$ 對應的 $(x, y)$**：
     $$x = 1 \cdot 1 = 1, \quad y = 1 + 1 = 2$$
     故對應點為 $(x, y) = (1, 2)$。
  4. **代入已知偏微分值**：
     $$\frac{\partial h}{\partial s}(1, 1) = \frac{\partial f}{\partial x}(1, 2) \cdot r\Big|_{r=1} + \frac{\partial f}{\partial y}(1, 2) \cdot 1$$
     $$= 2 \cdot 1 + 1 \cdot 1 = 3$$

* **答案**：(a) $\frac{\sqrt{3}}{24}$ (或 $\frac{1}{8\sqrt{3}}$) ； (b) $3$。

### 3. 微積分基本定理與單調性
**題目**：
If $f(x) = \int_0^{x^2} (1 - t^2) e^{t^2} dt$, on what interval(s) is $f$ increasing?

#### 相關核心概念筆記
* [[Fundamental Theorem of Calculus]]
* [[萊不尼茲微分法則]]
* [[Monotonic functions & the first derivative test]]

#### 步步拆解與分析
* **策略分析**：
  一個函數在某區間內「遞增」，代表其導函數在此區間內滿足 $f'(x) \ge 0$。我們需要利用微積分基本定理與連鎖律（即萊布尼茲法則）求出 $f'(x)$，再求解相應的不等式。

* **詳細解題步驟**：
  1. **求導 $f'(x)$**：
     根據萊布尼茲積分微分法則：
     $$\frac{d}{dx} \left[ \int_0^{g(x)} H(t) dt \right] = H(g(x)) \cdot g'(x)$$
     在此 $g(x) = x^2$，$H(t) = (1-t^2)e^{t^2}$。代入得：
     $$f'(x) = \left( 1 - (x^2)^2 \right) e^{(x^2)^2} \cdot \frac{d}{dx}(x^2) = (1 - x^4) e^{x^4} \cdot 2x = 2x (1 - x^4) e^{x^4}$$
     
  2. **求解不等式 $f'(x) \ge 0$**：
     $$2x (1 - x^4) e^{x^4} \ge 0$$
     由於指數項 $e^{x^4} > 0$ 對於所有實數 $x$ 恆為正，因此不等式的正負號完全由 $2x(1-x^4)$ 決定：
     $$2x(1 - x^2)(1 + x^2) \ge 0$$
     再者，項 $1 + x^2 > 0$ 亦恆為正，因此不等式可進一步簡化為：
     $$x(1 - x^2) \ge 0 \implies x(1 - x)(1 + x) \ge 0$$
     我們將不等式同乘 $-1$ 轉換成標準型以利分析：
     $$x(x - 1)(x + 1) \le 0$$
     
  3. **區間號誌分析（根為 $-1, 0, 1$）**：
     * 當 $x \le -1$ 時：三個因子皆非正值，乘積為負數或零（滿足 $\le 0$）。
     * 當 $-1 < x < 0$ 時：兩負一正，乘積為正數（不滿足 $\le 0$）。
     * 當 $0 \le x \le 1$ 時：一負二正，乘積為負數或零（滿足 $\le 0$）。
     * 當 $x > 1$ 時：三個因子皆為正，乘積為正數（不滿足 $\le 0$）。
     
     因此，滿足 $f'(x) \ge 0$ 的區間為：
     $$x \in (-\infty, -1] \cup [0, 1]$$

* **答案**：$(-\infty, -1]$ 與 $[0, 1]$。

### 4. 三角代換法
**題目**：
Let $a > 0$ be a constant. Evaluate
$$ \int_0^a \frac{x^2}{(x^2 + a^2)^{3/2}} dx $$

#### 相關核心概念筆記
* [[Trigonometric Substitution]]
* [[Trigonometric Integral]]
* [[Antiderivative]]

#### 步步拆解與分析
* **策略分析**：
  當被積函數中出現 $\sqrt{x^2 + a^2}$ 或其奇數次冪時，標準的做法是使用正切三角代換 $x = a \tan\theta$。這能利用恆等式 $1 + \tan^2\theta = \sec^2\theta$ 來消去根號。

* **詳細解題步驟**：
  1. **設定變數代換**：
     令 $x = a \tan\theta$，則其微分元素為 $dx = a \sec^2\theta d\theta$。
  2. **變換積分上下限**：
     * 當 $x = 0$ 時，$a\tan\theta = 0 \implies \theta = 0$。
     * 當 $x = a$ 時，$a\tan\theta = a \implies \tan\theta = 1 \implies \theta = \frac{\pi}{4}$。
  3. **代入化簡分母**：
     $$(x^2 + a^2)^{3/2} = (a^2\tan^2\theta + a^2)^{3/2} = (a^2(1+\tan^2\theta))^{3/2} = (a^2\sec^2\theta)^{3/2} = a^3\sec^3\theta$$
     （因為在 $\theta \in [0, \pi/4]$ 區間內，$\sec\theta > 0$，所以不需要加絕對值）。
  4. **重寫積分式**：
     $$\int_0^a \frac{x^2}{(x^2 + a^2)^{3/2}} dx = \int_0^{\frac{\pi}{4}} \frac{a^2\tan^2\theta}{a^3\sec^3\theta} \cdot a\sec^2\theta d\theta = \int_0^{\frac{\pi}{4}} \frac{\tan^2\theta}{\sec\theta} d\theta$$
  5. **化簡被積三角函數**：
     將其轉換為正弦與餘弦：
     $$\frac{\tan^2\theta}{\sec\theta} = \frac{\sin^2\theta}{\cos^2\theta} \cdot \cos\theta = \frac{\sin^2\theta}{\cos\theta} = \frac{1 - \cos^2\theta}{\cos\theta} = \sec\theta - \cos\theta$$
  6. **執行積分**：
     $$\int_0^{\frac{\pi}{4}} (\sec\theta - \cos\theta) d\theta = \left[ \ln|\sec\theta + \tan\theta| - \sin\theta \right]_0^{\frac{\pi}{4}}$$
     $$= \left( \ln\left|\sec\frac{\pi}{4} + \tan\frac{\pi}{4}\right| - \sin\frac{\pi}{4} \right) - \left( \ln\left|\sec 0 + \tan 0\right| - \sin 0 \right)$$
     $$= \left( \ln(\sqrt{2} + 1) - \frac{\sqrt{2}}{2} \right) - (\ln(1 + 0) - 0) = \ln(\sqrt{2} + 1) - \frac{\sqrt{2}}{2}$$

* **答案**：$\ln(\sqrt{2} + 1) - \frac{\sqrt{2}}{2}$。

### 5. 極座標區域面積
**題目**：
Find the area of the region that lies inside the curve $r = 4 \sin\theta$ and outside the curve $r = 2$.

#### 相關核心概念筆記
* [[極座標]]
* [[Integral]]

#### 步步拆解與分析
* **策略分析**：
  這題要求解兩條極座標曲線圍成的區域面積。我們需要先繪製或想像圖形以確定邊界，接著求解她們的交點，最後應用極座標面積公式計算。

* **詳細解題步驟**：
  1. **圖形理解與交點求解**：
     * $r = 4\sin\theta$ 是一個直徑為 4、圓心位於直角座標 $(0, 2)$ 的圓。
     * $r = 2$ 是一個半徑為 2、圓心位於原點的圓。
     聯立方程式求交點：
     $$4\sin\theta = 2 \implies \sin\theta = \frac{1}{2} \implies \theta = \frac{\pi}{6}, \frac{5\pi}{6}$$
     在區間 $[\frac{\pi}{6}, \frac{5\pi}{6}]$ 內，曲線 $r = 4\sin\theta$ 的半徑大於 $r = 2$。
     
  2. **套用極座標面積公式**：
     $$A = \frac{1}{2} \int_{\alpha}^{\beta} \left( r_{\text{outer}}^2 - r_{\text{inner}}^2 \right) d\theta$$
     $$A = \frac{1}{2} \int_{\frac{\pi}{6}}^{\frac{5\pi}{6}} \left( (4\sin\theta)^2 - 2^2 \right) d\theta = \frac{1}{2} \int_{\frac{\pi}{6}}^{\frac{5\pi}{6}} (16\sin^2\theta - 4) d\theta = \int_{\frac{\pi}{6}}^{\frac{5\pi}{6}} (8\sin^2\theta - 2) d\theta$$
     
  3. **使用倍角公式降次**：
     利用 $\sin^2\theta = \frac{1-\cos(2\theta)}{2}$：
     $$8\sin^2\theta - 2 = 8\left(\frac{1-\cos(2\theta)}{2}\right) - 2 = 4(1-\cos(2\theta)) - 2 = 2 - 4\cos(2\theta)$$
     
  4. **計算定積分**：
     $$A = \int_{\frac{\pi}{6}}^{\frac{5\pi}{6}} (2 - 4\cos(2\theta)) d\theta = \left[ 2\theta - 2\sin(2\theta) \right]_{\frac{\pi}{6}}^{\frac{5\pi}{6}}$$
     $$= \left( 2\left(\frac{5\pi}{6}\right) - 2\sin\left(\frac{5\pi}{3}\right) \right) - \left( 2\left(\frac{\pi}{6}\right) - 2\sin\left(\frac{\pi}{3}\right) \right)$$
     $$= \left( \frac{5\pi}{3} - 2\left(-\frac{\sqrt{3}}{2}\right) \right) - \left( \frac{\pi}{3} - 2\left(\frac{\sqrt{3}}{2}\right) \right)$$
     $$= \left( \frac{5\pi}{3} + \sqrt{3} \right) - \left( \frac{\pi}{3} - \sqrt{3} \right) = \frac{4\pi}{3} + 2\sqrt{3}$$

* **極具價值的幾何直觀驗證 (轉學考高分關鍵！)**：
  * 這兩個圓的半徑皆為 $R = 2$，圓心分別在 $(0, 0)$ 和 $(0, 2)$。
  * 由於兩圓心距離為 2，恰好等於半徑，這代表兩圓的交集區域是一個標準的「對稱葉狀透鏡（Lens）」。
  * 此透鏡區域的面積可以用兩個圓弧扇形面積扣除重疊的幾何圖形求得：
    對於半徑為 2、圓心角為 $120^\circ$ ($\frac{2\pi}{3}$) 的圓弓形（Segment），其面積為：
    $$A_{\text{segment}} = \frac{1}{2} R^2 (\theta - \sin\theta) = \frac{1}{2}(4)\left(\frac{2\pi}{3} - \sin\frac{2\pi}{3}\right) = \frac{4\pi}{3} - \sqrt{3}$$
    因此，兩圓重疊的透鏡面積為：
    $$A_{\text{lens}} = 2 A_{\text{segment}} = \frac{8\pi}{3} - 2\sqrt{3}$$
  * 我們所求的面積是「圓 $r = 4\sin\theta$（面積為 $4\pi$）內部，且在圓 $r = 2$ 外部」的區域。由對稱性可知，這正是上方圓扣除透鏡面積：
    $$A = A_{\text{circle}} - A_{\text{lens}} = 4\pi - \left( \frac{8\pi}{3} - 2\sqrt{3} \right) = \frac{4\pi}{3} + 2\sqrt{3}$$
    幾何直觀與微積分積分結果完全一致！

* **答案**：$\frac{4\pi}{3} + 2\sqrt{3}$。

### 6. 無限級數之收斂判定
**題目**：
For what real values of $p$ does the series $\sum_{n=2}^{\infty} \frac{1}{n^p \ln n}$ converges?

#### 相關核心概念筆記
* [[Improper Integrals]] (積分審斂法)
* [[正項級數]] (比較/極限比較審斂法)
* [[數列與級數]]

#### 步步拆解與分析
* **策略分析**：
  這是結合了冪函數與對數函數的正項級數。我們應該根據 $p$ 的不同區間（$p > 1$、$p < 1$、以及 $p = 1$ 的臨界點）進行討論，分別使用合適的審斂法。
分母中除了 $n^{p}$ 外只多了一個增長極慢的 $\ln n$，我們預測原級數的收斂行為依然會被主力項 $n^{p}$ 支配，因此臨界點必然圍繞在p = 1 附近。這指引了我們分成 p > 1、p < 1 與 p = 1 三個區間去論證。
* **詳細解題步驟**：
  1. **情況 1：$p > 1$**：
     因為對數函數 $\ln n$ 當 $n \ge 3$ 時滿足 $\ln n > 1$。因此我們可以得到以下不等式關係：
     $$0 < \frac{1}{n^p \ln n} < \frac{1}{n^p} \quad (\forall n \ge 3)$$
     我們知道 $\sum_{n=2}^{\infty} \frac{1}{n^p}$ 在 $p > 1$ 時是一個**收斂的 $p$-級數**。根據比較審斂法（Comparison Test），原級數在此範圍內必然**收斂**。
     
  2. **情況 2：$p < 1$**：
     當 $p < 1$ 時，函數的衰減速度太慢。我們可以將其與發散的**調和級數** $\sum_{n=2}^{\infty} \frac{1}{n}$ 進行極限比較審斂法（Limit Comparison Test）：
     $$\lim_{n\to\infty} \frac{\frac{1}{n^p \ln n}}{\frac{1}{n}} = \lim_{n\to\infty} \frac{n^{1-p}}{\ln n}$$
     由於 $1-p > 0$，分子為正實數次冪，其增長速度在 $n \to \infty$ 時遠快於分母的對數函數 $\ln n$。由羅必達法則可得此極限為：
     $$\lim_{x\to\infty} \frac{x^{1-p}}{\ln x} \overset{\text{L'H}}{=} \lim_{x\to\infty} \frac{(1-p)x^{-p}}{\frac{1}{x}} = \lim_{x\to\infty} (1-p)x^{1-p} = \infty$$
     根據極限比較審斂法，因為極限值為 $\infty$ 且比較級數發散，原級數在此範圍內必然**發散**。
     
  3. **情況 3：$p = 1$（臨界點）**：
     級數變為 $\sum_{n=2}^{\infty} \frac{1}{n \ln n}$。此時適合使用積分審斂法（Integral Test）。
     考慮函數 $f(x) = \frac{1}{x \ln x}$，當 $x \ge 2$ 時 $f(x)$ 為正值、連續且單調遞減。
     計算相應的瑕積分：
     $$\int_2^{\infty} \frac{1}{x \ln x} dx$$
     令 $u = \ln x$，則 $du = \frac{1}{x} dx$。積分範圍變更為 $[\ln 2, \infty)$：
     $$\int_2^{\infty} \frac{1}{x \ln x} dx = \int_{\ln 2}^{\infty} \frac{1}{u} du = \left[ \ln u \right]_{\ln 2}^{\infty} = \lim_{M\to\infty} \ln(\ln M) - \ln(\ln 2) = \infty$$
     由於瑕積分發散，依據積分審斂法，級數在 $p=1$ 時亦**發散**。

* **答案**：$p > 1$。

### 7. 冪級數求和（還原初等函數）
**題目**：
Let $f(x)$ be the function defined by the power series
$$ \sum_{n=0}^{\infty} \frac{(x + 2)^{2n}}{(n + 3)!} $$
Try to express $f(x)$ as an elementary function.

#### 相關核心概念筆記
* [[泰勒級數]] 與 [[常見函數的泰勒級數]]
* [[冪級數]] 及其應用

#### 步步拆解與分析
* **策略分析**：
  題目給出一個冪級數，要求寫出其閉合形式（即用初等函數表達）。分母的 $(n+3)!$ 強烈暗示了這與指數函數 $e^u = \sum \frac{u^k}{k!}$ 的泰勒級數展開密切相關。我們可以透過平移與代數變換來將其還原。

* **詳細解題步驟**：
  1. **引入輔助變數**：
     令 $u = x + 2$，則原級數可表示為：
     $$S(u) = \sum_{n=0}^{\infty} \frac{u^{2n}}{(n + 3)!}$$
     
  2. **尋找與麥克勞林級數的關聯**：
     回顧指數函數的麥克勞林級數展開：
     $$e^y = \sum_{k=0}^{\infty} \frac{y^k}{k!} = 1 + y + \frac{y^2}{2!} + \sum_{n=0}^{\infty} \frac{y^{n+3}}{(n+3)!}$$
     將前三項移至等號左邊：
     $$e^y - 1 - y - \frac{y^2}{2} = \sum_{n=0}^{\infty} \frac{y^{n+3}}{(n+3)!}$$
     
  3. **提取公因式以符合目標形式**：
     將右側的 $y^{n+3}$ 拆解成 $y^3 \cdot y^n$：
     $$e^y - 1 - y - \frac{y^2}{2} = y^3 \sum_{n=0}^{\infty} \frac{y^n}{(n+3)!}$$
     在 $y \neq 0$ 的情況下，兩邊同除以 $y^3$：
     $$\sum_{n=0}^{\infty} \frac{y^n}{(n+3)!} = \frac{e^y - 1 - y - \frac{y^2}{2}}{y^3}$$
     
  4. **代回原變數**：
     對照我們的目標級數 $S(u) = \sum_{n=0}^{\infty} \frac{(u^2)^n}{(n+3)!}$。我們只需令 $y = u^2$：
     $$S(u) = \frac{e^{u^2} - 1 - u^2 - \frac{1}{2}u^4}{u^6} \quad (u \neq 0)$$
     將 $u = x + 2$ 代回：
     $$f(x) = \frac{e^{(x+2)^2} - 1 - (x+2)^2 - \frac{1}{2}(x+2)^4}{(x+2)^6} \quad (x \neq -2)$$
     
  5. **探討 $x = -2$ 處的定義**：
     當 $x = -2$ 時，原級數中除了 $n=0$ 項之外，其餘各項均為 0：
     $$f(-2) = \frac{(0)^0}{3!} = \frac{1}{6}$$
     （這與公式在 $x \to -2$ 時的極限值完全吻合，可透過對分子進行泰勒展開至 $y^3$ 項來驗證）。

* **答案**：$f(x) = \frac{e^{(x+2)^2} - 1 - (x+2)^2 - \frac{1}{2}(x+2)^4}{(x+2)^6}$（當 $x \neq -2$ 時，且 $f(-2) = \frac{1}{6}$）。

### 8. 拉格朗日乘子法求極值
**題目**：
Find the global maximum and global minimum of $f(x, y, z) = x^2 + y^2 + z^2$ on the surface $x^2 + 2y^2 + 3z^2 = 1$ by ==using the method of Lagrange multipliers==.

#### 相關核心概念筆記
* [[Lagrange Multipliers]]（或 [[拉格朗日乘子法]]）
* [[多變數函數極值]]

#### 步步拆解與分析
* **策略分析**：
  這是一個典型的條件極值問題。限制面 $g(x, y, z) = x^2 + 2y^2 + 3z^2 - 1 = 0$ 是個封閉的橢球面，目標函數 $f(x, y, z) = x^2 + y^2 + z^2$ 是點到原點距離的平方。利用拉格朗日乘子法 $\nabla f = \lambda \nabla g$ 可找出候選點。

* **詳細解題步驟**：
  1. **建立梯度方程系統**：
     令 $g(x, y, z) = x^2 + 2y^2 + 3z^2 - 1 = 0$。
     $$\nabla f = \langle 2x, 2y, 2z \rangle$$
     $$\nabla g = \langle 2x, 4y, 6z \rangle$$
     建立方程組 $\nabla f = \lambda \nabla g$ 加上限制條件：
     - (1) $2x = 2\lambda x \implies x(1 - \lambda) = 0$
     - (2) $2y = 4\lambda y \implies y(1 - 2\lambda) = 0$
     - (3) $2z = 6\lambda z \implies z(1 - 3\lambda) = 0$
     - (4) $x^2 + 2y^2 + 3z^2 = 1$
     
  2. **分類討論候選點**：
     * **情況 1：若 $\lambda = 1$**：
       由方程 (2) 和 (3) 可知，由於 $1-2(1) \neq 0$ 且 $1-3(1) \neq 0$，必須有 $y = 0$ 且 $z = 0$。
       將其代入限制面方程 (4)：
       $$x^2 = 1 \implies x = \pm 1$$
       得到候選點為 $(\pm 1, 0, 0)$，對應目標函數值 $f(\pm 1, 0, 0) = 1$。
       
     * **情況 2：若 $\lambda = \frac{1}{2}$**：
       由方程 (1) 和 (3) 可知，必須有 $x = 0$ 且 $z = 0$。
       代入限制面方程 (4)：
       $$2y^2 = 1 \implies y = \pm \frac{1}{\sqrt{2}}$$
       得到候選點為 $(0, \pm \frac{1}{\sqrt{2}}, 0)$，對應目標函數值 $f(0, \pm \frac{1}{\sqrt{2}}, 0) = \frac{1}{2}$。
       
     * **情況 3：若 $\lambda = \frac{1}{3}$**：
       由方程 (1) 和 (2) 可知，必須有 $x = 0$ 且 $y = 0$。
       代入限制面方程 (4)：
       $$3z^2 = 1 \implies z = \pm \frac{1}{\sqrt{3}}$$
       得到候選點為 $(0, 0, \pm \frac{1}{\sqrt{3}})$，對應目標函數值 $f(0, 0, \pm \frac{1}{\sqrt{3}}) = \frac{1}{3}$。
       
  3. **比較極值大小**：
     因為橢球面是緊緻集合（Compact Set），根據極值定理（Extreme Value Theorem），絕對最大值與絕對最小值必定存在於這些拉格朗日候選點中。
     比較三組函數值：$1 > \frac{1}{2} > \frac{1}{3}$。
     * 絕對最大值為 $1$。
     * 絕對最小值為 $\frac{1}{3}$。

* **第二種解法（代數變換與線性規劃）**：
  令 $u = x^2 \ge 0$, $v = y^2 \ge 0$, $w = z^2 \ge 0$。
  * 限制條件為：$u + 2v + 3w = 1 \implies u = 1 - 2v - 3w \ge 0$。
  * 目標函數為：$f = u + v + w = (1 - 2v - 3w) + v + w = 1 - v - 2w$。
  * 由於 $v, w \ge 0$，顯然當 $v = 0$ 且 $w = 0$ 時，目標函數有最大值 $f_{\max} = 1$（此時 $u = 1 \ge 0$ 成立）。
  * 若要最小化 $f = 1 - (v + 2w)$，即要求在 $2v + 3w \le 1$ ($v, w \ge 0$) 的三角形可行域內最大化 $v + 2w$。
    這是一個簡單的二維線性規劃問題，可行域頂點為 $(0,0)$、$(1/2, 0)$ 和 $(0, 1/3)$：
    * 於 $(1/2, 0)$ 處：$v + 2w = \frac{1}{2}$。
    * 於 $(0, 1/3)$ 處：$v + 2w = \frac{2}{3}$。
    因此，$v + 2w$ 的最大值為 $\frac{2}{3}$，此時目標函數最小值為 $f_{\min} = 1 - \frac{2}{3} = \frac{1}{3}$。

* **答案**：絕對最大值為 $1$；絕對最小值為 $\frac{1}{3}$。

### 9. 二重積分之座標變換 (Jacobian)
**題目**：
Evaluate $\iint_R \frac{y}{x} e^{xy} dA$, where $R$ is the region in the first quadrant bounded by lines $y = x$, $y = 3x$, and the hyperbolas $xy = 1$, $xy = 3$.

#### 相關核心概念筆記
* [[二重積分]]
* [[座標變換]] (重積分的變數變換)
* [[傅比尼定理]]

#### 步步拆解與分析
* **策略分析**：
  邊界條件包含 $y/x = 1, y/x = 3$ 以及 $xy = 1, xy = 3$。這極力暗示了我們應該使用變數代換將斜交的區域轉換為 $uv$-平面上的矩形，從而簡化積分邊界。

* **詳細解題步驟**：
  1. **定義新變數與確定邊界**：
     令：
     $$u = xy$$
     $$v = \frac{y}{x}$$
     在此代換下，第一象限的積分區域 $R$ 對應到 $uv$-平面上的矩形區域 $S$：
     $$S = \{ (u, v) \mid 1 \le u \le 3, \ 1 \le v \le 3 \}$$
     
  2. **計算雅可比行列式 (Jacobian)**：
     我們首先求反向的偏導數矩陣行列式，這通常更容易計算(避免要用複雜的根號或分式求導)：
     $$J^{-1} = \frac{\partial(u, v)}{\partial(x, y)} = \begin{vmatrix} \frac{\partial u}{\partial x} & \frac{\partial u}{\partial y} \\ \frac{\partial v}{\partial x} & \frac{\partial v}{\partial y} \end{vmatrix} = \begin{vmatrix} y & x \\ -\frac{y}{x^2} & \frac{1}{x} \end{vmatrix}$$
     $$J^{-1} = y \left( \frac{1}{x} \right) - x \left( -\frac{y}{x^2} \right) = \frac{y}{x} + \frac{y}{x} = \frac{2y}{x} = 2v$$
     因此，座標轉換的雅可比行列式為：
     $$\left| \frac{\partial(x, y)}{\partial(u, v)} \right| = \frac{1}{|J^{-1}|} = \frac{1}{2v}$$
     
  3. **重寫積分表達式**：
     被積函數為 $\frac{y}{x} e^{xy} = v e^u$。
     $$\iint_R \frac{y}{x} e^{xy} dA = \iint_S \left( v e^u \right) \cdot \left| \frac{\partial(x, y)}{\partial(u, v)} \right| du dv$$
     $$= \int_1^3 \int_1^3 \left( v e^u \right) \cdot \frac{1}{2v} du dv = \int_1^3 \int_1^3 \frac{1}{2} e^u du dv$$
     
  4. **利用傅比尼定理計算**：
     由於被積函數與 $v$ 無關，可以直接拆解成兩個單變數積分的乘積：
     $$\left( \int_1^3 \frac{1}{2} dv \right) \cdot \left( \int_1^3 e^u du \right) = \left[ \frac{v}{2} \right]_1^3 \cdot \left[ e^u \right]_1^3 = 1 \cdot (e^3 - e^1) = e^3 - e$$

* **答案**：$e^3 - e$。

### 10. 格林定理與線積分
**題目**：
Evaluate the line integral $\int_C (1 - y^3) dx + (x^3 + e^{-y^2}) dy$, where $C$ is the arc of the circle $x^2 + y^2 = 4$ traversed counter-clockwise from $(2, 0)$ to $(-2, 0)$.

#### 相關核心概念筆記
* [[格林定理]]
* [[線積分]]（或 [[Line and Surface Integrals]]）

#### 步步拆解與分析
* **策略分析**：
  被積函數中的 $e^{-y^2} dy$ 項極難直接進行不定積分，這暗示了直接參數化路徑計算會非常痛苦。我們應該考慮使用格林定理。然而，路徑 $C$ 僅是上半圓弧而非封閉曲線，我們需要藉由添加一條邊界段來使其「閉合」，再扣除該輔助路徑的線積分。

* **詳細解題步驟**：
  1. **路徑閉合化設計**：
     * $C$ 是從 $(2, 0)$ 到 $(-2, 0)$ 沿著上半圓的逆時針圓弧。
     * 我們添加一條輔助線段 $C_1$，從 $(-2, 0)$ 沿著 x 軸直接走到 $(2, 0)$。
     * 此時，封閉路徑 $C_{\text{closed}} = C \cup C_1$ 剛好以逆時針方向圍住了上半圓盤區域 $D$：
       $$D = \{ (x, y) \mid x^2 + y^2 \le 4, \ y \ge 0 \}$$
       
  2. **套用格林定理**：
     令 $P = 1 - y^3$，$Q = x^3 + e^{-y^2}$。
     $$\oint_{C \cup C_1} P dx + Q dy = \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dA$$
     計算偏導數：
     $$\frac{\partial Q}{\partial x} = 3x^2, \quad \frac{\partial P}{\partial y} = -3y^2 \implies \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 3x^2 + 3y^2 = 3(x^2 + y^2)$$
     
  3. **計算二重積分（轉換為極座標）**：
     在上半圓盤 $D$ 上，$r \in [0, 2]$ 且 $\theta \in [0, \pi]$：
     $$\iint_D 3(x^2 + y^2) dA = \int_0^{\pi} \int_0^2 (3r^2) \cdot r dr d\theta = \int_0^{\pi} d\theta \cdot \int_0^2 3r^3 dr$$
     $$= \pi \cdot \left[ \frac{3}{4}r^4 \right]_0^2 = \pi \cdot \frac{3}{4}(16) = 12\pi$$
     
  4. **計算沿輔助線段 $C_1$ 的線積分**：
     在 x 軸路徑 $C_1$ 上，$y = 0 \implies dy = 0$，且 $x$ 從 $-2$ 變動到 $2$。
     將其代回線積分：
     $$\int_{C_1} (1 - y^3) dx + (x^3 + e^{-y^2}) dy = \int_{-2}^2 (1 - 0) dx + (x^3 + e^0) \cdot 0 = \int_{-2}^2 1 dx = 2 - (-2) = 4$$
     
  5. **求得原線積分值**：
     $$\int_C P dx + Q dy = \oint_{C \cup C_1} P dx + Q dy - \int_{C_1} P dx + Q dy = 12\pi - 4$$

* **答案**：$12\pi - 4$。
