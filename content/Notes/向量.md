## 定義與意義

### 數學上的向量
在數學中，向量是具有大小（長度）和方向的量。它可以用一個有向線段來表示，箭頭指示方向，長度表示大小。在坐標系中，向量通常表示為一個有序數組，例如二維空間中的 $\vec{v} = (x, y)$ 或三維空間中的 $\vec{v} = (x, y, z)$。

### 物理學上的向量
在物理學中，許多物理量都是向量，例如：
- **位移 (Displacement)**：物體從起點到終點的有向距離。
- **速度 (Velocity)**：物體運動的快慢和方向。
- **加速度 (Acceleration)**：物體速度變化率和方向。
- **力 (Force)**：作用於物體上，使其改變運動狀態的推力或拉力，具有大小和方向。

向量在物理學中對於描述物體的運動、受力情況以及場（如電場、磁場）的性質至關重要。

## 向量運算

### 內積 (Dot Product 或 Scalar Product)
內積是兩個向量相乘得到一個純量（只有大小沒有方向的量）。
對於兩個向量 $\vec{a}$ 和 $\vec{b}$，其內積定義為：
$$\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos \theta$$ 
其中 $|\vec{a}|$ 和 $|\vec{b}|$ 分別是向量 $\vec{a}$ 和 $\vec{b}$ 的大小，$\theta$ 是它們之間的夾角。

在坐標系中，若 $\vec{a} = (a_1, a_2, ..., a_n)$ 和 $\vec{b} = (b_1, b_2, ..., b_n)$，則：
$$\vec{a} \cdot \vec{b} = \sum_{i=1}^{n} a_i b_i = a_1 b_1 + a_2 b_2 + ... + a_n b_n$$ 

應用：
- 計算兩個向量之間的夾角。
- 計算一個向量在另一個向量上的投影。
- 物理學中用於計算功：$W = \vec{F} \cdot \vec{d}$（力與位移的內積）。

### 外積 (Cross Product 或 Vector Product)
外積是兩個**三維**向量相乘得到一個新的向量，這個新向量垂直於原始的兩個向量所在的平面。
對於兩個向量 $\vec{a} = (a_x, a_y, a_z)$ 和 $\vec{b} = (b_x, b_y, b_z)$，其外積定義為：
$$\vec{a} \times \vec{b} = (a_y b_z - a_z b_y, a_z b_x - a_x b_z, a_x b_y - a_y b_x)$$ 

幾何意義：
- 外積向量的大小 $|\vec{a} \times \vec{b}| = |\vec{a}| |\vec{b}| \sin \theta$，其值等於以 $\vec{a}$ 和 $\vec{b}$ 為鄰邊的平行四邊形的面積。
- 外積向量的方向遵循右手定則。

應用：
- 找到垂直於兩個給定向量的向量（法向量）。
- 計算平行四邊形或三角形的面積。
- 物理學中用於計算力矩：$\vec{\tau} = \vec{r} \times \vec{F}$（位置向量與力的外積）。
- 計算角動量：$\vec{L} = \vec{r} \times \vec{p}$（位置向量與動量的外積）。

## 重要定理與不等式

### 基本公式
- **向量的大小（模長）**：
  對於 $\vec{v} = (v_1, v_2, ..., v_n)$，其大小為 $|\vec{v}| = \sqrt{v_1^2 + v_2^2 + ... + v_n^2}$。
- **單位向量**：
  與原向量方向相同，大小為1的向量。$\hat{v} = \frac{\vec{v}}{|\vec{v}|}$。
- **向量加法與減法**：
  分量各自相加或相減，遵循平行四邊形法則或三角形法則。
- **純量乘法**：
  純量 $k$ 乘以向量 $\vec{v}$ 會改變向量的大小，方向不變或反向（如果 $k < 0$）。$k\vec{v} = (kv_1, kv_2, ..., kv_n)$。
- 以向量計算平行六面體
$$
V=|a\cdot (b\times c)|
$$
也可表示成三向量之行列式絕對值

### 柯西-施瓦茨不等式 (Cauchy-Schwarz Inequality)
對於任意兩個向量 $\vec{a}$ 和 $\vec{b}$，此不等式說明了它們內積的絕對值與它們模長乘積之間的關係：
$$|\vec{a} \cdot \vec{b}| \leq |\vec{a}| |\vec{b}|$$ 

用分量表示則為：
$$(\sum_{i=1}^{n} a_i b_i)^2 
\leq (\sum_{i=1}^{n} a_i^2)(\sum_{i=1}^{n} b_i^2)$$ 

等號成立的充要條件是，向量 $\vec{a}$ 和 $\vec{b}$ 共線（線性相關），即其中一個向量是另一個向量的純量倍。這個不等式是從內積的幾何定義 $\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos \theta$ 和 $|\cos 	\theta| \leq 1$ 直接得出的。

### 三角不等式 (Triangle Inequality)
對於任意兩個向量 $\vec{a}$ 和 $\vec{b}$，它們和的模長不大於它們各自模長的和：
$$|\vec{a} + \vec{b}| 
\leq |
\vec{a}| + |\vec{b}|$$ 

幾何意義上，這代表在一個三角形中，任意兩邊之和必大於第三邊。等號成立的充要條件是，向量 $\vec{a}$ 和 $\vec{b}$ 方向相同。
