# 概要
泊肅葉方程式（Poiseuille's Equation）是一個定量描述在特定條件下，黏性流體在細長圓管中進行層流時，其體積流量與壓力差、管道尺寸之間關係的流體動力學定律。

# 核心概念
- **黏性流 (Viscous Flow)**: 流體因具有黏性（內部摩擦力），在流動時會產生阻力。為了克服這種阻力並維持流動，必須在管道兩端施加一個壓力差。
- **壓力梯度 ($\Delta P$)**: 驅動流體流動的壓力差。它是克服黏性力的動力來源。在理想流體（無黏性）中，維持等速流動不需要壓力差。
- **體積流量 ($Q$)**: 單位時間內流過管道某一橫截面的流體體積。

# 結構/要素
泊肅葉方程式的完整形式為：
$$Q = \frac{\pi R^4 \Delta P}{8 \eta L}$$
其中：
- $Q$：體積流量 (m³/s)
- $\Delta P$：管道兩端的壓力差 (Pa)
- $R$：管道的內部半徑 (m)
- $\eta$：流體的動力黏度 (Pa·s)
- $L$：管道的長度 (m)

從公式可見，維持固定流量所需的壓力差 $\Delta P$ 與管道半徑 $R$ 的**四次方**成反比。
$$\Delta P \propto \frac{1}{R^4}$$
這意味著管道半徑的微小變化會對壓力差或流量產生巨大影響。

# 原理/推導
泊肅葉方程式的推導基於穩定層流中的一個核心假設：**力平衡**。對於一個在管道中穩定流動（無加速度）的流體元素，驅動它前進的壓力，必須與來自管壁和相鄰流體的黏性拖曳力完全抵消。

### 1. 速度剖面 (Velocity Profile)
- **為何速度分佈不均?**
  - **無滑動條件 (No-Slip Condition)**: 任何黏性流體在與固體表面接觸時，其最外層流體會「黏附」在表面上，因此在管壁處($r=R$)的流體速度為零。
  - **黏性力**: 流體可以被想像成無數個同心圓柱層。中心層流動最快，它會拖動相鄰的外層一起流動，但同時也受到外層的拖曳力。這種層與層之間的內部摩擦力（黏性力）導致速度從中心向管壁逐漸遞減。
- **速度剖面的形狀: 拋物線**
  - 綜合上述效應，流體速度在管道中心軸($r=0$)達到最大值，並向管壁($r=R$)平滑地減至零，形成一個**拋物線**形狀的速度剖面。
- **徑向速度 (Radial Velocity)**
  - 在此模型中，我們假設流動是完全沿著管道長度方向（軸向）的**層流**，因此不存在徑向速度（即流體不會從中心向外或從外向中心流動）。

### 2. 力平衡與推導
- **設定**: 考慮管道中一個半徑為 `r`、長度為 `L` 的圓柱形流體元素。此處的 `r` 是變數，代表從中心到任意位置的徑向距離。
- **壓力 (Pressure Force, $F_P$)**:
  - `ΔP` 是指管道兩端 ($L$ 的距離) 的**壓力差** ($P_1 - P_2$)，它是驅動流動的動力源。
  - 作用在此流體元素兩端的壓力所產生的淨力為：$F_P = P_1(\pi r^2) - P_2(\pi r^2) = \Delta P (\pi r^2)$。
- **黏性力 (Viscous Force, $F_\eta$)**:
  - 根據牛頓黏性定律，流體層之間的剪應力 $\tau = -\eta \frac{dv}{dr}$ (負號表示速度梯度與半徑方向相反)。
  - 黏性力是作用在圓柱體**側面**的總拖曳力，其側面面積為 $A = 2\pi r L$。
  - 因此，黏性力為 $F_\eta = \tau \cdot A = -\eta (2\pi r L) \frac{dv}{dr}$。
- **力平衡 ($F_P + F_\eta = 0$)**:
  - 在穩定流動中，淨力為零，因此壓力驅動力必須與黏性拖曳力大小相等、方向相反：$F_P = -F_\eta$。
    $$\Delta P (\pi r^2) = \eta (2\pi r L) \frac{dv}{dr}$$
- **求解速度 $v(r)$**:
  - 分離變數並對 `r` 積分，即可得到速度剖面的方程式。
  - $\frac{dv}{dr} = \frac{\Delta P}{2\eta L}r$
  - 對上式積分：$\int dv = \int \frac{\Delta P}{2\eta L}r \,dr$，得到 $v(r) = \frac{\Delta P}{4\eta L}r^2 + C$。
  - 使用邊界條件「在管壁處速度為零」 ($v=0$ when $r=R$) 來解出積分常數 $C$：
    $0 = \frac{\Delta P}{4\eta L}R^2 + C \implies C = -\frac{\Delta P}{4\eta L}R^2$
  - 將 $C$ 代回，得到最終的速度剖面公式，此處的速度 $v$ 是半徑 $r$ 的函數：
    $$v(r) = \frac{\Delta P}{4\eta L}(R^2 - r^2)$$

### 3. 積分計算總流量 (Volume Flow Rate, Q)
- **從積分角度理解**: 總流量 $Q$ 是流經整個管道橫截面的所有微小流量元 $dQ$ 的總和。
- 在半徑 $r$ 處，一個寬度為 $dr$ 的微小環狀區域的面積為 $dA = 2\pi r dr$。
- 流經這個環狀區域的微小流量為 $dQ = v(r) \cdot dA = v(r) \cdot (2\pi r dr)$。
- **詳細積分步驟**: 將 $v(r)$ 代入並從中心($r=0$)積分到管壁($r=R$)：
  $$Q = \int dQ = \int_0^R v(r) (2\pi r dr)$$
  $$Q = \int_0^R \frac{\Delta P}{4\eta L}(R^2 - r^2) (2\pi r) dr$$
  $$Q = \frac{2\pi \Delta P}{4\eta L} \int_0^R (R^2r - r^3) dr$$
  $$Q = \frac{\pi \Delta P}{2\eta L} \left[ \frac{R^2r^2}{2} - \frac{r^4}{4} \right]_0^R$$
  $$Q = \frac{\pi \Delta P}{2\eta L} \left( \left(\frac{R^4}{2} - \frac{R^4}{4}\right) - 0 \right) = \frac{\pi \Delta P}{2\eta L} \left( \frac{R^4}{4} \right)$$
- **最終結果**:
  $$Q = \frac{\pi R^4 \Delta P}{8 \eta L}$$


# 應用
- **血液流動**: 泊肅葉定律是理解血液循環的基礎。動脈由於膽固醇堆積而輕微變窄（半徑 $R$ 減小），會導致維持正常血流量所需的壓力差 $\Delta P$ 急劇升高，從而引發高血壓並加重心臟負擔。
- **醫療注射**: 護士在注射藥物時，若換用內徑小一半的針頭，在維持相同流速的情況下，所需的推力（壓力）會增加到原來的 $2^4 = 16$ 倍。
- **管線設計**: 在工程中用於計算和設計各類管道系統（如水管、油管）的流量與壓力規格。
