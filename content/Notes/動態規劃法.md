# 主要步驟
- 大問題$\to$子問題
- 列表法(記憶法):紀錄子問題的最佳解

# 特點
- 保證最佳解
- 時間複雜度: 暴力法>動態規劃>貪婪演算
- 尋找有很多**重疊子問題**的情況的最佳解時有效
- 每次將小問題的答案記錄下來，當下一回來用到前一回合答案時就直接查表，也可以說是一種用空間換取時間的解題方式

# 應用舉例
- 費氏數列

```python
# 費氏數列動態規劃法
def Fib_DP(n):
	if n == 0:
		return 0
	elif n == 1:
		return 1
	else:
		Fib = [0 for 1 in range(n + 1)]
		Fib[0] = 0
		Fib[1] = 1
		for i in range (2, n + 1):
			Fib[i] = Fib[i - 1] + Fib[i - 2]
		return Fib[n]

# 計算費氏數列
for n in range(40):
	print('Fib(' + str(n) + ') =', Fib_DP(n))
```

- 更進一步地，只記錄相鄰二值，以迴圈的方式執行，可以節省時間
