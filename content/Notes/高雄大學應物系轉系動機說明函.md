# 壹、 轉學動機：追求材料物理的完整體系
在就讀於屏東大學應用物理系期間，我雖在基礎學科取得班排一的佳績，但在選課與修課的時候，發現原校的課程規劃與我的職涯志趣產生落差。
我認為材料科學需要連貫的化學與物理基礎，然原校在「普通化學（二）」的授課資源缺口，以及其他針對化學操作之課程，使我決定尋求轉學，進入教學體系更完善的**國立高雄大學應用物理系**。

# 貳、 為何選擇高雄大學應用物理系
近年Formula 1 收穫大量粉絲，我也是其中之一。我最著迷的是各個賽季車隊對於賽車的改裝、設計與優化，這使我開始反思，台灣的工業是否能夠更加多元，而非僅僅是半導體領域的專精。因此，**我希望接觸更多不同領域之材料研究，並探索其在台灣多元工業發展的可能性。** 高雄大學應用物理系不僅在地緣上緊鄰半導體與精密工業聚落，其課程設計更精準對接了我的需求：
1. **理論與模擬並重：** 貴系強調「理論與計算物理」，這與我目前精進 Python 以進行物理計算的方向不謀而合。
2. **固態材料的深度：** 我渴望修習貴系開設之「固態物理」、「材料性質量測與分析」及「薄膜物理」。相比於化材系著重製程與合成，我更希望從「微觀物理本質」出發，理解材料結構如何決定其宏觀物理表現。

# 參、 學習計畫與個人優勢之應用
若能進入貴系就讀，我將利用大二一年的時間，在維持學術優勢的同時，完成以下目標：
- **補齊學科斷層：** 優先修習「普通化學（二）」、「普通化學實驗」與「工程數學」，構築完整的材料科學前瞻知識。
- **跨域工具整合：** 利用過去在 **3D 空間建模**培養的空間感，輔助理解複雜的晶體結構與應力分佈；並運用 **Python 程式之基礎**投入「計算機概論」與後續的科學計算課程，嘗試建立初步的材料物理模型。

# 肆、 未來願景
台灣在全球供應鏈中占有舉足輕重的地位，但我認為未來工業的突破點在於「自主品牌」與「材料主導權」。我目標在貴系紮實的學術架構下，從基礎物理出發，研發出更具競爭力的先進材料或技術。我已準備好以班級第一的專注力與高度的擴充性，銜接貴系大二之後的挑戰，為應用物理領域貢獻所長。
