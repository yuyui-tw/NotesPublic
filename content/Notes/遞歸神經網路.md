# NLP的深度學習
- [[語言模型與分散式表徵#^c86051|二元語言模型]]只能根據當前詞的前一個詞進行判斷
為了讓脈絡解析的範圍能==覆蓋全文==，NLP展開了深度學習的研究

1. 2013: word2vec [[語言模型與分散式表徵#分散式表徵|分散式表徵]]，NLP研究的基礎
2. 2014: [[#Seq2Seq]] 機器翻譯精度提升
3. 2017: [[Transformer]] 注意力機制為基礎的平行運算
4. 2018: [[BERT]] 高精度微調
5. 2020: GPT-3 大數據訓練，生成文章

# RNN
[[資料種類與AI特徵#RNN|RNN]]，處理[[NLP的預處理#^88d46c|序列資料]]所使用的一種神經網路
- NLP、股價預測、語音或視訊辨識
- 回饋循環:紀錄並使用過去資訊以預測當前任務
- 縱向運算具有神經網路的三層構造，橫向運算具有與資料量正相關的深度學習結構
- ==距離任務單詞遙遠的歷史單詞，資訊很難反應和調用==

# LSTM
![[深度學習#^c81603]]


- ==可取捨過去資訊並選擇所要記憶資料==的結構
	- 彌補[[#RNN]]過遠歷史資料的問題
- cell state: 記憶渠道，保存過去資料
	- 閥門概念: 記憶功能**非二元決定是否遺忘**，而是以0~1判別全部資訊的多少**比例**以記憶
- LSTM的三種閥門(可變之深度學習參數)
	- 資料的取捨抉擇
		- forget gate: 遺忘門，判斷記憶渠道需要遺忘多少資料
		- input gate: 輸入門，取捨要記錄多少新資料
	- 輸出資訊
		- output gate: 輸出門，決定需進行預測的資料
- Gate Recurrent Unit, GRU:藉由減少參數數量以縮短計算時間的模型

# Seq2Seq
*Sequence to Sequence*
處理輸入序列資料後再**輸出序列資料**的任務之模型，例如[[甚麼是自然語言處理(NLP)#^5ec69c|機器翻譯]]
- encoder-decoder: 由編碼器和解碼器組成 ^848a38
	- 編碼器 *encoder*: 資料編碼轉換為固定長度之向量
	- 解碼器 *decoder*: 將編碼後的資料解碼(復原)
	- 預測任務之構造同[[#RNN]]或[[#LSTM]]
	- BOS/EOS: Begin/End of Sentence(Sequence)
