# 標註語料庫
*annotated corpus*
>在一定數量的生語料庫附上語法解釋的語料庫

## 序列^[序列資料、文章]標記
- 單詞之詞類資訊
- 命名實體識別 *Named Entity Recognition, NER* : 專有名詞(人名、地名、組織等)與數值(日期、時間等)的辨識 ^b57d5b
- BIO標記法
	- Begin為命名實體開始, Inside屬於命名實體, Outside不屬於命名實體
	- 學習法: 由條件機率求得之條件隨機場(*Conditional Random Field，CRF*)、深度學習之[[BERT]]

e.g. 

| 單詞列    | BIO標記列           |
| ------ | ---------------- |
| 藍染     | B-人名             |
| 在      | O                |
| 2077   | B-日期             |
| 年      | I-日期 $\Uparrow$  |
| 買了     | O                |
| JONGGA | B-組織名            |
| 製品     | I-組織名 $\Uparrow$ |
| 的      | O                |
| 泡菜     | O                |

## 文書分類
>基於規則對文章做分類之任務
>e.g. 預測新聞報導的類別是政治、國際、經濟等；情緒分析
>- 序列標記的對象是文字列，文書分類則是文章

- 自定義分類基準，由人類加入註解
- 二元分類，e.g. 評論的正面意見為1，負面意見為0...
- 學習法
	- 監督式學習之隨機森林
	- [[BERT]]

# 雙語語料庫
*bilingual corpus*
>包含兩種語言互相對譯的文本對之生語料庫，由原始語言和目標語言組成
>常用於機器翻譯、文章校正、總結、回答問題等

- 統計式機器翻譯 *Statistical Machine Translation，SMT*
	- 以機率和統計法學習字詞的對應關係和文法順序
	- IBM模型: 字詞對齊 *word alignment*
- 神經機器翻譯 *Neural machine translation，NMT*

# 評價指標
- Recall、Precision、F-1 score、BLEU
## 雙語替換評測
*bilingual evaluation understudy，BLEU*
- 評價機器翻譯性能的代表性指標，方式為**翻譯結果愈接近專業譯者的翻譯，則模型精度愈高**
- 以單詞的一致率為指標
- Ngram

| N =  | Name    |
| ---- | ------- |
| 1    | unigram |
| 2    | bi-gram |
| 3    | trigram |
| 4或以上 | N-gram  |

e.g.
正確翻譯 These cookies are delicious.
系統A These cookies are very good.
系統B These cookies are very bad.

部分計算:
unigram:
正解 {**These, cookies, are**, delicious}
系統A {**These, cookies, are**, very, good}
系統B {**These, cookies, are**, very, bad}
$$
ScoreA = ScoreB = \frac{3}{5} = 0.6
$$

bi-gram:
正解 {**These-cookies, cookies-are**, are-delicious}
系統A {**These-cookies, cookies-are**, are-very, very-good}
系統B {**These-cookies, cookies-are**, are-very, very-abd}
$$
ScoreA = ScoreB = \frac{2}{4} = 0.5
$$

>N = 1 或 2 時雖然得分相同，但good比bad更接近原意，所以感覺A效能更好
