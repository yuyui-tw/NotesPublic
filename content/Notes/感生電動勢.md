# 1. 導論 (Introduction & Background)

**感生電動勢 (Induced EMF)**，又稱變壓器電動勢 (Transformer EMF)，是指當導體處於隨時間變化的磁場中，即使導體本身保持靜止，也會產生感應電動勢的現象。

馬克士威 (James Clerk Maxwell) 提出，這種電動勢的產生是因為**時變磁場 (Time-varying Magnetic Field)** 在空間中激發了一種特殊的電場，稱為**感應電場 (Induced Electric Field)**。

# 2. 核心 (Core Framework)

### 馬克士威-法拉第方程式 (Maxwell-Faraday Equation)
感生電動勢的積分定義為感應電場 $\mathbf{E}_{ind}$ 沿封閉路徑的線積分：
$$\varepsilon = \oint_L \mathbf{E}_{ind} \cdot d\mathbf{l} = -\frac{d\Phi_B}{dt}$$

### 微分形式 (Differential Form)
根據[[斯托克斯定理]]，可導出電場旋度與磁場變化率的關係：
$$\nabla \times \mathbf{E} = -\frac{\partial \mathbf{B}}{\partial t}$$

### 磁通量變化率
對於固定面積的迴路，$d\Phi_B/dt = A(dB/dt)$，因此：
$$\varepsilon = -A \frac{dB}{dt}$$

# 3. 邏輯 (Operational Logic)

### 感應電場與靜電場的比較
| 特性 | 靜電場 (Electrostatic Field) | 感應電場 (Induced Electric Field) |
| :--- | :--- | :--- |
| **來源** | 靜止電荷 | 時變磁場 |
| **線積分** | 沿封閉曲線積分為零 ($\oint \mathbf{E} \cdot d\mathbf{l} = 0$) | 沿封閉曲線積分不為零 |
| **性質** | 保守場 (Conservative) | **非保守場 (Non-conservative)** |
| **力線形式** | 起於正電荷，終於負電荷 | **封閉曲線** |
| **電位定義** | 可定義電位 (Potential) | **不可定義電壓/電位** |

### 產生機制
時變磁場在空間中產生渦旋狀的感應電場。若在該空間中放置導體，感應電場會對導體內的自由電荷施力，迫使電荷流動形成感應電流。即使沒有實體導線，感應電場依然存在於空間中。

# 4. 應用與脈絡 (Application & Context)

- **變壓器 (Transformer)**：利用初級線圈的時變磁場在次級線圈激發感生電動勢。
- **渦電流 (Eddy Currents)**：塊狀導體內部的感應電流，常用於電磁感應加熱或磁煞車。
- **電子感應加速器 (Betatron)**：利用時變磁場產生的渦旋電場來加速電子。
