# 微積分期末考複習題整理

## 13-7: Extreme Values
**解題方法：** 找出函數在區域內部的臨界點（即 $\nabla f = 0$ 處），並分別討論區域邊界上的極值。
相關筆記：[[多變數函數極值]]、[[Extrem Values of Functions on closed Intervals]]

**35: Find absolute max and min: $T(x, y) = x^2 + xy + y^2 - 6x + 2$ on the rectangular plate $0 \le x \le 5, -3 \le y \le 0$**
1. Interior critical points:
   $T_x = 2x + y - 6 = 0$
   $T_y = x + 2y = 0 \implies x = -2y$
   $2(-2y) + y - 6 = 0 \implies y = -2, x = 4$
   $T(4, -2) = 16 - 8 + 4 - 24 + 2 = -10$
2. Boundaries:
   - $y=0, 0 \le x \le 5: T(x,0) = x^2 - 6x + 2$. Critical at $x=3, T(3,0)=-7$. Endpoints $T(0,0)=2, T(5,0)=-3$.
   - $y=-3, 0 \le x \le 5: T(x,-3) = x^2 - 9x + 11$. Critical at $x=4.5, T(4.5,-3)=-9.25$. Endpoints $T(0,-3)=11, T(5,-3)=-9$.
   - $x=0, -3 \le y \le 0: T(0,y) = y^2 + 2$. Critical at $y=0$. Endpoints $T(0,0)=2, T(0,-3)=11$.
   - $x=5, -3 \le y \le 0: T(5,y) = y^2 + 5y - 3$. Critical at $y=-2.5, T(5,-2.5)=-9.25$. Endpoints $T(5,0)=-3, T(5,-3)=-9$.
3. Result: Max $T(0,-3) = 11$, Min $T(4,-2) = -10$.

**39: Find two numbers $a$ and $b$ with $a \le b$ such that $\int_a^b (6 - x - x^2) \, dx$ has its largest value.**
1. Maximize $I = \int_a^b (6-x-x^2) dx$.
2. Integrand $f(x) = 6-x-x^2 = -(x+3)(x-2)$.
3. $f(x) \ge 0 \iff -3 \le x \le 2$. ($f(x)\ge 0$避免積分值包含負數域)
4. Result: $a = -3, b = 2$.

## 13-8: Lagrange Multipliers
**解題方法：** 使用拉格朗日乘子法 $\nabla f = \lambda \nabla g$ 求解受限極值問題。
相關筆記：[[拉格朗日乘子法]]、[[Lagrange Multipliers]]

**41: Extrema on a curve of intersection - Find the extreme values of $f(x, y, z) = x^2 yz + 1$ on the intersection of the plane $z = 1$ with the sphere $x^2 + y^2 + z^2 = 10$.**
1. 建立複數輔助函數 (Lagrangian Function):
   $L(x, y, z, \lambda, \mu) = (x^2 yz + 1) + \lambda(z - 1) + \mu(x^2 + y^2 + z^2 - 10)$
2. 求偏微分為零 ($\nabla L = 0$):
   - $L_x = 2xyz + 2\mu x = 2x(yz + \mu) = 0$
   - $L_y = x^2 z + 2\mu y = 0$
   - $L_z = x^2 y + \lambda + 2\mu z = 0$
   - $L_\lambda = z - 1 = 0 \implies z = 1$
   - $L_\mu = x^2 + y^2 + z^2 - 10 = 0 \implies x^2 + y^2 = 9$
3. 解聯立方程:
   - 由 $L_x = 0$ 且 $z=1$ 得 $2x(y + \mu) = 0 \implies x=0$ 或 $\mu = -y$。
   - 若 $x=0$: 則 $y^2 = 9 \implies y = \pm 3$。點為 $(0, \pm 3, 1)$，$f = 1$。
   - 若 $\mu = -y$: 代入 $L_y = 0$ 得 $x^2(1) + 2(-y)y = 0 \implies x^2 = 2y^2$。
   - 代入 $x^2 + y^2 = 9$ 得 $3y^2 = 9 \implies y = \pm \sqrt{3}, x = \pm \sqrt{6}$。
4. 計算極值:
   - $f(\pm\sqrt{6}, \sqrt{3}, 1) = (6)(\sqrt{3})(1) + 1 = 1 + 6\sqrt{3}$
   - $f(\pm\sqrt{6}, -\sqrt{3}, 1) = (6)(-\sqrt{3})(1) + 1 = 1 - 6\sqrt{3}$
5. Result: Max $1+6\sqrt{3}$, Min $1-6\sqrt{3}$.

**43: Extrema on a circle of intersection - Find the extreme values of $f(x, y, z) = xy + z^2$ on the circle in which the plane $y - x = 0$ intersects the sphere $x^2 + y^2 + z^2 = 4$.**
1. 建立複數輔助函數 (Lagrangian Function):
   $L(x, y, z, \lambda, \mu) = (xy + z^2) + \lambda(y - x) + \mu(x^2 + y^2 + z^2 - 4)$
2. 求偏微分為零 ($\nabla L = 0$):
   - $L_x = y - \lambda + 2\mu x = 0$
   - $L_y = x + \lambda + 2\mu y = 0$
   - $L_z = 2z + 2\mu z = 2z(1 + \mu) = 0$
   - $L_\lambda = y - x = 0 \implies y = x$
   - $L_\mu = x^2 + y^2 + z^2 - 4 = 0 \implies 2x^2 + z^2 = 4$
3. 解聯立方程:
   - 由 $L_z = 0$ 得 $z=0$ 或 $\mu = -1$。
   - 若 $z=0$: 則 $2x^2 = 4 \implies x^2 = 2 \implies x = \pm \sqrt{2}$。點為 $(\pm\sqrt{2}, \pm\sqrt{2}, 0)$，$f = 2$。
   - 若 $\mu = -1$: 聯立 $L_x, L_y$ 且 $y=x$ 得 $x - \lambda - 2x = 0$ 與 $x + \lambda - 2x = 0 \implies x=0, \lambda=0$。
   - 若 $x=0$: 則 $y=0$，由 $2x^2 + z^2 = 4$ 得 $z^2 = 4 \implies z = \pm 2$。點為 $(0, 0, \pm 2)$，$f = 4$。
4. Result: Max $4$, Min $2$.

## 14-4: Double Integrals in Polar Form
**解題方法：** 將直角座標轉換為極座標 $x = r\cos\theta, y = r\sin\theta$，$dA = r dr d\theta$。
相關筆記：[[二重積分]]、[[極座標]]

**11: change to polar integral then evaluate: $\int_0^2 \int_0^{\sqrt{4-y^2}} (x^2+y^2) \, dx \, dy$**
1. Region: $0 \le r \le 2, 0 \le \theta \le \pi/2$.
2. $\int_0^{\pi/2} \int_0^2 r^2 \cdot r dr d\theta = \int_0^{\pi/2} [\frac{1}{4}r^4]_0^2 d\theta = \int_0^{\pi/2} 4 d\theta = 2\pi$.

**41: Converting to polar integral**
**a. The usual way to evaluate the improper integral $I = \int_0^\infty e^{-x^2} \, dx$ is first to calculate its square:**
**$I^2 = \left( \int_0^\infty e^{-x^2} \, dx \right) \left( \int_0^\infty e^{-y^2} \, dy \right) = \int_0^\infty \int_0^\infty e^{-(x^2 + y^2)} \, dx \, dy$.**
**Evaluate the last integral using polar coordinates and solve the resulting equation for $I$.**
1. $I^2 = \int_0^{\pi/2} \int_0^\infty e^{-r^2} r dr d\theta = \int_0^{\pi/2} [-\frac{1}{2}e^{-r^2}]_0^\infty d\theta = \int_0^{\pi/2} \frac{1}{2} d\theta = \pi/4$.
2. $I = \sqrt{\pi}/2$.

**b. Evaluate $\lim_{x \to \infty} \text{erf}(x) = \lim_{x \to \infty} \int_0^x \frac{2e^{-t^2}}{\sqrt{\pi}} \, dt$**
1. $\lim_{x \to \infty} \text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^\infty e^{-t^2} dt = \frac{2}{\sqrt{\pi}} \cdot \frac{\sqrt{\pi}}{2} = 1$.

## 14-5: Triple Integrals
**解題方法：** 根據邊界平面設定三重積分的積分上下限。
相關筆記：[[三重積分]]

**33: Find the volume using triple integral: The region between the planes $x+y+2z=2$ and $2x+2y+z=4$ in the first octant.**
1. Intersection: $x+y+2z=2, 2x+2y+z=4 \implies x+y=2$.
2. Upper: $z_2 = 4-2x-2y$, Lower: $z_1 = 1-x/2-y/2$.
3. $V = \int_0^2 \int_0^{2-x} \int_{z_1}^{z_2} dz dy dx = \int_0^2 \int_0^{2-x} (3 - \frac{3}{2}x - \frac{3}{2}y) dy dx$.
4. $V = \frac{3}{2} \int_0^2 [2y - xy - \frac{1}{2}y^2]_0^{2-x} dx = \frac{3}{2} \int_0^2 \frac{1}{2}(2-x)^2 dx = \frac{3}{2} [-\frac{1}{6}(2-x)^3]_0^2 = \frac{3}{2} \cdot \frac{8}{6} = 2$.

## 14-7: Cylindrical and Spherical Coordinates
**解題方法：** 柱座標 $(r, \theta, z)$ 或球座標 $(\rho, \phi, \theta)$。
相關筆記：[[三重積分]]、[[曲線座標]]

**23: evaluate integral in cylindrical coordinate: $\int_0^{2\pi} \int_0^1 \int_r^{\sqrt{2-r^2}} r \, dz \, dr \, d\theta$**
1. $\int_0^{2\pi} \int_0^1 r(\sqrt{2-r^2} - r) dr d\theta = 2\pi [-\frac{1}{3}(2-r^2)^{3/2} - \frac{1}{3}r^3]_0^1$.
2. $2\pi ( (-\frac{1}{3} - \frac{1}{3}) - (-\frac{2\sqrt{2}}{3} - 0) ) = \frac{2\pi}{3}(2\sqrt{2} - 2)$.

**55: Find iterated integral in spherical coordinate: The solid between the sphere $\rho = \cos\phi$ and hemisphere $\rho = 2, z \ge 0$.**
1. $V = \int_0^{2\pi} \int_0^{\pi/2} \int_{\cos\phi}^2 \rho^2 \sin\phi d\rho d\phi d\theta$.
2. $2\pi \int_0^{\pi/2} \frac{1}{3}(8 - \cos^3\phi)\sin\phi d\phi = \frac{2\pi}{3} [-8\cos\phi + \frac{1}{4}\cos^4\phi]_0^{\pi/2} = \frac{2\pi}{3} (0 - (-8+1/4)) = \frac{31\pi}{6}$.

**59: Find iterated integral in spherical coordinate: the solid bounded below by the sphere $\rho = 2 \cos\phi$ and above by the cone $z = \sqrt{x^2+y^2}$.**
1. Cone: $\phi = \pi/4$. Solid below cone and above sphere.
2. Setup: $\int_0^{2\pi} \int_{\pi/4}^{\pi/2} \int_0^{2\cos\phi} \rho^2 \sin\phi d\rho d\phi d\theta$.
3. $2\pi \int_{\pi/4}^{\pi/2} \frac{8}{3}\cos^3\phi \sin\phi d\phi = \frac{16\pi}{3} [-\frac{1}{4}\cos^4\phi]_{\pi/4}^{\pi/2} = \frac{16\pi}{3} (0 + \frac{1}{4}(\frac{1}{\sqrt{2}})^4) = \frac{16\pi}{3} \cdot \frac{1}{16} = \frac{\pi}{3}$.

**69: find the volume between $r = \sin\theta$ and $z = \sqrt{1-x^2-y^2}$ in First Octant**
1. $V = \int_0^{\pi/2} \int_0^{\sin\theta} r\sqrt{1-r^2} dr d\theta = \int_0^{\pi/2} [-\frac{1}{3}(1-r^2)^{3/2}]_0^{\sin\theta} d\theta$.
2. $\frac{1}{3} \int_0^{\pi/2} (1 - \cos^3\theta) d\theta = \frac{1}{3} ( \pi/2 - (1-1/3) ) = \frac{\pi}{6} - \frac{2}{9}$.

## 14-8: Substitution in Multiple Integrals
**解題方法：** 使用雅可比行列式（Jacobian）進行座標轉換。
相關筆記：[[座標變換]]

**19: Evaluate $\iiint_D |xyz| \, dx \, dy \, dz$ over the solid ellipsoid $D: \frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} \le 1$. (Hint: Let $x=au, y=bv, z=cw$. Then integrate over an appropriate region in $uvw$-space.)**
1. Let $x=au, y=bv, z=cw \implies J = abc$.
2. $abc \iiint_{u^2+v^2+w^2 \le 1} |(au)(bv)(cw)| du dv dw = a^2b^2c^2 \cdot 8 \int_0^{\pi/2} \int_0^{\pi/2} \int_0^1 \rho^5 \sin^3\phi \cos\phi \sin\theta \cos\theta d\rho d\phi d\theta$.
3. $8 a^2b^2c^2 (\frac{1}{6}) (\frac{1}{4}) (\frac{1}{2}) = \frac{a^2b^2c^2}{6}$.

## 15-1: Line Integrals
**解題方法：** 將曲線參數化 $\mathbf{r}(t)$，並計算 $\int_C f ds = \int_a^b f(\mathbf{r}(t)) |\mathbf{r}'(t)| dt$。
相關筆記：[[線積分]]、[[Line and Surface Integrals]]

**19: evaluate $\int_C x \, dx$ where $C$ is**
**a. the straight-line segment $x= t, y=t/2$ from $(0,0)$ to $(4,2)$**
1. $x=t, dx=dt, 0 \le t \le 4$.
2. $\int_0^4 t dt = 8$.

**b. the parabolic curve $x=t, y=t^2$ from $(0,0)$ to $(2,4)$**
1. $x=t, dx=dt, 0 \le t \le 2$.
2. $\int_0^2 t dt = 2$.

## 15-2: Vector Fields and Line Integrals (Work)
**解題方法：** 計算功 $W = \int_C \mathbf{F} \cdot d\mathbf{r} = \int_a^b \mathbf{F}(\mathbf{r}(t)) \cdot \mathbf{r}'(t) dt$。
相關筆記：[[線積分]]、[[向量微積分習題]]

**19: Find the work done by $\mathbf{F}$ over the curve in the direction of increasing $t$. $\mathbf{F} = xy\mathbf{i} + y\mathbf{j} - yz\mathbf{k}, \mathbf{r}(t) = t\mathbf{i} + t^2\mathbf{j} + t\mathbf{k}, 0 \le t \le 1$**
1. $\mathbf{r}'(t) = (1, 2t, 1), \mathbf{F}(\mathbf{r}(t)) = (t^3, t^2, -t^3)$.
2. $W = \int_0^1 (t^3 + 2t^3 - t^3) dt = \int_0^1 2t^3 dt = \frac{1}{2}$.

## 15-4: Green's Theorem
**解題方法：** 利用格林定理將線積分轉換為區域內的二重積分。
相關筆記：[[格林定理]]

**1: find the $k$-component of $\text{curl}(\mathbf{F})$ for the following vector fields on the plane. $\mathbf{F} = (x+y)\mathbf{i} + (2xy)\mathbf{j}$**
1. $\text{curl}_k \mathbf{F} = \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 2y - 1$.

**7: verify the conclusion of Green's Thm by evaluating both sides of the circulation and flux forms of the theorem. Take the domains of integrals in each case to be the disk $R: x^2+y^2 \le a^2$ and its bounding circle $C: \mathbf{r} = (a \cos t)\mathbf{i} + (a \sin t)\mathbf{j}, 0 \le t \le 2\pi, \mathbf{F} = -y\mathbf{i} + x\mathbf{j}$**
1. 向量場分量: $P = -y, Q = x$。
2. **Circulation (環量) 驗證**:
   - 線積分: $\oint_C \mathbf{F} \cdot d\mathbf{r} = \int_0^{2\pi} [(-a\sin t)(-a\sin t) + (a\cos t)(a\cos t)] dt = \int_0^{2\pi} a^2 dt = 2\pi a^2$。
   - 二重積分: $\iint_R (\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}) dA = \iint_R (1 - (-1)) dA = \iint_R 2 dA = 2(\pi a^2) = 2\pi a^2$。
3. **Flux (通量) 驗證**:
   - 線積分: $\oint_C \mathbf{F} \cdot \mathbf{n} \, ds = \oint_C P dy - Q dx = \int_0^{2\pi} [(-a\sin t)(a\cos t) - (a\cos t)(-a\sin t)] dt = 0$。
   - 二重積分: $\iint_R (\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y}) dA = \iint_R (0 + 0) dA = 0$。

**11: use Green's Thm to find the counterclockwise circulation and outward flux for the field $\mathbf{F} = (x-y)\mathbf{i} + (y-x)\mathbf{j}$ and the curve $C$: the square bounded by $x=0, x=1, y=0$ and $y=1$**
1. 向量場分量: $P = x-y, Q = y-x$。
2. **Circulation**:
   - 使用格林定理: $\oint_C \mathbf{F} \cdot d\mathbf{r} = \iint_R (\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}) dA$。
   - 計算偏微分: $\frac{\partial Q}{\partial x} = -1, \frac{\partial P}{\partial y} = -1$。
   - $\iint_R (-1 - (-1)) dA = \iint_R 0 dA = 0$。
3. **Outward Flux**:
   - 使用格林定理: $\oint_C \mathbf{F} \cdot \mathbf{n} \, ds = \iint_R (\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y}) dA$。
   - 計算偏微分: $\frac{\partial P}{\partial x} = 1, \frac{\partial Q}{\partial y} = 1$。
   - $\iint_R (1 + 1) dA = \int_0^1 \int_0^1 2 dx dy = 2$。

**15: use Green's Thm to find the counterclockwise circulation and outward flux for the field $\mathbf{F} = (xy+y^2)\mathbf{i} + (x-y)\mathbf{j}$ and the curve $y = x^2$ from $(0,0)$ to $(1,1)$ and $x = y^2$ from $(1,1)$ to $(0,0)$**
1. 區域 $R$: 下邊界 $y = x^2$，上邊界 $y = \sqrt{x}$，其中 $0 \le x \le 1$。
2. 向量場分量: $P = xy+y^2, Q = x-y$。
3. **Circulation**:
   - $\text{curl}_k \mathbf{F} = \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 1 - (x+2y)$。
   - $\iint_R (1-x-2y) dy dx = \int_0^1 [y-xy-y^2]_{x^2}^{\sqrt{x}} dx$
   - $= \int_0^1 [(\sqrt{x} - x\sqrt{x} - x) - (x^2 - x^3 - x^4)] dx$
   - $= [\frac{2}{3}x^{3/2} - \frac{2}{5}x^{5/2} - \frac{1}{2}x^2 - \frac{1}{3}x^3 + \frac{1}{4}x^4 + \frac{1}{5}x^5]_0^1 = \frac{2}{3} - \frac{2}{5} - \frac{1}{2} - \frac{1}{3} + \frac{1}{4} + \frac{1}{5} = -7/60$。
4. **Outward Flux**:
   - $\text{div} \mathbf{F} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} = y + (-1) = y-1$。
   - $\iint_R (y-1) dy dx = \int_0^1 [\frac{1}{2}y^2 - y]_{x^2}^{\sqrt{x}} dx$
   - $= \int_0^1 [(\frac{1}{2}x - \sqrt{x}) - (\frac{1}{2}x^4 - x^2)] dx$
   - $= [\frac{1}{4}x^2 - \frac{2}{3}x^{3/2} - \frac{1}{10}x^5 + \frac{1}{3}x^3]_0^1 = \frac{1}{4} - \frac{2}{3} - \frac{1}{10} + \frac{1}{3} = -11/60$。
