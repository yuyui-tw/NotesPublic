# 概念
*Binary Tree*
是一種樹結構，它是一種分層的數據結構，其中每個節點最多可以有兩個子節點，分別稱為 **左子節點 (Left Child)** 和 **右子節點 (Right Child)**

* **節點 (Node):** 樹的基本組成單元，包含數據和指向子節點的連結
* **根節點 (Root Node):** 樹的最頂層節點，沒有父節點
* **父節點 (Parent Node):** 有子節點的節點
* **子節點 (Child Node):**  被父節點指向的節點
* **葉節點 (Leaf Node):** 沒有子節點的節點
* **邊 (Edge):** 節點之間的連接線
* **深度 (Depth):** 從根節點到某個節點的邊的數量。
* **高度 (Height):** 從某個節點到其最遠子節點的邊的數量。

# 類型

*   **完全二元樹 (Complete Binary Tree):**  除了最後一層之外，所有層都完全填滿，且最後一層節點都從左到右排列
*   **滿二元樹 (Full Binary Tree):**  所有節點都有兩個子節點，或者沒有子節點（葉節點）
*   **平衡二元樹 (Balanced Binary Tree):**  左子樹和右子樹的高度差異不大，通常為了提高搜索效率而設計
	* 常見的平衡二元樹包括 AVL 樹和紅黑樹
*   **二元搜索樹 (Binary Search Tree, BST):**  左子樹的所有節點值都小於其父節點的值，而右子樹的所有節點值都大於其父節點的值。這使得在 BST 中進行搜索、插入和刪除操作非常高效

# 應用

* 數據搜索和排序: 二元搜索樹 (BST) 是一種高效的數據結構，用於搜索和排序數據
* 表達式求值: 二元樹可以用來表示數學表達式，例如加法、減法、乘法和除法
* 編譯器: 二元樹可以用來表示抽象語法樹 (Abstract Syntax Tree, AST)，用於編譯器中的語法分析和代碼生成
* 文件系統: 一些文件系統使用樹結構來組織文件和目錄
* 決策樹: 在機器學習中，決策樹是一種用於分類和回歸的算法，它使用樹結構來表示決策規則

# Python
在Python中，二元樹通常用類來呈現
```python
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None

class BinaryTree:
    def __init__(self, root=None):
        self.root = root
```


## 範例：建立一個二元樹
```python
root = Node(1)
root.left = Node(2)
root.right = Node(3)
root.left.left = Node(4)
root.left.right = Node(5)
```
## 建立BinaryTree物件
```python
tree = BinaryTree(root)
```

## 範例：遍歷二元樹 (前序)
```python
def preorder(node):
    if node:
        print(node.data)
        preorder(node.left)
        preorder(node.right)

preorder(tree.root) # 輸出: 1 2 4 5 3
```
