# 概要
伯努利方程式（Bernoulli's Equation）是流體力學中的一個關鍵關係式，基於**能量守恆原理**，用於描述在特定條件下，流體沿著流線流動時，其壓力、流速和海拔高度之間的動態平衡。

# 核心概念
- **能量守恆**: 在理想流體中，壓力能、動能和重力勢能三者之和沿流線保持恆定。
- **壓力與速度反比**: 在水平流動中，流體流速高的區域其壓力較低，反之亦然。
- **應用條件**: 僅適用於**理想**（無黏性）、**不可壓縮**、**穩定**的流體流動。

# 結構/要素
伯努利方程式的通用形式表達為：
$$p + \rho g y + \frac{1}{2}\rho v^2 = \text{常數}$$
對於流管中任意兩點（1和2），此方程式可寫為：
$$p_1 + \rho g y_1 + \frac{1}{2}\rho v_1^2 = p_2 + \rho g y_2 + \frac{1}{2}\rho v_2^2$$
其中：
-   $p$：流體壓力
-   $\rho$：流體密度
-   $g$：重力加速度
-   $y$：流體點的海拔高度
-   $v$：流體流速

# 原理/推導
伯努利方程式是將**功-能定理**（Work–Energy Theorem）應用於流體元素推導而來。在忽略流體內部摩擦力（黏性）的情況下，流體所受的淨功等於其動能與重力位能的變化總和。

-   **推導基礎 ($W_{\text{淨}} = \Delta K + \Delta U$)**:
    -   **壓力做功 (Work Done by Pressure)**: 考慮一小段流體，在時間 $dt$ 內，入口端（點1）的流體在壓力 $p_1$ 推動下移動了 $dl_1$ 的距離，壓力對流體做功 $dW_1 = F_1 dl_1 = (p_1 A_1) dl_1$。同時，出口端（點2）的流體抵抗壓力 $p_2$ 移動了 $dl_2$ 的距離，外界對流體做負功 $dW_2 = -F_2 dl_2 = -(p_2 A_2) dl_2$。
    -   因此，壓力對流體所做的淨功為 $dW = p_1 (A_1 dl_1) - p_2 (A_2 dl_2)$。
    -   根據連續性方程式，流體體積元 $dV = A_1 dl_1 = A_2 dl_2$，故淨功可寫為 $dW = (p_1 - p_2)dV$。
    -   **動能與位能變化**: 該流體元素的動能變化 $\Delta K = \frac{1}{2}(\rho dV)v_2^2 - \frac{1}{2}(\rho dV)v_1^2$，重力位能變化 $\Delta U = (\rho dV)gy_2 - (\rho dV)gy_1$。
    -   **整合**: 將上述三項代入功-能定理 $dW = \Delta K + \Delta U$，並消去 $dV$ 項，即可整理得到伯努利方程式。

-   **靜態流體**: 當流體靜止 ($v_1 = v_2 = 0$) 時，伯努利方程式簡化為靜態流體壓力公式：
    $$p_1 - p_2 = \rho g (y_2 - y_1)$$

-   **物理意義**: 根據方程式，當流體在水平管中加速（流速 $v$ 增加）時，需要一個向前的淨力，這表示必須從高壓區域流向低壓區域。因此，流速高的地方壓力低。

-   **應用限制與延伸 (Limitations and Extensions)**:
    -   **理想流體**: 標準的伯努利方程式僅適用於理想流體。
    -   **非理想流體下的修正**: 對於真實世界的**黏性流體**，由於摩擦會導致能量損失，方程式需要修正。擴展的伯努利方程式引入一個**水頭損失 (Head Loss, $h_L$)** 項來量化這種能量耗散：
        $$\frac{p_1}{\rho g} + \frac{v_1^2}{2g} + y_1 = \frac{p_2}{\rho g} + \frac{v_2^2}{2g} + y_2 + h_L$$
        此處的 $h_L$ 代表因摩擦而損失的能量，這使得方程式能應用於更廣泛的實際工程問題。

# 應用與延伸
### 動態升力 (Dynamic Lift)
動態升力是一種垂直於流體流動方向的作用力，通常與飛機機翼或旋轉的球體相關。它源於物體上下表面的壓力差，此壓力差可由白努利原理解釋：
- **基本原理**: 當流體流經一個非對稱物體（如機翼）時，其上表面的流速會快於下表面。根據白努利原理，流速較快處壓力較低。
- **壓力差產生升力**: 上下表面的壓力差（下方壓力大於上方壓力）產生了一個向上的淨力，即為動態升力。
- **實例**:
    - **飛機機翼**: 機翼的特殊剖面（上凸下平）設計，旨在創造上下表面空氣流速差以產生升力。
    - **旋轉球體的馬格努斯效應 (Magnus Effect)**: 在網球或棒球中，旋轉的球會帶動周圍空氣一起旋轉，導致球的一側空氣流速加快、壓力降低，另一側則相反，從而使球產生側向力，形成曲線運動。
