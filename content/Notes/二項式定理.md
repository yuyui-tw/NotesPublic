# 概要 (Overview)
**二項式定理 (Binomial Theorem)** 描述了二項式的冪次展開規律。具體而言，它給出了當 $n$ 為正整數時，展開 $(x+y)^n$ 的多項式各項係數。

它是代數學中的基礎定理，不僅在組合數學中有重要應用，更是微積分中 **[[二項式級數]] (Binomial Series)** 的有限項特例。

$$
(x+y)^n = \sum_{k=0}^n \binom{n}{k} x^{n-k} y^k = \binom{n}{0}x^n + \binom{n}{1}x^{n-1}y + \dots + \binom{n}{n}y^n
$$

# 核心概念 (Core Concepts)
- **二項式係數 (Binomial Coefficient)**：
    符號為 $\binom{n}{k}$（讀作 "n choose k"），計算公式為：
    $$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$
    這也代表從 $n$ 個相異物中取出 $k$ 個的組合數 $C^n_k$。
- **帕斯卡三角形 (Pascal's Triangle)**：
    二項式係數的幾何排列。三角形中每一行的數字是由上一行相鄰兩數相加而得，反映了恆等式：
    $$\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$$
- **推廣至級數 (Generalization)**：
    當冪次 $n$ 不再是正整數（如分數或負數）時，展開式會變為無限項的 **[[二項式級數]]**，這需要透過 **[[泰勒級數]]** 的理論來處理。

# 結構/要素 (Structure / Elements)
- **一般項 (General Term)**：
    展開式中的第 $k+1$ 項為 $T_{k+1} = \binom{n}{k} x^{n-k} y^k$。
- **對稱性 (Symmetry)**：
    因為 $\binom{n}{k} = \binom{n}{n-k}$，展開式的係數是前後對稱的。
- **係數總和**：
    令 $x=1, y=1$，可得所有係數之和為 $\sum_{k=0}^n \binom{n}{k} = 2^n$。
- **項數**：
    $(x+y)^n$ 展開後共有 $n+1$ 個單項式。

# 原理/推導 (Principles / Derivation)
### 1. 組合學解釋 (Combinatorial Proof)
展開 $(x+y)^n = (x+y)(x+y)\dots(x+y)$ 時，每一項都是從這 $n$ 個括號中各選一個 $x$ 或一個 $y$ 相乘。
若要得到 $x^{n-k}y^k$，必須在 $n$ 個括號中選擇 $k$ 個括號貢獻 $y$，剩餘 $n-k$ 個選 $x$。
因此，該項的係數即為從 $n$ 個中選 $k$ 個的組合數 $\binom{n}{k}$。

### 2. 數學歸納法 (Mathematical Induction)
1. 驗證 $n=1$ 時成立。
2. 假設 $n=m$ 時成立，利用 $(x+y)^{m+1} = (x+y)(x+y)^m$ 並結合帕斯卡恆等式推導 $n=m+1$ 亦成立。

### 與冪級數的對應 (Correspondence with Power Series)
二項式定理可以看作是函數 $f(x) = (1+x)^n$ 的 **[[泰勒級數]]**：
- 當 $n \in \mathbb{N}$，泰勒級數在 $n+1$ 項後的導數皆為 0，因此級數變為有限項的「定理」。
- 當 $n \notin \mathbb{N}$，泰勒級數具有無限項，即為「級數」。
- 這種關係展現了從離散代數到連續分析的過渡。
