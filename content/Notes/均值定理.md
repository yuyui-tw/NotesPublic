# 概要
均值定理（Mean Value Theorem, MVT）是微分學中的一個核心定理。
它描述了一個可導函數在閉區間上的整體平均變化率，與該區間內某一點的瞬時變化率（即導數）之間的關係。此定理有多種形式，其中最基本的是**羅爾定理 (Rolle's Theorem)**，而最常用的是**拉格朗日均值定理 (Lagrange Mean Value Theorem)**，通常簡稱為均值定理。

# 核心理論

## 羅爾定理 (Rolle's Theorem)
羅爾定理是均值定理的特例，也是證明均值定理的基礎。

- **定理條件**:
	設函數 $f(x)$ 滿足以下三個條件：
	1. 在閉區間 $[a, b]$ 上連續。
	2. 在開區間 $(a, b)$ 上可導。
	3. 在區間端點的函數值相等，即 $f(a) = f(b)$。

- **定理結論**:
	則在 $(a, b)$ 中**至少存在一點** $c$，使得該點的導數為零：
	$$ f'(c) = 0 $$

- **幾何意義**:
	若一條連續且處處可導的曲線在兩個端點的高度相同，那麼在這兩點之間，曲線上至少有一點的切線是水平的。

## 均值定理 (The Mean Value Theorem, MVT)
此定理是羅爾定理的推廣，去除了 $f(a) = f(b)$ 的條件。

- **定理條件**:
	設函數 $f(x)$ 滿足以下兩個條件：
	1. 在閉區間 $[a, b]$ 上連續。
	2. 在開區間 $(a, b)$ 上可導。

- **定理結論**:
	則在 $(a, b)$ 中**至少存在一點** $c$，使得：
	$$ f'(c) = \frac{f(b) - f(a)}{b - a} $$

- **幾何意義**:
	對於一條連續且可導的曲線，在任意兩點之間，必定能找到一點，該點的切線斜率恰好等於連接這兩點的割線斜率。

## 柯西均值定理 (Cauchy's Mean Value Theorem)
這是對均值定理的進一步推廣，涉及兩個函數。

- **定理條件**:
	設函數 $f(x)$ 和 $g(x)$ 滿足：
	1. 在閉區間 $[a, b]$ 上皆連續。
	2. 在開區間 $(a, b)$ 上皆可導。
	3. 對於所有 $x \in (a, b)$，$g'(x) \neq 0$。

- **定理結論**:
	則在 $(a, b)$ 中**至少存在一點** $c$，使得：
	$$ \frac{f'(c)}{g'(c)} = \frac{f(b) - f(a)}{g(b) - g(a)} $$
	(註：由 $g'(x) \neq 0$ 和羅爾定理可知 $g(a) \neq g(b)$)

# 定理證明

## 羅爾定理證明
1.  若 $f(x)$ 在 $[a, b]$ 上是常數函數，則對於所有 $x \in (a, b)$，$f'(x) = 0$。定理顯然成立。
2.  若 $f(x)$ 不是常數函數，因為它在 $[a, b]$ 上連續，根據**極值定理**，它必定在 $[a, b]$ 上有最大值 $M$ 和最小值 $m$。
3.  由於 $f(a) = f(b)$ 且 $f(x)$ 不是常數，所以最大值或最小值中至少有一個必定在開區間 $(a, b)$ 內部發生。
4.  假設最大值 $M$ 發生在點 $c \in (a, b)$，即 $f(c) = M$。根據**費馬引理 (Fermat's Lemma)**，如果函數在某個內部點達到極值且在該點可導，則其導數必為零。
5.  因此，存在 $c \in (a, b)$ 使得 $f'(c) = 0$。最小值的情況同理。Q.E.D.

## 均值定理證明
為了證明均值定理，我們構造一個輔助函數，使其滿足羅爾定理的條件。

1.  定義割線函數，即連接點 $(a, f(a))$ 和 $(b, f(b))$ 的直線方程：
    $$ L(x) = f(a) + \frac{f(b) - f(a)}{b - a}(x - a) $$
2.  構造輔助函數 $h(x)$，表示 $f(x)$ 與割線 $L(x)$ 之間的垂直差距：
    $$ h(x) = f(x) - L(x) = f(x) - f(a) - \frac{f(b) - f(a)}{b - a}(x - a) $$
3.  檢驗 $h(x)$ 是否滿足羅爾定理的條件：
    - **連續性**: $h(x)$ 是連續函數 $f(x)$ 和線性函數 $L(x)$ 的差，因此在 $[a, b]$ 上連續。
    - **可導性**: $h(x)$ 在 $(a, b)$ 上可導，其導數為 $h'(x) = f'(x) - \frac{f(b) - f(a)}{b - a}$。
    - **端點值**:
        - $h(a) = f(a) - f(a) - \frac{f(b) - f(a)}{b - a}(a - a) = 0$
        - $h(b) = f(b) - f(a) - \frac{f(b) - f(a)}{b - a}(b - a) = f(b) - f(a) - (f(b) - f(a)) = 0$
    因此 $h(a) = h(b) = 0$。
4.  由於 $h(x)$ 滿足羅爾定理的所有條件，故存在一點 $c \in (a, b)$ 使得 $h'(c) = 0$。
    $$ h'(c) = f'(c) - \frac{f(b) - f(a)}{b - a} = 0 $$
    移項可得：
    $$ f'(c) = \frac{f(b) - f(a)}{b - a} $$
    Q.E.D.

# 推論與應用
均值定理有兩個非常重要的推論，它們是連接導數性質和函數性質的橋樑。

- **推論 1**: 若在區間 $I$ 上的每一點 $x$ 都有 $f'(x) = 0$，則 $f(x)$ 在 $I$ 上是一個常數函數。
	- **證明**: 在區間 $I$ 中任取兩點 $x_1, x_2$ ($x_1 < x_2$)。根據均值定理，存在 $c \in (x_1, x_2)$ 使得 $f'(c) = \frac{f(x_2) - f(x_1)}{x_2 - x_1}$。因為已知 $f'(c) = 0$，所以 $\frac{f(x_2) - f(x_1)}{x_2 - x_1} = 0$，這意味著 $f(x_2) - f(x_1) = 0$，即 $f(x_2) = f(x_1)$。由於 $x_1, x_2$ 是任意兩點，因此 $f(x)$ 在整個區間 $I$ 上為常數。

- **推論 2**: 若在區間 $I$ 上的每一點 $x$ 都有 $f'(x) = g'(x)$，則存在一個常數 $C$，使得在 $I$ 上 $f(x) = g(x) + C$。
	- **證明**: 構造一個新函數 $h(x) = f(x) - g(x)$。那麼對於區間 $I$ 中的所有 $x$，其導數為 $h'(x) = f'(x) - g'(x) = 0$。根據推論 1，$h(x)$ 必定是一個常數，我們稱之為 $C$。所以 $h(x) = C$，即 $f(x) - g(x) = C$，整理後得 $f(x) = g(x) + C$。這個推論是**不定積分**的理論基礎。

# 例題

### 羅爾定理的例子
**問題**: 驗證函數 $f(x) = x^3 - 4x$ 在區間 $[-2, 2]$ 上滿足羅爾定理，並找出所有滿足條件的 $c$ 值。

**解**:
1.  **驗證條件**:
    - $f(x)$ 是多項式函數，在 $[-2, 2]$ 上顯然連續。
    - $f'(x) = 3x^2 - 4$，在 $(-2, 2)$ 上可導。
    - $f(-2) = (-2)^3 - 4(-2) = -8 + 8 = 0$。
    - $f(2) = (2)^3 - 4(2) = 8 - 8 = 0$。
    - 因此 $f(-2) = f(2)$。
2.  **求解 c**:
    根據羅爾定理，存在 $c \in (-2, 2)$ 使得 $f'(c) = 0$。
    $$ 3c^2 - 4 = 0 \implies c^2 = \frac{4}{3} \implies c = \pm \frac{2}{\sqrt{3}} $$
    這兩個值都在 $(-2, 2)$ 區間內，所以均為所求的 $c$ 值。

### 均值定理的例子
**問題**: 驗證函數 $f(x) = \sqrt{x}$ 在區間 $[1, 4]$ 上滿足均值定理，並找出所有滿足條件的 $c$ 值。

**解**:
1.  **驗證條件**:
    - $f(x) = \sqrt{x}$ 在 $[1, 4]$ 上連續。
    - $f'(x) = \frac{1}{2\sqrt{x}}$，在 $(1, 4)$ 上可導。
2.  **求解 c**:
    根據均值定理，存在 $c \in (1, 4)$ 使得 $f'(c) = \frac{f(4) - f(1)}{4 - 1}$。
    - 割線斜率: $\frac{\sqrt{4} - \sqrt{1}}{4 - 1} = \frac{2 - 1}{3} = \frac{1}{3}$。
    - 切線斜率: $f'(c) = \frac{1}{2\sqrt{c}}$。
    令兩者相等：
    $$ \frac{1}{2\sqrt{c}} = \frac{1}{3} \implies 2\sqrt{c} = 3 \implies \sqrt{c} = \frac{3}{2} \implies c = \frac{9}{4} $$
    因為 $c = \frac{9}{4} = 2.25$ 確實位於 $(1, 4)$ 區間內，所以這是所求的 $c$ 值。
