# 電場 (Electric Field)

### 1. 概要 (Overview)
電場是存在於帶電體周圍空間的一種物理場。當測試電荷 (Test Charge) 置於此空間時會受到靜電力作用。電場的引入將「超距作用」轉化為「場的相互作用」，是古典電磁學描述電荷交互作用的基本方式。

### 2. 核心概念 (Core Concepts)
*   **電場強度 ($\mathbf{E}$)**：定義為單位正測試電荷所受的力。
    $$\mathbf{E} = \frac{\mathbf{F}}{q_0}$$
    *   $\mathbf{E}$ 為向量場 (Vector Field)，方向與正測試電荷受力方向相同。
*   **單位 (SI Unit)**：牛頓/庫倫 (N/C) 或 伏特/公尺 (V/m)。
*   **點電荷電場 (Field of a Point Charge)**：
    $$\mathbf{E} = k \frac{q}{r^2} \hat{\mathbf{r}}$$
    *   正電荷產生發散場，負電荷產生匯聚場。

### 3. 結構/要素 (Structure/Elements)
*   **疊加原理 (Principle of Superposition)**：
    多個點電荷在某點產生的總電場，為各電荷單獨存在時在該點產生電場的向量和：
    $$\mathbf{E}_{total} = \sum_{i} \mathbf{E}_i = k \sum_{i} \frac{q_i}{r_i^2} \hat{\mathbf{r}}_i$$
*   **電荷密度 (Charge Densities)**：處理連續分布電荷時的必備參數：
    1.  **線電荷密度 ($\lambda$)**：$\lambda = \frac{dq}{dl}$ (C/m)
    2.  **面電荷密度 ($\sigma$)**：$\sigma = \frac{dq}{dA}$ (C/m²)
    3.  **體電荷密度 ($\rho$)**：$\rho = \frac{dq}{dV}$ (C/m³)

### 4. 原理/推導 (Principles/Derivation)
*   **連續電荷分布之電場計算**：
    將帶電體切割為微元電荷 $dq$，則在空間某點產生的微元電場為 $d\mathbf{E} = k \frac{dq}{r^2} \hat{\mathbf{r}}$。總電場需通過積分求得：
    $$\mathbf{E} = \int d\mathbf{E} = \int \frac{k \cdot \hat{\mathbf{r}}}{r^2} dq$$

*   **典型模型推論 (Exam-Essential Models)**：

| **幾何模型** | **核心公式 (必記)** | **備考關鍵 (Key Points)** |
| :--- | :--- | :--- |
| **有限長細棒 (軸向端點)** | $E = \frac{kQ}{d(L+d)}$ | $dq = \lambda dx$。積分區間從 $d$ 到 $L+d$。 |
| **有限長細棒 (中垂線上)** | $E = \frac{2k\lambda}{y} \sin\theta_0$ | $\theta_0$ 為端點對中心張角之半。$\infty$ 長時 $\sin\theta_0 \to 1$。 |
| **無限長帶電線** | $E = \frac{2k\lambda}{r} = \frac{\lambda}{2\pi\epsilon_0 r}$ | 熟練高斯定律應用。電場與 $r$ 成反比。 |
| **均勻帶電圓環 (軸線上 $z$)** | $E_z = \frac{kQz}{(z^2+R^2)^{3/2}}$ | 垂直軸分量對稱抵消。當 $z \gg R$ 時，視同點電荷。 |
| **均勻帶電圓盤 (軸線上 $z$)** | $E_z = \frac{\sigma}{2\epsilon_0}\left[1 - \frac{z}{\sqrt{z^2+R^2}}\right]$ | 以圓環為 $dq$ 積分。若 $R \to \infty$ 則退化為無限大平面。 |
| **無限大帶電平面** | $E = \frac{\sigma}{2\epsilon_0}$ | 均勻電場。與距離無關。常見於電容器內部場分析。 |
| **均勻帶電球殼 (Shell)** | $E_{out} = \frac{kQ}{r^2}, E_{in} = 0$ | 殼層定理。球外等效點電荷位於球心，球內合場為零。 |

*   **解題策略**：
    1.  **對稱性判斷**：積分前先確定電場分量是否抵消，簡化運算。
    2.  **變數變換**：在處理圓環或圓弧時，常將 $dq$ 轉換為角度微元 $Rd\theta$。
    3.  **極限檢驗**：推導完畢後，驗證 $z \to \infty$ 或 $R \to \infty$ 的極限狀況是否符合已知基礎模型（如點電荷或無限平面）。
