# 概要

拉格朗日乘數法 (Lagrange Multipliers) 是一種在有特定**約束條件 (constraint)** 下，尋找多元函數極值（最大值或最小值）的強大數學方法。
當我們想要求解的問題不是在整個定義域上尋找極值，而是被限制在某個曲線、曲面或更高維的子集上時，此方法便能派上用場。

其核心思想是將一個有約束的優化問題，轉換為一個無約束但維度更高的方程組問題。

# 核心概念

要理解拉格朗日乘數法的直觀意義，可以想像一個**登山客**的比喻：

假設函數 $f(x,y)$ 是一張**地形圖**，等高線代表相同的高度。而約束條件 $g(x,y)=c$ 是一條畫在地圖上的**固定路徑**。我們的目標是找出沿著這條路徑能達到的最高點或最低點。

當登山客沿著路徑走到某個局部最高點時，他會發現：在該點，**路徑的方向**與**地形圖等高線的切線方向**是相同的。這意味著，該點的**坡度方向（梯度 $\nabla f$）** 必須與**路徑的法線方向（梯度 $\nabla g$）** 完全平行。換句話說，在極值點上，函數 $f$ 的梯度向量 $\nabla f$ 與約束函數 $g$ 的梯度向量 $\nabla g$ 是平行的。

### 解題步驟
使用拉格朗日乘數法尋找函數 $f(x,y,z)$ 在約束 $g(x,y,z)=c$ 下的極值，通常遵循以下步驟：

1.  **建立方程組**：
    根據梯度平行條件 $\nabla f = \lambda \nabla g$ 和原始約束條件，建立一個方程組。
2.  **求解方程組**：
    解方程組，找出所有可能的**候選點**（受限臨界點）。
3.  **評估候選點**：
    將所有找到的候選點的座標代入原始函數 $f$ 中，計算出對應的函數值。
4.  **確定極值**：
    比較所有候選點的函數值以確定最大值和最小值。如果約束描述的是一個**封閉且有界**的集合，則極值必定存在。

### 應用與限制
- **應用**：拉格朗日乘數法在物理學（如尋找能量最低態）、經濟學（如在預算限制下最大化效益）和工程學（如在材料限制下優化設計）等領域有著廣泛的應用。
- **限制**：此方法的主要挑戰在於**求解方程組**。如果函數 $f$ 和 $g$ 比較複雜，所產生的方程組可能是非線性的，很難甚至不可能找到解析解。在這種情況下，通常需要藉助數值方法來近似求解。

# 結構/要素

一個典型的拉格朗日乘數法問題包含以下三個基本要素：

1.  **目標函數 $f(x, y, \dots)$**：這是我們希望最大化或最小化的函數。
2.  **約束條件 $g(x, y, \dots) = c$**：這是一個或多個方程式，變數必須滿足這些方程式，它定義了問題的邊界或可行域。
3.  **拉格朗日乘數 $\lambda$**：這是一個輔助純量（或多個純量，對於多個約束），它在求解過程中引入，用以表示在極值點處目標函數梯度與約束函數梯度之間的比例關係。

# 原理/推導

### 梯度平行條件
上述的幾何直觀可以用數學語言精確描述。如果函數 $f$ 在約束 $g=c$ 下的極值點是 $(a,b)$，且 $\nabla g(a,b) \neq 0$，那麼在該點必然存在一個純量 $\lambda$（拉格朗日乘數），使得：

$$\nabla f(a,b) = \lambda \nabla g(a,b)$$

這個方程式是拉格朗日乘數法的理論基石。它將幾何上的「平行」關係轉化為代數上的向量方程。對於多變數和多約束的情況，可以定義拉格朗日函數 $L(x, y, \dots, \lambda) = f(x, y, \dots) - \lambda(g(x, y, \dots) - c)$，並通過求解 $\nabla L = 0$ 來找到極值點。

### 拉格朗日乘數 $\lambda$ 的意義
拉格朗日乘數 $\lambda$ 不僅僅是一個輔助計算的工具，它本身也具有重要的經濟學和物理學意義。$\lambda$ 的值近似等於：當約束條件的常數 $c$ **增加一個單位**時，目標函數 $f$ 的極值會**改變多少**。

例如，在經濟學中，如果 $f$ 是利潤，$c$ 是預算，$\lambda$ 就代表「邊際效用」，即每增加一元預算，能帶來多少額外利潤。
