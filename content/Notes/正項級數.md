# 概要 (Overview)
**正項級數 (Positive Series)** 指各項 $a_n \ge 0$ 的級數。其部分和 $S_n$ 必為單調遞增，故其斂散性僅取決於是否有界。

# 核心概念 (Core Concepts)
- **收斂判斷原則**：若部分和數列有上界，則必收斂；無上界則必發散至 $\infty$。
- **必要條件**：$\lim_{n \to \infty} a_n = 0$。若不滿足，級數必發散。

# 結構/要素 (Structure/Elements)
### 常用判別法總表
| 判別法        | 判斷準則                                                                                                   | 適用場景                                                             |
| :--------- | :----------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------- |
| 性質判斷法      | 若$\sum_{n=1}^{\infty}a_{n}$收斂，$\lim_{ n \to \infty }a_{n}=0$，其逆不真(例如$\sum_{n=1}^{\infty} \frac{1}{n}$) | 若$\lim_{ n \to \infty }a_{n}\ne 0$，則$\sum_{n=1}^{\infty}a_{n}$發散 |
| **積分審斂法**  | $\sum a_n \sim \int_1^\infty f(x)dx$                                                                   | $a_n$ 具備對應連續函數形式                                                 |
| **p-級數測試** | $\sum \frac{1}{n^p}, \frac{\ln n}{n^p}, \frac{1}{n(\ln n)^p}$                                          | $p>1$ 收；$p \le 1$ 發。詳細證明見 [[Improper Integrals]]                 |
| **比較判別法**  | 大收則小收；$a_n \ge b_n$ 且 $b_n$ 發散則 $a_n$ 發散                                                               | 具備明顯大小關係時                                                        |
| **極限比較法**  | $\lim \frac{a_n}{b_n} = L \in (0, \infty)$ 同斂散                                                         | 處理多項式分式，忽略低次項                                                    |
| **比值/根值法** | $\rho < 1$ 收；$\rho > 1$ 發                                                                              | 處理階乘 $n!$、次方 $a^n$                                               |

> [!NOTE] 觀念說明
> 1. 比值與根植為同一級數的比較，原理為等比級數的公比 |r| < 1收斂之結論
> 2. 比較法為不同級數之比較，其觀察結果為函數本身之趨性，故只要結論為常數即可判斷

# 原理/推導 (Principles/Derivation)
### 1. 積分審斂法原理 (The Integral Test)
- **原理**：若 $f(x)$ 為 $[k, \infty)$ 上的連續、正值、遞減函數，且 $a_n = f(n)$，則 $\sum a_n$ 收斂當且僅當 $\int_k^\infty f(x)dx$ 收斂。
- **證明簡述**：
  透過面積比較：$\int_1^{n+1} f(x)dx \le \sum_{k=1}^n a_k \le a_1 + \int_1^n f(x)dx$。
  當 $n \to \infty$，積分的有界性直接決定級數的和是否有界。

- **p-Test 之可用性證明**：
  利用積分審斂法，可將三種常見 p-級數基準轉化為瑕積分判定：
  1. $\sum \frac{1}{n^p} \sim \int \frac{1}{x^p} dx$
  2. $\sum \frac{\ln n}{n^p} \sim \int \frac{\ln x}{x^p} dx$
  3. $\sum \frac{1}{n(\ln n)^p} \sim \int \frac{1}{x(\ln x)^p} dx$
  以上三者均在 $p > 1$ 時收斂。具體積分推導與收斂證明見 [[Improper Integrals#原理/推導 (Principles/Derivation)]]。

### 2. 比值法之幾何級數本質
- **證明簡述**：若 $\lim \frac{a_{n+1}}{a_n} = \rho < 1$，則對足夠大的 $n$，有 $a_{n+1} \approx \rho a_n$。這使級數後半段趨近於公比為 $\rho$ 的**幾何級數**。由幾何級數性質知其必收斂。

### 3. 比較法 Limit comparison method
比較法: 已知 $a_{n}\le b_{n}$ ，$\forall n$，則
- 若 $\sum_{n=1}^{\infty}b_{n}$ 收斂， $\sum_{n=1}^{\infty}a_{n}$ 收斂
- 若 $\sum_{n=1}^{\infty}a_{n}$ 發散， $\sum_{n=1}^{\infty}b_{n}$ 發散

>用函數圖形想像很好理解

以上論述之實用形式即為極限比較法: 
已知 $\sum_{n=1}^{\infty}a_{n}$、 $\sum_{n=1}^{\infty}b_{n}$ 均為正向級數，且 $\lim_{ n \to \infty } \frac{a_{n}}{b_{n}}=L$
1. $0<L<\infty$，兩級數斂散性相同
2. $L=0$，表示 $a_{n}\le b_{n}$ ，由定理三之結論決定斂散
3. $L=\infty$，表示 $a_{n}\ge b_{n}$ ，由定理三之結論決定斂散
