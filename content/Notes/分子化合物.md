# 概要
分子化合物由獨立的分子單元組成，通常由兩種或多種非金屬元素透過共價鍵結合而成。

# 性質
- **成鍵**: 原子間透過共價鍵 (Covalent Bonds) 共享電子。
- **導電性**: 在任何狀態下（固態、液態、氣態）通常都不導電，因為沒有自由移動的電荷。
- **熔點與沸點**: 相對較低，因為分子間作用力（Intermolecular Forces）比離子鍵弱。
- **狀態**: 在室溫下可能為固態、液態或氣態。

# 英文命名規則
適用於由兩種非金屬元素組成的二元分子化合物。主要有兩種命名系統。

### 規則一：希臘前綴系統 (Greek Prefix System)
這是最常見的命名法。
1.  **第一個元素**: 按其在化學式中的順序命名，使用完整的元素名稱。
2.  **第二個元素**: 將元素名稱的字尾改為 **-ide**。
3.  **使用希臘數字前綴**: 用希臘前綴 (Greek Prefixes) 來表示每種元素的原子數量。

**命名注意事項**:
- 如果第一個元素只有一個原子，則省略 `mono-` 前綴。
- 當前綴的結尾元音 (o 或 a) 與元音開頭的元素名稱 (如 oxide) 相遇時，通常會省略前綴的元音以簡化發音 (例如，`mono-oxide` → `monoxide`)。
- 含有氫的分子化合物通常使用俗名 (Common Names)，不遵循此規則 (如 $H_2O$ 是 water，$NH_3$ 是 ammonia)。

### 規則二：羅馬數字系統 (Stock System)
這種方法類似於離子化合物的命名，較少用於分子化合物，但在某些情況下也會使用。
1.  **第一個元素**: 視為陽離子，使用其元素名稱，並在後面用 **羅馬數字括號** 標示其氧化數 (Oxidation State)。
2.  **第二個元素**: 視為陰離子，將字尾改為 **-ide**。
