# 概要
穩定流（Steady Flow），或稱穩流，是流體力學中的一種流動狀態。其核心特徵為：在流場中**任何一個固定點**，流體的所有性質（如速度、壓力、密度）都不會隨時間的推移而改變。與之相對的是非穩定流（Unsteady Flow），其性質會隨時間變化。

# 核心概念
- **時間不變性 (Time Invariance)**: 這是穩定流的根本定義。從數學上看，在一個固定的空間點上，任何流體性質對時間的偏導數都為零。
- **歐拉描述 (Eulerian Description)**: 穩定流是在歐拉視角下定義的，即我們觀察的是空間中的固定點，而非追蹤單個流體粒子（拉格朗日描述）。在穩定流中，雖然每個粒子自身的速度會因為位置改變而改變，但在任一固定點，後續粒子流經該點時的速度都與前一粒子相同。
- **流線、跡線與煙線 (Streamlines, Pathlines, and Streaklines)**: 在穩定流中，這三種描述流動路徑的線是完全重合的。流線（Streamline）代表在某一瞬間，流體速度場的切線方向，描繪了流動的瞬時模式。因為在穩定流中這個模式不隨時間改變，所以它也同時代表了單一粒子走過的實際路徑（跡線, Pathline）。

# 結構/要素
- **數學條件**:
  對於流場中的任何性質（此處以速度 `v`、壓力 `P`、密度 `ρ` 為例），其對時間 `t` 的偏微分等於零：
  $$\frac{\partial \vec{v}}{\partial t} = 0, \quad \frac{\partial P}{\partial t} = 0, \quad \frac{\partial \rho}{\partial t} = 0$$
- **與其他流動類型的關係**:
    - **穩態層流 (Steady Laminar Flow)**: 指流體平滑、分層流動，且各點速度恆定。例如，低速流經長直管道的黏性流體（如泊肅葉定律所描述的流動）。
    - **穩態紊流 (Steady Turbulent Flow)**: 紊流（或稱湍流）本質上是高度不穩定的，其速度在任何點都有快速、隨機的脈動。但在工程上，如果這些脈動的**時間平均值**保持不變（例如，平均速度、平均壓力恆定），則該流動可被視為「統計意義上的穩定流」。

# 原理/推導
穩定流的假設大大簡化了流體力學分析，特別是守恆定律的應用。
- **守恆定律的簡化**: 在分析穩定流時，質量、動量和能量守恆方程式中與時間相關的項 ($\partial/\partial t$) 均為零。
  - **範例（質量守恆）**: 對於密度不變（不可壓縮）的流體，在穩定流中應用質量守恆，可推導出**連續性方程式**。在一個管徑變化的管道中（對應您筆記中的「不同管徑」），此方程式簡化為：
    $$A_1 v_1 = A_2 v_2$$
    這表示流速與管道截面積成反比。
- **應用實例**:
    - **工程設計**: 常用於分析和設計飛機機翼、水壩、橋墩周圍的穩定流場，以及評估管道內的壓力損失。
    - **生物力學**:
        - **大動脈 (Aorta)**: 雖然心臟的搏動使大動脈中的血流本質上是非穩定流，但在進行宏觀分析或評估一個心跳週期內的平均效應時，有時會將其近似為穩定流。
        - **微血管 (Capillary)**: 由於流速極低且管徑極小，血球在微血管中的流動更接近於穩定的層流（泊肅葉流）。
