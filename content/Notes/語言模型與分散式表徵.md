# 語言模型
*language model*，使用生語料庫計算特定文章表現或單詞出線機率的模型，NLP中最基本且重要的模型
- 二元語言模型 *bigram language model* ^c86051
	- 根據前一個字詞計算下一個字詞的可能性
	- 分散式表徵、[[BERT]]、GPT-3、文章生成...

# 特徵與向量
- 編碼 *encode*
	- 依特定規則，將資料特徵轉換為電腦可辨識之向量(具有方向與大小之量)
	- 維度:表示向量之座標軸

# 獨熱編碼
*one-hot encode*
>對於每一個類別特徵的每一個可能取值，分配一個唯一的二進位向量，且在這個向量中，只有一個位置為1，其餘皆為0

## 原理
- 假設某個特徵有N種可能的取值，則用N位的二進位向量來表示(通常為文章出現的語彙數)
- 每一種取值對應的向量中，僅有一個位置為1（代表該類別），其餘位置為0
- 這樣的表示方式確保了不同類別之間沒有數值上的大小或順序關係，避免了模型誤解分類特徵的數值意義

## 特點
- 可變長度編碼 *variable length encode*: 編碼長度與語彙數成正比，數量一多會造成電腦負擔
- 產生的特徵向量稀疏（大多數元素為0），但能被大多數機器學習算法直接處理
# 分散式表徵
*distributed representation*
>為解決[[#獨熱編碼]]長度過長而發展出的想法

- 分散假說 *distributional hypothesis* : 相似脈絡中的兩個單詞具有相似意義
e.g. 餅乾非常**美味**... 與 拉麵非常**好吃**...
- 固定長度編碼
- 詞嵌入 *word embedding* : 將單詞嵌入固定長度的向量空間
![[分散式表徵示意圖.png|600]]

## 連續詞袋模型
*CBOW*
- 使用神經網路進行學習，調整中間層的參數
	- 輸入層: 單詞轉換為獨熱編碼
	- 中間層: 轉換為固定長度之向量
	- 輸出層: 單詞的出現機率

> [!NOTE] 單詞分類
> - 目標詞 *target word* :  要預測的單詞
> - 語境詞 *context word* : 目標詞附近出現的詞
## 連續跳躍式模型
*Skip-gram*
- 與CBOW相反，以目標詞推算語境詞出現的機率
>推薦使用的軟體
>- word2vec 與 gensim library (函式庫^[將具有特定功能的程式定型化，供其他程式調用的檔案])

# 分散式表徵的優點
- 計算單詞之間的相似度
	- 向量夾角越小，相似度越高
	- 餘弦相似性 *cosine similarity* : 向量夾角轉換為餘弦值以判斷相似度
- 以單詞進行數學運算: 向量的加減法...
![[單詞分散式表徵的數學運算示意圖.png|700]]
- 作為NLP多個任務的輸入資訊
# 分散式表徵的應用
- 以[[什麼是非監督式學習#^fa6942|k-means]]法為相似文章做解析
	1. 對第一篇文章做單詞分割(語素分析)
	2. 用分散式表徵對單詞作向量化
	3. 計算文章所有單詞的向量平均值
	4. 對其餘文章做相同處理
	5. 以k-means法分群
