# 1. 導論 (Introduction & Background)

空間曲線 (Space Curve) 是由單變數向量函數 $\vec{r}(t)$ 所描述的點集合。透過微積分工具，我們可以精確量化曲線的幾何特性，其中最重要的兩個量化指標為描述長度的 **弧長 (Arc Length)** 與描述彎曲程度的 **曲率 (Curvature)**。

# 2. 核心 (Core Framework)

- **弧長元素 (Arc Length Element):**
  $$ds = |d\vec{r}| = |\dot{\vec{r}}(t)| dt = \sqrt{\dot{x}^2 + \dot{y}^2 + \dot{z}^2} dt$$
- **單位切線向量 (Unit Tangent Vector):**
  $$\vec{u}(t) = \frac{\dot{\vec{r}}(t)}{|\dot{\vec{r}}(t)|}, \quad |\vec{u}(t)| = 1$$
- **曲率定義 (Definition of Curvature):**
  $$\kappa(s) = \left| \frac{d\vec{u}}{ds} \right|$$
- **曲率半徑 (Radius of Curvature):**
  $$\rho = \frac{1}{\kappa}$$

# 3. 邏輯 (Operational Logic)

### 3.1 弧長元素 $ds$ 之推導
位移向量 $d\vec{r}$ 可以表示為對參數 $t$ 的微分：
$$d\vec{r} = \frac{d\vec{r}}{dt} dt = \dot{\vec{r}}(t) dt$$
由於弧長 $s$ 代表路徑長度，其微小變化量 $ds$ 等於位移向量的模長：
$$ds = |d\vec{r}| = |\dot{\vec{r}}(t) dt| = |\dot{\vec{r}}(t)| dt$$
若展開向量分量 $\vec{r}(t) = \langle x(t), y(t), z(t) \rangle$，則：
$$ds = \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2 + \left(\frac{dz}{dt}\right)^2} dt = \sqrt{\dot{\vec{r}} \cdot \dot{\vec{r}}} dt$$

### 3.2 曲率 $\kappa$ 之公式推導
曲率定義為單位切線向量對弧長的變化率大小。利用連鎖律 (Chain Rule) 將其轉換為對參數 $t$ 的運算：
$$\kappa = \left| \frac{d\vec{u}}{ds} \right| = \left| \frac{d\vec{u}/dt}{ds/dt} \right| = \frac{|\dot{\vec{u}}(t)|}{|\dot{\vec{r}}(t)|}$$

若要直接由 $\vec{r}(t)$ 及其導數表示，推導如下：
1. 由於 $\dot{\vec{r}} = |\dot{\vec{r}}| \vec{u} = \frac{ds}{dt} \vec{u} = \dot{s} \vec{u}$
2. 對其再微分：$\ddot{\vec{r}} = \ddot{s} \vec{u} + \dot{s} \dot{\vec{u}}$
3. 計算外積：$\dot{\vec{r}} \times \ddot{\vec{r}} = (\dot{s} \vec{u}) \times (\ddot{s} \vec{u} + \dot{s} \dot{\vec{u}}) = \dot{s}^2 (\vec{u} \times \dot{\vec{u}})$
4. 取模長：$|\dot{\vec{r}} \times \ddot{\vec{r}}| = \dot{s}^2 |\vec{u}| |\dot{\vec{u}}| \sin(90^\circ) = \dot{s}^2 |\dot{\vec{u}}|$ (註：因 $\vec{u} \cdot \vec{u} = 1 \implies \vec{u} \cdot \dot{\vec{u}} = 0$)
5. 代入 $\kappa = \frac{|\dot{\vec{u}}|}{\dot{s}}$，得出：
$$\kappa(t) = \frac{|\dot{\vec{r}}(t) \times \ddot{\vec{r}}(t)|}{|\dot{\vec{r}}(t)|^3}$$

# 4. 應用與脈絡 (Application & Context)

- **幾何直觀:** 曲率越大，表示單位路徑內切線方向改變越劇烈。
- **特殊曲線:**
    - **圓 (Circle):** $\vec{r}(t) = \langle a\cos t, a\sin t, 0 \rangle \implies \kappa = 1/a$。
    - **螺旋線 (Helix):** $\vec{r}(t) = \langle a\cos t, a\sin t, bt \rangle \implies \kappa = \frac{a}{a^2+b^2}$。
