# 概要
離子化合物由陽離子 (Cations) 和陰離子 (Anions) 透過靜電引力（離子鍵）結合而成。通常是金屬元素與非金屬元素的組合，或是由多原子離子構成。

# 性質
- **成鍵**: 陽離子與陰離子之間的離子鍵 (Ionic Bonds)。
- **導電性**: 固態時不導電，但在熔融狀態或溶於水中時可以導電，因為離子可以自由移動。
- **熔點與沸點**: 非常高，因為需要巨大能量才能克服強大的離子鍵。
- **狀態**: 在室溫下通常是堅硬、易碎的晶體固體 (Crystalline Solids)。

# 英文命名規則
離子化合物的命名核心是 **先陽離子，後陰離子**。

### 規則一：固定電荷金屬 (Type I)
適用於陽離子只有一種固定電荷的金屬（如第 1 族、第 2 族、Al, Zn, Ag, Cd）。
1.  **陽離子 (Cation)**: 使用金屬的完整元素名稱。
2.  **陰離子 (Anion)**: 如果是單原子陰離子，將非金屬元素的字尾改為 **-ide**；如果是多原子陰離子，直接使用其名稱。

### 規則二：可變電荷金屬 (Type II)
適用於陽離子可以形成多種不同電荷的金屬（如大多數過渡金屬）。有兩種命名系統並存：

#### A. 現代命名法 (Stock System)
1.  **陽離子 (Cation)**: 使用金屬的元素名稱，並在後面緊跟一個 **羅馬數字的括號**，表示其電荷數。
2.  **陰離子 (Anion)**: 規則同上。

#### B. 傳統命名法 (Traditional System)
1.  **陽離子 (Cation)**: 使用金屬名稱的拉丁文字根，並根據電荷高低加上不同字尾：
    -   **-ous**: 用於表示 **較低** 的電荷。
    -   **-ic**: 用於表示 **較高** 的電荷。
2.  **陰離子 (Anion)**: 規則同上。

### 規則三：含有多原子離子的化合物
命名方式與前兩類相似，但陽離子或陰離子（或兩者）是多原子離子時，直接使用該多原子離子的名稱。

# 例子

| 化學式 | 類型 | 英文名稱 (Stock) | 英文名稱 (Traditional) | 中文名稱 |
| :---: | :---: | :---: | :---: | :---: |
|  NaCl | Type I | Sodium Chloride | - | 氯化鈉 |
| $CaBr_2$ | Type I | Calcium Bromide | - | 溴化鈣 |
| $FeCl_2$ | Type II | Iron(II) Chloride | Ferrous Chloride | 氯化亞鐵 |
| $FeCl_3$ | Type II | Iron(III) Chloride | Ferric Chloride | 氯化鐵 |
| $Cu_2O$ | Type II | Copper(I) Oxide | Cuprous Oxide | 氧化亞銅 |
| $CuO$ | Type II | Copper(II) Oxide | Cupric Oxide | 氧化銅 |
| $NH_4Cl$ | Polyatomic | Ammonium Chloride | - | 氯化銨 |
| $KNO_3$ | Polyatomic | Potassium Nitrate | - | 硝酸鉀 |
