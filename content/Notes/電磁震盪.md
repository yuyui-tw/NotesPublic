# 1. 導論 (Introduction & Background)

**電磁震盪 (Electromagnetic Oscillations)** 指的是電路中電荷與電流隨時間發生週期性變化的現象。最基本的模型是 **LC 電路**（包含電感與電容），在忽略電阻的情況下，能量會在電容的電場與電感的磁場之間反覆轉換，其物理機制與力學中的 **[[Simple Harmonic Motion|簡諧運動 (SHM)]]** 完全類比。

當電路中包含電阻（**RLC 電路**）時，系統能量會以熱能形式耗散，產生類似於力學阻尼運動的 **阻尼震盪**。

# 2. 核心 (Core Framework)

### 2.1 LC 電路：無阻尼震盪
![[LC Circuit.png]]
電荷 $q(t)$ 滿足二階線性齊次微分方程：
$$L \frac{d^2q}{dt^2} + \frac{1}{C}q = 0 \implies \frac{d^2q}{dt^2} + \omega^2 q = 0$$
- **自然角頻率 (Natural Angular Frequency)**：
  $$\omega = \frac{1}{\sqrt{LC}}$$
- **電荷與電流隨時間之變化**：
  - $q(t) = Q_{max} \cos(\omega t + \phi)$
  - $i(t) = \frac{dq}{dt} = -\omega Q_{max} \sin(\omega t + \phi) = -I_{max} \sin(\omega t + \phi)$

### 2.2 RLC 電路：阻尼震盪
![[RLC Circuit.png]]
引入電阻 $R$ 後，方程式變為：
$$L \frac{d^2q}{dt^2} + R \frac{dq}{dt} + \frac{1}{C}q = 0$$
系統表現取決於阻尼係數：
- **欠阻尼 (Underdamped)**：$R^2 < 4L/C$，電荷呈指數衰減的震盪。
- **臨界阻尼 (Critically Damped)**：$R^2 = 4L/C$，系統最快回到平衡狀態且不震盪。
- **過阻尼 (Overdamped)**：$R^2 > 4L/C$，電荷緩慢回歸平衡且不震盪。

### 2.3 系統總能量
在 LC 電路中，總能量 $U$ 為電場能與磁場能之和，且保持守恆：
$$U = U_E + U_B = \frac{q^2}{2C} + \frac{1}{2} L i^2 = \frac{Q_{max}^2}{2C}$$

### 2.4 RLC 交流電路與共振 (Resonance in Driven RLC Circuits)
當 RLC 電路接上交流電源（驅動頻率為 $\omega_d$）時，系統的阻抗 $Z$ 與相位角會隨頻率改變。根據感抗 $X_L = \omega_d L$ 與容抗 $X_C = 1/(\omega_d C)$ 的相對大小，可分為三種情況：

1. **感性為主 ($X_L > X_C$)**：驅動頻率高於共振頻率，電壓相位領先電流($\omega > \frac{1}{\sqrt{ LC }},\phi > 0$)。
2. **容性為主 ($X_L < X_C$)**：驅動頻率低於共振頻率，電流相位領先電壓($\omega < \frac{1}{\sqrt{ LC }},\phi < 0$)。
3. **共振狀態 ($X_L = X_C$)**：
   - **條件**：驅動角頻率 $\omega_d$ 等於系統自然角頻率 $\omega_0 = 1/\sqrt{LC}$。
   - **特性**：
     - 電壓與電流**同相 (In-phase)**($\phi=0$)。
     - 系統**阻抗最小** ($Z = R$)。
     - **電流達到峰值**。

# 3. 邏輯 (Operational Logic)

### 3.1 電磁與力學之物理類比
電磁震盪的數學結構與力學振子完全一致，各物理量對應如下：

| 電磁系統 (LC/RLC Circuit) | 力學系統 (Mass-Spring System) |
| :--- | :--- |
| 電荷 $q$ | 位移 $x$ |
| 電流 $i = dq/dt$ | 速度 $v = dx/dt$ |
| 電感 $L$ | 質量 $m$ (慣性) |
| 電容倒數 $1/C$ | 彈性係數 $k$ |
| 電阻 $R$ | 阻尼係數 $b$ |
| 電池電動勢 $\mathcal{E}$ | 驅動力 $F(t)$ |
| 電場能 $q^2/2C$ | 彈性位能 $kx^2/2$ |
| 磁場能 $Li^2/2$ | 動能 $mv^2/2$ |

### 3.2 能量轉換機制
1.  **$q = Q_{max}$ ($i = 0$)**：能量全部儲存於電容器的電場中。
2.  **$q$ 減小，$i$ 增加**：電容放電，電場能轉化為電感的磁場能。
3.  **$q = 0$ ($i = I_{max}$)**：能量全部儲存於電感器的磁場中。
4.  **$i$ 減小，$q$ 反向增加**：磁場能轉化回電場能。

# 4. 應用與脈絡 (Application & Context)

- **無線電通訊**：LC 電路作為接收器的「調諧電路 (Tuning Circuit)」，藉由改變 $L$ 或 $C$ 使自然頻率與目標電台頻率發生共振。
- **訊號濾波**：RLC 電路可用於選擇特定頻率的訊號或抑制雜訊。
