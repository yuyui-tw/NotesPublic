# 注意力機制
*attention mechanism*
- 為解決[[遞歸神經網路#Seq2Seq|Seq2Seq]]因為以固定長度向量產生模型**處理長文本之精度低下**的問題
	- 固定長度之向量，長文句容易被壓縮
- 注意力參數: 用文字出現的機率表示為其對文章的重要程度
- 脈絡參數 *context vector* : 單字參數的權重總和，代表整個文章的脈絡傾向
	![[加入注意力機制的Seq2Seq.png|600]]

# 自注意力機制
*self-attention*
- 關注**單詞自己與文章的關係**，可以讓模型處理[[NLP的模糊與困難#^80d868|回指關係]]
- 可以平行運算
- 以向量計算相似度([[語言模型與分散式表徵#分散式表徵的優點]])
	- query 參照詞
	- key 比較詞
	- value 乘數

# Transformer
- 具有[[#自注意力機制]]的模型，縮短計算時間
- 機器翻譯、圖像分類、語意分割、動作辨識、聲音辨識、預測蛋白質立體結構
- [[遞歸神經網路#^848a38|encoder-decoder]]之一

![[Transformer 結構圖.png|400]]

- 位置編碼 *Positional Encoding, PE*
利用正弦函數(sin)和餘弦函數(cos)將文章中的單詞順序向量化，以處理單詞位置的資訊
能夠保存原始語言文章和目標語言文章的各單詞順序資訊
![[位置編碼示意圖.png|500]]
