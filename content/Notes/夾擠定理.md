# 夾擠定理 (Squeeze Theorem)

## 定理敘述
若在一個包含點 $c$ 的開區間 $I$ 中，對於所有 $x\in I$（可能 $x=c$ 除外），函數 $f(x), g(x), h(x)$ 滿足以下條件：

1.  $f(x)\le g(x) \le h(x)$
2.  $\lim_{x 	\to c} f(x) = \lim_{x 	\to c} h(x) = L$

則結論為：
$$
\lim_{x\to c} g(x) = L
$$

## 證明
根據極限的 $\varepsilon-\delta$ 定義，對於任意給定的 $\varepsilon > 0$：

-   因為 $\lim_{x 	\to c} f(x) = L$，所以存在 $\delta_1 > 0$，使得當 $0 < |x - c| < \delta_1$ 時，有 $L - \varepsilon < f(x) < L + \varepsilon$。
-   同樣地，因為 $\lim_{x 	\to c} h(x) = L$，所以存在 $\delta_2 > 0$，使得當 $0 < |x - c| < \delta_2$ 時，有 $L - \varepsilon < h(x) < L + \varepsilon$。

取 $\delta = \min(\delta_1, \delta_2)$。則當 $0 < |x - c| < \delta$ 時，上述兩個條件同時成立。

結合已知條件 $f(x)\le g(x)\le h(x)$，可得不等式鏈：
$$ 
L - \varepsilon < f(x)\le g(x)\le h(x) < L + \varepsilon
$$
由此可知：
$$ 
L - \varepsilon < g(x) < L + \varepsilon
$$ 
這等價於 $|g(x) - L| < \varepsilon$。

因此，我們證明了對於任意 $\varepsilon > 0$，都存在一個 $\delta > 0$，使得當 $0 < |x - c| < \delta$ 時 $|g(x) - L| < \varepsilon$ 恆成立。故：
$$ 
\lim_{x \to c} g(x) = L
$$ 

## 直觀解釋
此定理可形象地理解為：若函數 $g(x)$ 被「夾」在兩個趨向同一極限 $L$ 的函數 $f(x)$ 和 $h(x)$ 之間，那麼 $g(x)$ 也必然趨向該極限 $L$。
