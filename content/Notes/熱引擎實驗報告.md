## 一、摘要 (Abstract)

本實驗旨在探討熱引擎循環過程及其熱機效率。透過將鋁瓶交替浸泡於熱水（$T_H \approx 318.54\text{ K}$）與冷水（$T_C \approx 286.15\text{ K}$）中，並透過重物加壓模擬等壓與等溫過程。實驗依據熱力學第一定律與理想氣體狀態方程，計算氣體在循環中的總吸熱量 $Q_H$ 與總淨功 $W_{total}$。實驗測得實際效率 $e_{act} = 6.79\%$，相對於理論卡諾效率 $e_{theo} = 10.03\%$，誤差率為 $32.29\%$。誤差主要源於活塞與氣缸間的摩擦力、系統熱量散失以及非理想狀態下的路徑偏差。

## 二、簡介 (Introduction)

熱引擎是一種能將熱能連續轉化為機械功的熱力學系統。在熱力學發展史上，卡諾循環定義了熱機效率的理論上限，而實際熱機則受限於各種不可逆因素。本實驗利用簡易的熱機裝置，結合壓力與位移感應器，即時觀測氣體在 $P-V$ 圖上的循環路徑。透過量化分析等壓膨脹、等溫膨脹、等壓收縮與等溫壓縮等四個階段的能量轉換，我們得以深入理解熱力學第一定律在循環過程中的應用，並評估實際機械裝置中的能量損耗。

## 三、實驗理論 (Experimental Theory)

### 1. 熱力學基礎
根據熱力學第一定律：$\Delta U = Q - W$。其中 $U$ 為內能，$Q$ 為吸收熱量，$W$ 為對外作功。
對於理想氣體，內能變化 $\Delta U = n C_v \Delta T$。在本實驗中，空氣視為雙原子分子，定容莫耳比熱 $C_v = \frac{5}{2}R$，定壓莫耳比熱 $C_p = \frac{7}{2}R$。

>**補充說明**：
>空氣之比熱比 $\gamma = C_p/C_v \approx 1.4$，反映了雙原子分子在常溫下的 5個自由度。
>此數值決定了絕熱過程與等溫過程在 $P-V$ 圖上的斜率差異，$\gamma$ 愈大則絕熱曲線愈陡。

### 2. 循環路徑與公式推導
本實驗循環包含四個階段（A $\to$ B $\to$ C $\to$ D $\to$ A），其公式推導如下：

#### (1) 等溫過程 (Isothermal Process): A $\to$ B 與 C $\to$ D
在等溫過程中，溫度保持不變 ($\Delta T = 0$)。
- **內能不變**：根據理想氣體內能公式 $\Delta U = n C_v \Delta T$，當 $\Delta T = 0$ 時，$\Delta U = 0$。
- **功與熱量關係**：由熱力學第一定律 $\Delta U = Q - W$，可知 $Q = W$。
- **作功推導**：
  根據功的定義 $W = \int_{V_i}^{V_f} P \, dV$，代入理想氣體方程 $P = \frac{nRT}{V}$：
  $$W = \int_{V_i}^{V_f} \frac{nRT}{V} \, dV = nRT \int_{V_i}^{V_f} \frac{1}{V} \, dV = nRT \ln\left(\frac{V_f}{V_i}\right)$$
  在本實驗中，利用 $nR = \frac{PV}{T}$，公式可寫為 $W = PV \ln\left(\frac{V_f}{V_i}\right)$。

#### (2) 等壓過程 (Isobaric Process): B $\to$ C 與 D $\to$ A
在等壓過程中，壓力保持不變 ($\Delta P = 0$)。
- **吸熱量推導**：
  根據定壓比熱定義，在恆壓下吸收的熱量為 $Q_p = n C_p \Delta T$。
  對於雙原子分子（如空氣），定壓莫耳比熱 $C_p = C_v + R = \frac{5}{2}R + R = \frac{7}{2}R$。
- **實驗公式應用**：
  將 $C_p = \frac{7}{2}R$ 代入吸熱公式，並利用參考點（如狀態 D）的氣體狀態推算 $nR = \frac{P_D V_D}{T_D}$：
  $$Q_{B \to C} = n \left(\frac{7}{2}R\right) (T_C - T_B) = \frac{7 P_D V_D}{2 T_D} (T_C - T_B)$$
- **作功計算**：
  等壓作功為 $W = P \Delta V$。在 B $\to$ C 膨脹過程中，氣體對外做正功；在 D $\to$ A 收縮過程中，氣體對外做負功。

### 3. 效率定義
- **理論卡諾效率**：僅取決於冷熱庫溫差。
  $$e_{theo} = \left( 1 - \frac{T_C}{T_H} \right) \times 100\%$$
- **實際效率**：定義為循環淨功與總吸熱量之比。
  $$e_{act} = \frac{|W_{total}|}{Q_{BC} + Q_{CD}} \times 100\%$$
  其中 $W_{total} = W_{AB} + W_{BC} + W_{CD} + W_{DA}$。

## 四、實驗 (Experiment)

### 1. 儀器清單與架設
- 熱機實驗組（含活塞與位移感應器）
- 壓力感應器與 Data Studio 介面
- 200g 法碼、鋁瓶及連接管
- 熱水槽、冷水槽與溫度計

### 2. 實驗流程
1. 將鋁瓶連同感應器歸零。
2. 鋁瓶置於冷水，放置法碼（A $\to$ B）。
3. 移至熱水，觀察活塞上升（B $\to$ C）。
4. 移除法碼，活塞進一步上升（C $\to$ D）。
5. 移回冷水，活塞回到原點（D $\to$ A）。
6. 紀錄各點壓力、體積與溫度數據。

## 五、結果與討論 (Results and Discussion)

### 1. 實驗數據彙整 (G8 數據)
根據實驗數據表計算，關鍵數值如下：

| 狀態點 | 壓力 $P$ (Pa) | 體積 $V$ ($m^3$) | 溫度 $T$ (K) |
| :--- | :--- | :--- | :--- |
| **A** | 99800 | 0.000184466 | 286.15 |
| **B** | 101500 | 0.000184475 | 286.60 |
| **C** | 104400 | 0.000184480 | 318.54 |
| **D** | 102100 | 0.000184475 | 317.97 |

**能量計算結果：**
- **總吸熱量 $Q_H (Q_{BC}+Q_{CD})$**：$6.6214 \text{ J}$
- **循環分段功：**
    - $W_{AB} = 0.0009 \text{ J}$
    - $W_{BC} = 6.6219 \text{ J}$
    - $W_{CD} = -0.0005 \text{ J}$
    - $W_{DA} = -7.0718 \text{ J}$
- **總淨功 $W_{total}$**：$-0.4495 \text{ J}$ (取絕對值進行效率計算)
- **實際效率 $e_{act}$**：$6.79\%$
- **理論卡諾效率 $e_{theo}$**：$10.03\%$
- **相對誤差**：**$32.29\%$**

### 2. 系統誤差與討論
本實驗誤差率為 $32.29\%$，相對於一般熱機實驗屬合理範圍。系統誤差分析如下：

1. **非理想路徑偏差**：
	移除法碼 (C $\to$ D) 過程中，若操作速度過快，氣體行為將由等溫 ($P \propto V^{-1}$) 轉向絕熱 ($P \propto V^{-1.4}$)。由於絕熱指數 $\gamma=1.4$ 大於 1，這會導致壓力下降過快，縮減循環包圍面積，是造成實際效率低於預期的重要物理因素。 
2. **活塞摩擦力 (Mechanical Friction)**：
    活塞與氣缸壁之間的靜摩擦力與動摩擦力是能量損耗的主因。在 $D \to A$ 的等壓收縮過程中，氣體必須克服摩擦力才能帶動活塞下降，這導致 $W_{DA}$ 的絕對值顯著大於膨脹功，造成淨功減少。
3.  **熱量散失與非理想過程 (Heat Loss & Irreversibility)**：
    理論假設 B $\to$ C 與 D $\to$ A 為等壓過程，但實際移動鋁瓶時，連接管暴露於環境溫度中，導致氣體在熱交換完成前即發生壓力波動。此外，C $\to$ D 的等溫膨脹在實際操作中因移除法碼速度較快，往往偏向絕熱膨脹，導致實際 $P-V$ 路徑與理論曲線偏離。
4.  **熱傳導滯後 (Thermal Lag)**：
    鋁瓶與水槽間的熱傳導需要時間。若氣體未完全達到 $T_H$ 或 $T_C$ 即開始下一階段，會導致循環面積縮小，降低實際效率。
5.  **氣密性與活塞漏氣**：
    系統連接處的微小漏氣會造成循環中莫耳數 $n$ 的改變。計算顯示各狀態點的 $PV/RT$ 存在微小變動，這直接影響了利用狀態點 D 作為基準計算熱量的準確性。

## 六、結論 (Conclusion)

本實驗透過精密感應器監控氣體循環，成功計算出實際效率為 $6.79\%$，並驗證其受限於卡諾效率 $10.03\%$。雖然系統存在顯著的摩擦力與熱散失，但透過完整包含 $W_{DA}$ 的總功計算及手冊建議的熱力學模型，實驗結果能有效模擬實際熱引擎的能量轉換過程。

**改進建議**：
1. **強化氣密性**：實驗前應使用肥皂水檢查連接管處是否有漏氣。
2. **潤滑優化**：清潔氣缸並使用極少量低黏度潤滑油，減少摩擦力對作功的干擾。
3. **穩定溫差**：確保冷熱水槽體積充足，以維持實驗過程中的溫度穩定性。
