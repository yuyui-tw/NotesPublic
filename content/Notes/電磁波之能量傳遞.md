# 電磁波之能量傳遞 (Energy Transport of EM Waves)

電磁波在真空中或介質中傳播時，不僅僅是場的震盪，更伴隨著能量與動量的搬運。這種能量傳遞的機制是無線通訊、光學現象及輻射熱傳導的物理基礎。

---

## 1. 電磁波總能量密度 (Total Energy Density)

電磁場在空間中儲存的總能量密度 $u$ 是電場能量密度 $u_E$ 與磁場能量密度 $u_B$ 的總和。

### 1.1 組成部分
根據 **[[電容器之儲能]]** 與 **[[電感器]]** 的結論：
- **電場能量密度**：$u_E = \frac{1}{2} \varepsilon_0 E^2$
- **磁場能量密度**：$u_B = \frac{1}{2\mu_0} B^2$

### 1.2 瞬間能量密度的對等性
在 **[[電磁波方程式|電磁波方程]]** 中，我們已知在真空中電場與磁場振幅滿足 $E = cB$，且 $c = 1/\sqrt{\mu_0 \varepsilon_0}$。
代入磁場能量密度：
$$u_B = \frac{1}{2\mu_0} \left( \frac{E}{c} \right)^2 = \frac{1}{2\mu_0} \frac{E^2}{1/(\mu_0 \varepsilon_0)} = \frac{1}{2} \varepsilon_0 E^2 = u_E$$
這證明了在電磁波中，**能量是平均分配在電場與磁場中的**。

### 1.3 總能量密度公式
因此，總能量密度 $u$ 可表示為：
$$u = u_E + u_B = \varepsilon_0 E^2 = \frac{B^2}{\mu_0} = \sqrt{\frac{\varepsilon_0}{\mu_0}} EB$$

## 2. 能量流率：坡印廷向量 (Poynting Vector)

為了描述能量傳遞的「流動」概念，我們定義能量流率 $S$ 為：垂直於波前方向，每單位時間通過單位面積的能量。

### 2.1 推導過程
考慮電磁波在 $dt$ 時間內通過面積 $A$，前進距離 $dx = c dt$：
1. 通過該面積的微元能量 $dU = u \cdot dV = u \cdot (A \cdot c dt)$。
2. 能量流率 $S$ 定義為功率密度(單位面積內之能量傳送速率)：
   $$S = \frac{1}{A} \frac{dU}{dt} = u \cdot c$$
3. 代入 $u = \sqrt{\frac{\varepsilon_0}{\mu_0}} EB$ 及 $c = \frac{1}{\sqrt{\mu_0 \varepsilon_0}}$：
   $$S = \left( \sqrt{\frac{\varepsilon_0}{\mu_0}} EB \right) \left( \frac{1}{\sqrt{\mu_0 \varepsilon_0}} \right) = \frac{EB}{\mu_0}$$

### 2.2 向量形式
為了同時描述能量流動的方向，引入 **坡印廷向量 (Poynting Vector) $\mathbf{S}$**：
$$\mathbf{S} = \frac{1}{\mu_0} \mathbf{E} \times \mathbf{B}$$
- **大小**：即為上述的能量流率（單位：$\text{W/m}^2$）。
- **方向**：由右手定則確定，與電磁波的傳播方向一致。

## 3. 電磁波強度 (Intensity)

由於電磁波（如可見光）的頻率極高，場強 $E$ 與 $B$ 隨時間快速起落，實驗量測通常關注的是坡印廷向量的 **時間平均值**，稱為 **電磁波強度 ($I$)**。

對於正弦平面電磁波：
$E = E_m \sin(kx - \omega t)$
$B = B_m \sin(kx - \omega t)$

### 3.1 計算平均值
$$I = S_{avg} = \frac{1}{\mu_0} [E B]_{avg} = \frac{E_m B_m}{\mu_0} [\sin^2(kx - \omega t)]_{avg}$$
由於 $\sin^2$ 在一個週期內的平均值為 $1/2$：
$$I = \frac{E_m B_m}{2\mu_0}$$

### 3.2 常用表示式
利用 $E_m = c B_m$：
$$I = \frac{E_m^2}{2\mu_0 c} = \frac{c}{2\mu_{0}}{B^{2}_{m}}= \frac{1}{2} c \varepsilon_0 E_m^2$$
若使用 **均方根值 (RMS)** $E_{rms} = E_m/\sqrt{2}$：
$$I = \frac{E_{rms}^2}{\mu_0 c} = c \varepsilon_0 E_{rms}^2 = c u_{avg}$$

## 4. 延伸探討：輻射壓與動量

電磁波不僅攜帶能量，也攜帶 **[[Momentum|動量]] ($p$)**。
- 若物體完全吸收電磁波，在時間 $\Delta t$ 內獲得的動量為 $\Delta p = \Delta U / c$。
- **輻射壓 (Radiation Pressure)**：單位面積受力 $P_{rad} = \frac{I}{c}$ (全吸收) 或 $P_{rad} = \frac{2I}{c}$ (全反射)。
