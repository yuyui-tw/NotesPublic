## mermaid流程图基础语法

**插件简介：**  
mermaid，是markdown自带的 **流程图语法** ，obsidian中也支持了部分mermaid的特性。我们不用了解太多，照着下面的用就可以了。

**代码：**

```markdown
\`\`\`mermaid
  flowchart TB
      A("开始") --> B["一级"]
      A --> C("二级")
      A --> D("三级")
\`\`\`
```

```markdown
\`\`\`mermaid
  flowchart TB
      A("开始") --> B["一级"]
      A --> C("二级")
      A -->|"说明"| D("三级")
\`\`\`
```

```markdown
\`\`\`mermaid
  flowchart TB
      A("开始") --> B["一级"]
      A --> C("二级")
      A -->|"说明"| D("三级")
      B --> B1("我是B的下级菜单")
      C --> C1("我是C的下级菜单")
\`\`\`
```

```markdown
\`\`\`mermaid
  flowchart LR
      A("开始") --> B["一级"]
      A --> C("二级")
      A -->|"说明"| D("三级")
      B --> B1("我是B的下级菜单")
      C --> C1("我是C的下级菜单")
\`\`\`
```
