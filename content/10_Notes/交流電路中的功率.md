# 1. 導論 (Introduction & Background)

**交流電路中的功率 (Power in AC Circuits)** 是指交流電源提供給電路元件的能量轉換速率。在交流系統中，能量的分佈與直流電路有顯著差異：**電阻器 (Resistor)** 會將電能以熱能形式消耗，而 **電感器 (Inductor)** 與 **電容 (Capacitor)** 則分別透過磁場與電場暫時儲存能量，並在週期內與電源交換。

在穩態情況下，電感與電容的平均儲能不變，因此發電機提供的總功率在週期平均後，完全等於電阻產生的熱能消耗率。

# 2. 核心 (Core Framework)

### 2.1 均方根 (Root-Mean-Square, RMS) 的意義
**均方根值 (RMS Value)** 是衡量交流電效應的核心指標。其物理意義為：若一交流電在電阻上產生的平均發熱功率與某直流電相等，則該直流電的數值即為該交流電的均方根值。因此，RMS 又稱為 **有效值 (Effective Value)**。

對於正弦電流 $i(t) = I_m \sin(\omega t - \phi)$：
- **定義**：對瞬時值的平方取平均後開根號。
- **計算結果**：$I_{rms} = \frac{I_m}{\sqrt{2}} \approx 0.707 I_m$。
- **電動勢 (EMF)**：同理，$\varepsilon_{rms} = \frac{\varepsilon_m}{\sqrt{2}}$。(V=IR同除$\sqrt{ 2 }$)

### 2.2 平均功率 (Average Power) 與功率因子
在交流電路中，只有電阻會消耗功率（實功），其平均值為：
$$P_{av} = I_{rms}^2 R$$
結合[[歐姆定律]]的交流形式 $I_{rms} = \frac{\varepsilon_{rms}}{Z}$，可進一步表示為：
$$P_{av} = I_{rms} \left( \frac{\varepsilon_{rms}}{Z} \right) R = \varepsilon_{rms} I_{rms} \left( \frac{R}{Z} \right)$$
其中 $\frac{R}{Z} = \cos \phi$ 定義為 **功率因子 (Power Factor)**。

# 3. 邏輯 (Operational Logic)

### 3.1 功率公式的積分演算
考慮瞬時功率 $p(t) = i^2(t) R = [I_m \sin(\omega t - \phi)]^2 R$。在一個週期 $T = \frac{2\pi}{\omega}$ 內的平均功率 $P_{av}$，可經由以下積分演算求得：

$$P_{av} = \frac{1}{T} \int_{0}^{T} p(t) dt = \frac{I_m^2 R}{T} \int_{0}^{T} \sin^2(\omega t - \phi) dt$$

利用倍角公式 $\sin^2 \theta = \frac{1 - \cos 2\theta}{2}$ 展開積分項：
$$\int_{0}^{T} \sin^2(\omega t - \phi) dt = \int_{0}^{T} \frac{1 - \cos(2\omega t - 2\phi)}{2} dt$$
$$= \frac{1}{2} \left[ \int_{0}^{T} 1 dt - \int_{0}^{T} \cos(2\omega t - 2\phi) dt \right]$$

由於 $\cos(2\omega t - 2\phi)$ 在一個週期 $T$（對其而言是兩個完整週期）內的積分值為 0，則有：
$$\int_{0}^{T} \sin^2(\omega t - \phi) dt = \frac{1}{2} [T - 0] = \frac{T}{2}$$

代回平均功率公式：
$$P_{av} = \frac{I_m^2 R}{T} \cdot \frac{T}{2} = \frac{I_m^2}{2} R = \left( \frac{I_m}{\sqrt{2}} \right)^2 R = I_{rms}^2 R$$
此結果驗證了均方根電流與平均功率的直接關聯。

### 3.2 串聯電路中的功率分配
在 RLC 串聯電路中，總阻抗 $Z = \sqrt{R^2 + (X_L - X_C)^2}$。
根據 $P = I_{rms}^2 R$，代入電流關係式：
$$P_{av} = \left( \frac{\varepsilon_{rms}}{Z} \right)^2 R = \frac{\varepsilon_{rms}^2 R}{R^2 + (X_L - X_C)^2}$$
- **最大功率傳輸**：當 $X_L = X_C$（共振）時，阻抗 $Z$ 最小（等於 $R$），此時 $P_{av} = \frac{\varepsilon_{rms}^2}{R}$ 達到最大值。
- **相位關係**：此推導再次證明了平均功率僅由電阻項決定，電抗項（$X_L, X_C$）僅透過改變總電流大小與相位角 $\phi$ 來影響功率輸出。

# 4. 應用與脈絡 (Application & Context)

- **共振 (Resonance)**：在 RLC 串聯電路中，當感抗與容抗相等（$X_L = X_C$）時，電路發生共振。此時相位差 $\phi = 0$，功率因子 $\cos \phi = 1$，阻抗最小且電功率轉換至電阻的效率最大。
- **電力系統優化**：電力公司通常要求工業用戶補償功率因子（例如並聯電容器），以減少輸電線路上的虛功傳輸，從而降低熱損耗。
