# 1. 導論 (Introduction & Background)

**最小平方法 (Method of Least Squares)** 是一種在統計與工程中極其重要的數學最佳化技術。
其目標是尋找一個函數（如直線），使其與一組觀測數據點的 **總殘差 (Residuals)** 達到最小。
之所以採用「平方和」而非絕對值之和，是因為平方函數具有良好的可微性，便於利用微積分工具求解。

# 2. 核心 (Core Framework)

### 目標函數 (Objective Function)
對於數據點 $(x_i, y_i)$，設定擬合模型 $y = ax + b$。定義誤差平方和 $S$：
$$S(a, b) = \sum_{i=1}^{n} (y_i - (ax_i + b))^2$$

### 正規方程 (Normal Equations)
使 $S$ 達到極小，對參數 $a, b$ 求偏導並設為零：
1. $\sum y_i = na + b \sum x_i$
2. $\sum x_iy_i = a \sum x_i + b \sum x_i^2$
這是一個關於 $a$ 與 $b$ 的二元一次方程組，具有唯一解。

# 3. 邏輯 (Operational Logic)

### 幾何意涵：向量投影
在線性代數的視角下，最小平方法等同於將觀測向量 $\mathbf{y}$ **正交投影 (Orthogonal Projection)** 到由模型自變數構成的子空間中。
擬合出的預測向量 $\mathbf{\hat{y}}$ 是該子空間中距離 $\mathbf{y}$ 最近的向量，使得誤差向量 $\mathbf{e} = \mathbf{y} - \mathbf{\hat{y}}$ 垂直於子空間。

### 推導證明 (Derivation via Calculus)
- **步驟一**：展開平方項 $S = \sum (y_i^2 - 2y_i(ax_i+b) + (ax_i+b)^2)$。
- **步驟二**：對 $b$ 求偏導：$\frac{\partial S}{\partial b} = -2 \sum (y_i - ax_i - b) = 0 \implies \sum y_i = n b + a \sum x_i$。
- **步驟三**：對 $a$ 求偏導：$\frac{\partial S}{\partial a} = -2 \sum x_i(y_i - ax_i - b) = 0 \implies \sum x_iy_i = b \sum x_i + a \sum x_i^2$。
- **驗證**：由於 $S$ 的二階偏導 $\frac{\partial^2 S}{\partial b^2} = 2n > 0$，根據二階檢定，此平穩點確為極小值點。

# 4. 應用與脈絡 (Application & Context)

### 應用場景
- **線性迴歸 (Linear Regression)**：統計學中預測變數間關係的基礎。
- **測繪學與導航**：處理具備誤差的重複觀測數據。

### 限制與性質
- **高斯-馬可夫定理 (Gauss-Markov Theorem)**：在誤差項滿足特定條件下，最小平方法是最佳線性不偏估計量 (BLUE)。
- **缺點**：對 **離群值 (Outliers)** 極其敏感，因平方運算會放大離群值的誤差權重。

### 相關概念
- [[多變數函數極值]]：最小平方法在本質上是一個多變數極值問題。
- [[線性代數]]：提供投影與矩陣形式的優雅解釋（$\mathbf{X}^T\mathbf{X}\mathbf{\hat{\beta}} = \mathbf{X}^T\mathbf{y}$）。
