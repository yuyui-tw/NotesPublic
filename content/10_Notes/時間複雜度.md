# 時間複雜度分析
## 漸進表示法
*Asymptotic Notations*
### Big-O Notation
在最壞情況下，演算法執行時間的**上限**(Upper bound)
e.g. (輸入資料量n)
迴圈:
```python
sum = 0
for i in range(n):
	sum = sum + 1
```
主程式執行n次，時間複雜度為$O(n)$

巢狀迴圈
```python
for i in range(n):
	for j in range(n):
		sum = sum + 1
```
主程式執行$n^{2}$次，時間複雜度為$O(n^{2})$

- 成長率 *Growth Rate*
	- 時間複雜度使用函數的成長率做客觀評價
	- 函數成長率越小，演算法執行效率越佳

$$
\displaylines{
常數<對數<多項式<指數<階乘 \\
O(1)<O(\log n)<O(n)<O(n^{2})<O(n^{3})<O(2^{n})<O(n!)
}
$$
