# 概要
曲線座標 (Curvilinear Coordinates) 是對傳統笛卡爾座標系統的一種推廣，它使用相交的曲線來建立座標網格，用以更方便地描述和分析具有特定對稱性（如圓柱對稱或球對稱）的幾何問題。
在向量微積分和物理學中，當處理的曲面或體積在笛卡爾座標^[即直角坐標系]中表達式複雜時，轉換到適當的曲線座標系統通常能大幅簡化方程式，使問題更易於求解。

# 核心概念
在歐幾里得空間 ($\mathbb{R}^3$) 中，任何一個點的位置都可以由一組有序的數字（座標）來唯一確定。標準的**笛卡爾座標** $(x, y, z)$ 使用三個互相垂直的直線軸來定位。

與之相對，**曲線座標系統**則利用一組相交的曲面來定義空間中的點。當我們固定某個座標變數為常數時，所形成的曲面稱為**座標曲面 (Coordinate Surfaces)**。三個座標曲面的交線則定義了**座標線 (Coordinate Lines)**。

### 應用與實例
曲線座標的主要優勢在於**簡化特定幾何形狀的方程式**。

- **範例1（簡化）**：
  一個在笛卡爾座標中表示為 $x^2 + y^2 = 4$ 的圓柱，在圓柱座標中可以極其簡潔地表示為 $r = 2$。

- **範例2（複雜化）**：
  然而，不當的使用可能使方程式變得更複雜。例如，一個未以原點為中心的球體 $(x-2)^2+(y-1)^2+z^2=9$，轉換到球座標後會變成 $\rho^2-2 \sin \phi (2 \cos \theta + \sin \theta)\rho - 4 = 0$，這反而使其幾何意義更難辨識。因此，選擇合適的座標系統至關重要。

# 結構/要素
### 圓柱座標 (Cylindrical Coordinates)
圓柱座標 $(r, \theta, z)$ 常用於描述具有圓柱對稱性的物體，其本質上是二維[[極座標]] (Polar Coordinates) 向三維空間的推廣。
- **$r$ (徑向距離)**：點在 xy 平面上的投影到原點的距離 ($r \ge 0$)。
- **$\theta$ (方位角)**：點在 xy 平面上的投影與正 x 軸之間的夾角 ($0 \le \theta < 2\pi$)。
- **$z$ (高度)**：與笛卡爾座標中的 z 相同。

#### 座標曲面
1.  **$r = r_0$**：一個以 z 軸為中心、半徑為 $r_0$ 的**圓柱體**。
2.  **$\theta = \theta_0$**：一個從 z 軸出發、與 xy 平面夾角固定的**半平面**。
3.  **$z = z_0$**：一個平行於 xy 平面的**水平面**。

### 球座標 (Spherical Coordinates)
球座標 $(\rho, \theta, \phi)$ 常用於描述具有球對稱性的物體。
- **$\rho$ (徑向距離)**：點到原點的直線距離 ($\rho \ge 0$)。
- **$\theta$ (方位角)**：與圓柱座標的 $\theta$ 相同，是點在 xy 平面上的投影與正 x 軸的夾角 ($0 \le \theta < 2\pi$)。
- **$\phi$ (天頂角/極角)**：點與原點的連線與正 z 軸之間的夾角 ($0 \le \phi \le \pi$)。

#### 座標曲面
1.  **$\rho = \rho_0$**：一個以原點為中心、半徑為 $\rho_0$ 的**球體**。
2.  **$\theta = \theta_0$**：一個從 z 軸出發的**半平面**。
3.  **$\phi = \phi_0$**：一個頂點在原點、與 z 軸夾角為 $\phi_0$ 的**圓錐體**。

# 原理/推導
### 圓柱座標轉換
#### 從圓柱到笛卡爾
$$x = r\cos\theta$$
$$y = r\sin\theta$$
$$z = z$$

#### 從笛卡爾到圓柱
$$r = \sqrt{x^2+y^2}$$
$$\theta = \tan^{-1}\left(\frac{y}{x}\right)$$
$$z = z$$

- **變數範圍與特性**：
    - $r \ge 0$
    - $0 \le \theta < 2\pi$
    - $\theta$ 在 $(x, y) = (0, 0)$ 時未定義。

### 球座標轉換
#### 從球座標到笛卡爾
$$x = \rho \sin\phi \cos\theta$$
$$y = \rho \sin\phi \sin\theta$$
$$z = \rho \cos\phi$$

#### 從笛卡爾到球座標
$$\rho = \sqrt{x^2+y^2+z^{2}}$$
$$\theta = \tan^{-1}\left(\frac{y}{x}\right)$$
$$\phi = \cos^{-1}\left(\frac{z}{\sqrt{x^2+y^2+z^2}}\right)$$

- **變數範圍與特性**：
    - $\rho \ge 0$
    - $0 \le \theta < 2\pi$
    - $0 \le \phi \le \pi$
    - $\theta$ 在 $(x, y) = (0, 0)$ 時未定義。
    - $\phi$ 在原點 $(0, 0, 0)$ 時未定義。
