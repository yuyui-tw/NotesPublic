# 機器學習和統計學的差別

| 機器學習                                                    | 統計學                             |
| ------------------------------------------------------- | ------------------------------- |
| 提高預測或分類資料的精準度                                           | 解釋資料並理解                         |
| 先不論[[機器學習和深度學習的差異#XAI\|XAI]]，大多模型只講求精確程度與效率，不必理解中間之演算過程 | 「解釋」大多只要確認**相關性**即可，不須找出精確的因果關係 |

- 統計學
	- 敘述統計學 e.g. 平均、離散
	- 推論統計學 e.g. 樣本+母體、代表值、分布

# 資料視覺化
將數據資料加工為圖表之類易懂的形式
好處:
- 易於理解
	- e.g. 客戶關係管理系統(Customer Relationship Management, CRM)之營業流程視覺化
- 彌補個人技能差異
- 形成相同認知
