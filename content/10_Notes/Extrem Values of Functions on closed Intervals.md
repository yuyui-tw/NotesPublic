# 概要
討論如何尋找一個連續函數在一個閉區間上的最大值與最小值（絕對極值）。

# 理論
- **絕對最大/最小值 (Absolute Maximum/Minimum)**
	- 設 $f$ 為一定義於區間 $D$ 的函數。若在 $D$ 中存在一點 $c$，使得對於所有 $D$ 中的 $x$ 均滿足 $f(c) \ge f(x)$，則稱 $f(c)$ 為 $f$ 在 $D$ 上的**絕對最大值 (absolute maximum value)**。
	- 同理，若在 $D$ 中存在一點 $d$，使得對於所有 $D$ 中的 $x$ 均滿足 $f(d) \le f(x)$，則稱 $f(d)$ 為 $f$ 在 $D$ 上的**絕對最小值 (absolute minimum value)**。
	- 絕對最大值與最小值合稱為**絕對極值 (absolute extrema)**。

- **局部最大/最小值 (Local Maximum/Minimum)**
	- 若在包含 $c$ 的某個開區間 $I$ 中，對於所有 $I$ 中的 $x$ 均滿足 $f(c) \ge f(x)$，則稱 $f(c)$ 為 $f$ 的一個**局部最大值 (local maximum value)**。
	- 同理，若在包含 $d$ 的某個開區間 $J$ 中，對於所有 $J$ 中的 $x$ 均滿足 $f(d) \le f(x)$，則稱 $f(d)$ 為 $f$ 的一個**局部最小值 (local minimum value)**。
	- 局部最大值與最小值合稱為**局部極值 (local extrema)**。

- **極值定理 (The Extreme Value Theorem)**
	如果函數 $f$ 在閉區間 $[a, b]$ 上是連續的，則 $f$ 必在 $[a, b]$ 上達到絕對最大值與絕對最小值。

- **臨界點 (Critical Point)**
	函數 $f$ 定義域中的一個內點 $c$，若 $f'(c) = 0$ 或 $f'(c)$ 不存在，則稱 $c$ 為**臨界點**。
	> [!IMPORTANT] 若 $f$ 在 $c$ 點有局部極值，則 $c$ 必為臨界點。

# 公式
- 尋找閉區間 $[a, b]$ 上連續函數 $f$ 的絕對極值步驟
	1.  **找臨界點**：找出 $f$ 在開區間 $(a, b)$ 中所有臨界點。
	2.  **計算函數值**：計算所有臨界點上的函數值。
	3.  **計算端點值**：計算區間端點 $a$ 和 $b$ 的函數值，即 $f(a)$ 和 $f(b)$。
	4.  **比較**：比較步驟 2 和 3 中求得的所有函數值。最大者即為絕對最大值，最小者即為絕對最小值。
