> 電腦模仿人類透過經驗學習事物，提高電腦判斷的精度的技術

基本原理:
大量資料輸入電腦，從資料中找出特定的模式

機器學習的方法主要有三:「監督式學習」、「非監督式學習」、「強化學習」

# 監督式學習
成對提供資料及正解附註，讓電腦學習資料的特徵

## 主要演算法
### 分類 *Classification*
- 預測資料的類別
- e.g. 垃圾郵件過濾、圖像辨識
- 主要模型
	- 感知器
	- 決策樹
	- 隨機森林
	- 邏輯迴歸
	- SVM
	- 神經網路
	- k-NN
### 迴歸 *Regression*
- 預測輸入資料的連續值
- e.g. 預測電力消耗量
- 主要模型
	- 迴歸樹
	- 線性迴歸
	- Lasso迴歸、Ridge迴歸
	- Elastic Net
	- SVR

>[!NOTE] 模型
>在機器學習中，已訓練完畢、可以執行特定任務或運算的檔案或運算方法
# 非監督式學習
不給予正解標註，只給予資料，讓電腦學習資料的特徵

## 主要演算法
### 分群
- 找出資料的傾向
- e.g. 針對不同顧客推薦不同商品
- 主要模型
	- k-means法
	- 階層式分群
### 降維
- 將無法辨認的高維資料轉換為低維(例如將身高和體重轉換為BMI以評估健康)
- e.g. 資料視覺化
- 主要模型
	- PCA(Principal Component Analysis 主成分分析)
	- t-SNE
# 強化學習
以某個目標為終點，進行 【正確/錯誤】 的行動給予 【獎勵/懲罰】，讓電腦學會最佳行動
左手拿鞭右手拿糖(?
- 訓練難度較高
- 應用於 推薦、異常偵測、頻繁樣式的匹配
	- e.g. youtube推薦影片www
## 主要演算法
### Q學習
- 用Q表格管理某種態的某行動的價值，並不斷更新Q值
- e.g. 打磚塊、Alpha Go、自動駕駛、設備自動控制
- 主要模型
	- DQN
	- A3C
### 蒙地卡羅方法
- 不斷使用亂數測試直到找出適合之答案
- e.g. Alpha Go
### 策略梯度法
- 用神經網路表現智能體行動機率
- e.g. Alpha Go
- 主要模型
	- PRO
