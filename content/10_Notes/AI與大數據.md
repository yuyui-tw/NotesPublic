# 大數據的定義與AI的關聯性
>累積大量且即時的結構化或非結構化資料，然後分析、處理這些資料的技術，又或是指這些資料本身
- 大數據的特徵:3V
	- Volume(量):資料量與處理能力
	- Velocity(速度):變化速度與更新頻率
	- Variety(多樣性):各種資料的組合
- 大數據與[[深度學習]]密切相關:深度學習的多層化神經網路演算法需要大量加工處理過的資料，即大數據
- Apache Hadoop 與 Apache Spark等大數據管理技術的使用能夠比單靠關聯式資料庫(Relational Database)更加容易管理數十TB的龐大資料

## 資料的品質
收集大數據時，除了資料的量，還需考慮資料的品質是否高級，並防止品質劣化的問題
- 資料管理知識體系(DMBok,Data Management Body of Knowledge)

| 評價標準  | 概要                           |
| ----- | ---------------------------- |
| 正確性   | 資料正確呈現要代表的實體                 |
| 完整性   | 齊備資料所有要素                     |
| 一致性   | 同一實體只存在一個代表資料                |
| 最新性   | 資料呈現的是當前實體                   |
| 精度    | 資料的詳細度(有效位數等)是否充足            |
| 隱私    | 存取管理和使用監測                    |
| 妥善性   | 多個對象中所持的資料一致不矛盾              |
| 參照整合性 | 資料存在參照來源                     |
| 適時性   | 資料可隨時調用                      |
| 有效性   | 資料的屬性(類型、格式、精度、字元編碼等)都在有效範圍內 |
