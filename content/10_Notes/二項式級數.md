# 概要 (Overview)
**二項式級數 (Binomial series)** 是將傳統的 **[[二項式定理]]** 從整數冪次推廣至任意實數（或複數）冪次 $k$ 的 **泰勒級數 (Taylor series)** 形式。

在泰勒級數的應用中，它能透過簡單的代數代換，直接獲得複雜函數（如根式、分式）的級數展開，而無需重複進行繁瑣的逐階微分計算。它是連接代數展開與無窮級數分析的橋樑。

$$
(1+x)^{n}=\sum_{r=0}^{\infty} \frac{n(n-1)\dots(n-r+1)}{r!}x^{r}=\sum_{r=0}^{\infty}\binom{n}{r}x^{r},n\in R
$$

# 核心概念 (Core Concepts)
- **從展開式到級數 (Expansion to Series)**：
    - **二項式展開**：當 $k$ 為正整數時，展開式會在 $n=k+1$ 項後變為 0，形成有限項的多項式。
    - **二項式級數**：當 $k$ 非正整數時（如負數或分數），展開式為無限級數，僅在收斂半徑 $|x| < 1$ 內有效。
- **推廣二項式係數 (Generalized Binomial Coefficient)**：
	對於任意實數 $k$，定義為：
	$$\binom{k}{n} = \frac{k(k-1)(k-2)\dots(k-n+1)}{n!}$$
    這是決定級數每一項權重的核心係數。
- **收斂性 (Convergence)**：
	- 級數在 $|x| < 1$ 時必定收斂。
	- 若 $k \geq 0$，在 $x = \pm 1$ 亦收斂。
	- 若 $k \leq -1$，在 $x = \pm 1$ 發散。
# 結構/要素 (Structure / Elements)
### 標準形式與線性近似
當我們討論 $(1+u)^n$ 的展開時，最常見的形式為：
$$(1+u)^n = 1 + nu + \frac{n(n-1)}{2!}u^2 + \frac{n(n-1)(n-2)}{3!}u^3 + \dots$$
- **$1+nu$ 的來源**：這是泰勒級數的一階截斷（線性近似）。在物理學或工程學中，當 $u \ll 1$ 時，高次項 $u^2, u^3$ 的值微乎其微，因此常使用 $(1+u)^n \approx 1+nu$ 作為快速估算的公式。
- **常用模型**：
    - **倒數**：$(1+x)^{-1} = 1 - x + x^2 - \dots \approx 1-x$
    - **根號**：$(1+x)^{1/2} = 1 + \frac{1}{2}x - \frac{1}{8}x^2 + \dots \approx 1 + \frac{1}{2}x$

# 原理/推導 (Principles / Derivation)
二項式級數本質上是 $f(x) = (1+x)^k$ 在 $x=0$ 處的 **麥克勞林級數 (Maclaurin Series)**。

1. **各階導數的規律**：
	- $f(0) = (1+0)^k = 1$
	- $f'(x) = k(1+x)^{k-1} \implies f'(0) = k$
	- $f''(x) = k(k-1)(1+x)^{k-2} \implies f''(0) = k(k-1)$
	- $f^{(n)}(0) = k(k-1)\dots(k-n+1)$
2. **帶入泰勒公式**：
	根據泰勒公式 $f(x) = \sum \frac{f^{(n)}(0)}{n!}x^n$：
	$$f(x) = \frac{1}{0!}x^0 + \frac{k}{1!}x^1 + \frac{k(k-1)}{2!}x^2 + \dots = 1 + kx + \frac{k(k-1)}{2}x^2 + \dots$$
	這便解釋了為何第一項永遠是 $1$，第二項永遠是「冪次乘以變數 ($kx$ 或 $nu$)」。

### 對泰勒級數的作用 (Role in Taylor Series)
它是構造複雜函數級數的最強大工具：
- **避免直接微分**：例如求 $f(x) = \frac{1}{\sqrt{1-x^2}}$ 的級數，只需令 $u = -x^2, n = -1/2$ 代入上述公式，即可直接寫出展開式。
- **解析組合**：許多泰勒級數（如 $\arcsin x$）的推導，最後一步往往是將二項式級數進行逐項積分。
