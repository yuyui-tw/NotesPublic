# 1. 導論 (Introduction & Background)

**高階偏導數 (Higher-Order Partial Derivatives)** 是指對一個已經進行過偏微分的函數再次進行偏微分的操作。其在物理學與工程學中極為重要，用於描述物理量（如溫度、波形）在空間與時間上的二階變化率。根據 **克萊羅定理 (Clairaut's Theorem)**，若二階偏導數在某點連續，則混合偏導數與求導順序無關，即 $f_{xy} = f_{yx}$。

# 2. 核心 (Core Framework)

### 符號表示
對於函數 $f(x, y)$，其二階偏導數可表示為：
- 對 $x$ 微分兩次：$\frac{\partial^2 f}{\partial x^2}$ 或 $f_{xx}$
- 對 $x$ 後對 $y$ 微分：$\frac{\partial^2 f}{\partial y \partial x}$ 或 $f_{xy}$

### 基本運算規則
高階偏微分本質上是重複應用一階偏微分的規則。在計算某個變數的偏導時，將其餘變數視為常數。

# 3. 邏輯 (Operational Logic)

### 求法技巧
1. **樹狀圖法 (Tree Diagram)**：在處理複合函數時，繪製變數間的依賴關係，沿路徑相乘、跨路徑相加。
2. **全微分取代法 (Differential Method)**：利用 $d(uv) = udv + vdu$ 的形式，先求出一階結果再進行二次微分。

### 二階連鎖律推導 (Chain Rule Derivation)
若 $f(x,y)$ 且 $x=x(t), y=y(t)$，其對 $t$ 的二階導函數為：
$$\frac{d^2f}{dt^2} = f_{xx} \left(\frac{dx}{dt}\right)^2 + 2f_{xy} \frac{dx}{dt} \frac{dy}{dt} + f_{yy} \left(\frac{dy}{dt}\right)^2 + f_x \frac{d^2x}{dt^2} + f_y \frac{d^2y}{dt^2}$$
> **注意**：計算過程中，偏微分符號 ($\partial$) 與常微分符號 ($d$) 必須嚴格區分，不可混用。

# 4. 應用與脈絡 (Application & Context)

### 物理模型應用
- **波方程式 (Wave Equation)**：$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}$，描述波動傳播的基礎特性。
- **拉普拉斯方程式 (Laplace Equation)**：$\nabla^2 f = \sum \frac{\partial^2 f}{\partial x_i^2} = 0$，常見於靜電學與流體力學。
- **脈絡連結**：此概念為 [[多變數隱函數]] 微分與極值判定的核心基礎。
