# in Python
## 堆疊(Stack)
- Python原生列表(list)即具備完整堆疊功能

```python
stack = []
# 推入元素 (Push)
stack.append('A')
# 彈出元素(Pop)
top = stack.pop()
# 查看頂端元素(Peek)
top = stack[-1] if stack else None
# 檢查空值
is_empty = len(stack) == 0
```

## 佇列(Queue)

### 1. 列表(list)基礎實現

```python
queue = [] 
# 入隊 (Enqueue)
queue.append('B')
# 出隊 (Dequeue) - 效率較低(O(n)) 
item = queue.pop(0) if queue else None
```

### 2. collections.deque高效實現
```python
from collections import deque q = deque()
# 入隊
q.append('C')
# 出隊 (O(1)時間)
item = q.popleft()
# 查看隊首
front = q[0] if q else None
```

### 3. queue模塊(線程安全)
```python
import queue q = queue.Queue(maxsize=5)
# 入隊
q.put('D')
# 出隊
item = q.get()
# 檢查隊列狀態
is_full = q.full()
is_empty = q.empty()
size = q.qsize()
```

## 功能對照表

|操作|堆疊(list)|佇列(deque)|queue模塊|
|---|---|---|---|
|添加元素|append()|append()|put()|
|移除元素|pop()|popleft()|get()|
|查看元素|[-1]||N/A|
|線程安全|否|否|是|
|大小限制|無|無|maxsize參數|
