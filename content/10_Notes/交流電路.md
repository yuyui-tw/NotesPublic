# 1. 導論 (Introduction & Background)

**交流電路 (Alternating Current Circuit, AC Circuit)** 是指電壓與電流的大小及方向隨時間呈週期性（通常為正弦函數）變化的電路。相較於直流電 (DC)，交流電便於透過 **變壓器 (Transformer)** 改變電壓，從而降低長途輸電的能量損耗。

在交流電路分析中，由於電感與電容會產生相位差，傳統的代數加法被 **相量分析法 (Phasor Analysis)** 所取代，這使得描述電壓與電流之間的超前或落後關係變得直觀。

# 2. 核心 (Core Framework)

### 2.1 交流電壓源與均方根值
![[交流發電機原理圖.png]]
設定交流電壓隨時間變化為 $v(t) = V_m \sin(\omega t)$。
- **峰值 (Peak Value)**：$V_m$。
- **均方根值 (Root-Mean-Square, RMS)**：用於衡量交流電的等效發熱效應。
  $$V_{rms} = \frac{V_m}{\sqrt{2}} \approx 0.707 V_m, \quad I_{rms} = \frac{I_m}{\sqrt{2}}$$

### 2.2 抗磁與阻抗 (Reactance & Impedance)
在 AC 電路中，電感與電容對電流的阻礙作用稱為 **電抗 (Reactance)**：
- **感抗 (Inductive Reactance)**：$X_L = \omega L$（頻率越高，阻礙越大）。
- **容抗 (Capacitive Reactance)**：$X_C = \frac{1}{\omega C}$（頻率越高，阻礙越小）。
- **阻抗 (Impedance)**：總合電阻與電抗的向量和 $Z$。

### 2.3 相量關係總結
對於各元件在 $v(t) = V_m \sin(\omega t)$ 下的響應：

| 元件 | 歐姆定律變體 | 相位關係 (Phase) | 性質描述 |
| :--- | :--- | :--- | :--- |
| **電阻 (R)** | $V_R = I_R R$ | 同相 (In phase) | 電流與電壓同時達到峰值 |
| **電感 (L)** | $V_L = I_L X_L$ | 電流落後電壓 $90^\circ$ | 電壓領先 (ELI) |
| **電容 (C)** | $V_C = I_C X_C$ | 電流領先電壓 $90^\circ$ | 電流領先 (ICE) |

# 3. 邏輯 (Operational Logic)

### 3.1 交流發電機原理
根據 [[電磁感應#法拉第感應定律 (Faraday's Law of Induction)]]，當線圈在磁場中以定角速度 $\omega$ 旋轉時，磁通量 $\Phi_B = BA \cos(\omega t)$，產生的感應電動勢為：
$$\varepsilon = -N \frac{d\Phi_B}{dt} = NBA\omega \sin(\omega t)$$
這解釋了交流電源為何通常呈正弦波形。

### 3.2 阻抗的頻率特性推導
1. **電感**：由 $v_L = L \frac{di}{dt}$，若 $i = I_m \sin(\omega t)$，則 $v_L = L \omega I_m \cos(\omega t) = (I_m \omega L) \sin(\omega t + 90^\circ)$。定義 $X_L = \omega L$。
2. **電容**：由 $i_C = C \frac{dv}{dt}$，若 $v = V_m \sin(\omega t)$，則 $i_C = C \omega V_m \cos(\omega t) = (V_m \omega C) \sin(\omega t + 90^\circ)$。定義 $X_C = 1/\omega C$。

### 3.3 RLC 串聯電路分析
利用相量圖，總電壓 $V$ 為各元件電壓的向量和：
$$V = \sqrt{V_R^2 + (V_L - V_C)^2} = I \sqrt{R^2 + (X_L - X_C)^2}$$
定義總阻抗 $Z = \sqrt{R^2 + (X_L - X_C)^2}$。
相位角 $\phi$ 滿足：$\tan \phi = \frac{X_L - X_C}{R}$。

# 4. 應用與脈絡 (Application & Context)

- **電力輸送**：利用變壓器提升電壓以減少輸電線路上的 $I^2R$ 損耗。
- **阻抗匹配**：在音響與收訊設備中，確保負載阻抗與電源阻抗匹配以獲得最大功率傳輸。
- **相關連結**：
    - [[歐姆定律]]：AC 分析中 $V=IZ$ 是其推廣形式。
    - [[電磁震盪]]：當 $\omega L = 1/\omega C$ 時，電路發生共振，阻抗最小（僅剩電阻）。
    - [[電磁感應]]：交流電產生的物理根源。
