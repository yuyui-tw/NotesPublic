# 1. 導論 (Introduction & Background)

**雙曲線函數 (Hyperbolic Functions)** 是一類與雙曲線幾何特徵相關的函數，其定義是基於自然指數函數 $e^x$ 的代數組合。

### 與三角函數的幾何對比
- **三角函數 (Trigonometric Functions)**：亦稱圓函數，藉由單位圓 $x^2 + y^2 = 1$ 上的點座標定義，滿足關係式 $(x, y) = (\cos\theta, \sin\theta)$。
- **雙曲線函數**：藉由單位雙曲線 $u^2 - v^2 = 1$ 右半支上的點座標定義，滿足關係式 $(u, v) = (\cosh a, \sinh a)$。此處的雙曲角 $a$ 為射線與雙曲線所圍扇形面積的兩倍。

### 基本函數類型
- **雙曲正弦 (Hyperbolic Sine)**：$\sinh x$，為奇函數。
- **雙曲餘弦 (Hyperbolic Cosine)**：$\cosh x$，為偶函數。
- **雙曲正切 (Hyperbolic Tangent)**：$\tanh x$，常用於將輸入範圍壓縮至 $(-1, 1)$。
- 以及對應的倒數函數：雙曲餘切 $\coth x$、雙曲正割 $\text{sech } x$ 與雙曲餘割 $\text{csch } x$。

# 2. 核心 (Core Framework)

### 定義公式 (Defining Formulas)
- $\sinh x = \frac{e^x - e^{-x}}{2}$
- $\cosh x = \frac{e^x + e^{-x}}{2}$
- $\tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}$
- $\coth x = \frac{e^x + e^{-x}}{e^x - e^{-x}} \quad (x \neq 0)$
- $\text{sech } x = \frac{1}{\cosh x} = \frac{2}{e^x + e^{-x}}$
- $\text{csch } x = \frac{1}{\sinh x} = \frac{2}{e^x - e^{-x}} \quad (x \neq 0)$

### 雙曲恆等式 (Hyperbolic Identities)
- **畢氏雙曲恆等式**：
  $$ \cosh^2 x - \sinh^2 x = 1 $$
  $$ 1 - \tanh^2 x = \text{sech}^2 x $$
  $$ \coth^2 x - 1 = \text{csch}^2 x $$
- **和差公式**：
  $$ \sinh(x \pm y) = \sinh x \cosh y \pm \cosh x \sinh y $$
  $$ \cosh(x \pm y) = \cosh x \cosh y \pm \sinh x \sinh y $$
  $$ \tanh(x \pm y) = \frac{\tanh x \pm \tanh y}{1 \pm \tanh x \tanh y} $$

### 導函數公式 (Derivatives)
- $\frac{d}{dx}(\sinh x) = \cosh x$
- $\frac{d}{dx}(\cosh x) = \sinh x$
- $\frac{d}{dx}(\tanh x) = \text{sech}^2 x$
- $\frac{d}{dx}(\coth x) = -\text{csch}^2 x$
- $\frac{d}{dx}(\text{sech } x) = -\text{sech } x \tanh x$
- $\frac{d}{dx}(\text{csch } x) = -\text{csch } x \coth x$

### 反雙曲線函數與其導數 (Inverse Hyperbolic Functions)
- **反雙曲正弦**：$\sinh^{-1} x = \ln(x + \sqrt{x^2+1})$，其導數為 $\frac{d}{dx}(\sinh^{-1} x) = \frac{1}{\sqrt{x^2+1}}$
- **反雙曲餘弦**：$\cosh^{-1} x = \ln(x + \sqrt{x^2-1}) \quad (x \ge 1)$，其導數為 $\frac{d}{dx}(\cosh^{-1} x) = \frac{1}{\sqrt{x^2-1}} \quad (x > 1)$
- **反雙曲正切**：$\tanh^{-1} x = \frac{1}{2}\ln\left(\frac{1+x}{1-x}\right) \quad (|x| < 1)$，其導數為 $\frac{d}{dx}(\tanh^{-1} x) = \frac{1}{1-x^2} \quad (|x| < 1)$

# 3. 邏輯 (Operational Logic)

### 畢氏雙曲恆等式推導
將定義公式代入 $\cosh^2 x - \sinh^2 x$：
$$ \cosh^2 x - \sinh^2 x = \left(\frac{e^x + e^{-x}}{2}\right)^2 - \left(\frac{e^x - e^{-x}}{2}\right)^2 $$
$$ = \frac{e^{2x} + 2 + e^{-2x}}{4} - \frac{e^{2x} - 2 + e^{-2x}}{4} = \frac{4}{4} = 1 $$
同除以 $\cosh^2 x$ 可得 $1 - \tanh^2 x = \text{sech}^2 x$。

### 反雙曲線函數對數表達式推導 (以 $y = \sinh x$ 為例)
設 $y = \sinh x = \frac{e^x - e^{-x}}{2}$，求解其[[反函數]] $x = \sinh^{-1} y$：
$$ 2y = e^x - e^{-x} \implies 2y = e^x - \frac{1}{e^x} $$
同乘 $e^x$ 移項整理：
$$ (e^x)^2 - 2y(e^x) - 1 = 0 $$
利用一元二次方程求根公式解 $e^x$：
$$ e^x = \frac{2y \pm \sqrt{4y^2 + 4}}{2} = y \pm \sqrt{y^2+1} $$
因 $e^x > 0$ 且 $\sqrt{y^2+1} > |y|$（即 $y - \sqrt{y^2+1} < 0$），故必須取正號：
$$ e^x = y + \sqrt{y^2+1} \implies x = \ln(y + \sqrt{y^2+1}) $$
故得 $\sinh^{-1} x = \ln(x + \sqrt{x^2+1})$。

### 反雙曲線函數微分推導 (以 $\sinh^{-1} x$ 為例)
使用反函數微分定理推導：
設 $y = \sinh^{-1} x \implies x = \sinh y$。兩邊對 $x$ 微分：
$$ 1 = \cosh y \cdot \frac{dy}{dx} \implies \frac{dy}{dx} = \frac{1}{\cosh y} $$
由於 $\cosh^2 y - \sinh^2 y = 1 \implies \cosh y = \sqrt{1+\sinh^2 y}$（因為 $\cosh y > 0$ 恆成立），代入 $\sinh y = x$：
$$ \frac{dy}{dx} = \frac{1}{\sqrt{1+x^2}} $$
得 $\frac{d}{dx}(\sinh^{-1} x) = \frac{1}{\sqrt{x^2+1}}$。

# 4. 應用與脈絡 (Application & Context)

### 人工智慧神經網路激活層 (AI Activation Layers)
- 雙曲正切函數 $\tanh x$ 是機器學習中極為常見的非線性激活函數。
- 其值域為 $(-1, 1)$，為**零對稱 (Zero-centered)** 的函數。相較於 Sigmoid 函數，它能使神經網路在反向傳播 (Backpropagation) 計算時，權重更新方向更加穩定且收斂更快。

### 懸鏈線 (Catenary)
- 僅在重力作用下懸掛且質量分佈均勻的自由垂懸鏈條，其幾何形狀並非拋物線，而是由雙曲餘弦函數描述的懸鏈線。
- 方程式表示為 $y = a\cosh\left(\frac{x}{a}\right)$。

### 狹義相對論中的快速度 (Rapidity in Special Relativity)
- 在描述高速運動的粒子時，利用雙曲正切定義快速度 $\eta$（使速度比值 $\frac{v}{c} = \tanh\eta$），可以將相對論性的非線性速度相加變換轉換成快速度 $\eta$ 的線性代數相加。
