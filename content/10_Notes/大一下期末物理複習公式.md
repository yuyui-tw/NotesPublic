# 物理複習公式 (Physics Formula Review)

本筆記彙整電磁學中核心之物理公式，內容依主題分類，旨在提供言簡意賅之快速複習參考。公式後方均標記引用之筆記來源。

---

## 1. 磁場與帶電粒子運動 (Magnetic Fields & Particle Motion)

*   **勞倫茲力 (Lorentz Force)**：帶電粒子在電磁場中之總受力。
    $$\mathbf{F} = q(\mathbf{E} + \mathbf{v} \times \mathbf{B})$$
    標記引用：[[帶電粒子在磁場中之運動]]、[[馬克士威方程式]]
*   **磁力 (Magnetic Force)**：單一運動電荷在磁場中之受力（磁力絕不對電荷作功）。
    $$\mathbf{F}_B = q(\mathbf{v} \times \mathbf{B}) \quad \text{或} \quad F_B = |q|vB\sin\phi$$
    標記引用：[[磁場]]
*   **磁場高斯定律 (Gauss's Law for Magnetism)**：自然界不存在磁單極子，磁力線恆為封閉曲線。
    $$\oint \mathbf{B} \cdot d\mathbf{A} = 0 \quad (\text{微分形式: } \nabla \cdot \mathbf{B} = 0)$$
    標記引用：[[磁場]]、[[馬克士威方程式]]
*   **等速率圓周運動 (Circular Motion in Uniform B-Field)**：當速度 $\mathbf{v}$ 與均強磁場 $\mathbf{B}$ 垂直時。
    *   **軌道半徑**：$$R = \frac{mv}{qB}$$
    *   **角速度 (迴旋頻率)**：$$\omega = \frac{qB}{m}$$
    *   **週期 (與速度無關)**：$$T = \frac{2\pi m}{qB}$$
    標記引用：[[帶電粒子在磁場中之運動]]

## 2. 載流導線之磁場與力 (Magnetic Field & Force of Wires)

*   **載流導線受力 (Force on Wire)**：
    $$\mathbf{F} = I(\mathbf{L} \times \mathbf{B}) \quad \text{或} \quad F = ILB\sin\phi$$
    標記引用：[[載流導線在磁場中所受之力]]
*   **封閉載流線圈之力矩 (Torque on Loop)**：
    $$\boldsymbol{\tau} = \boldsymbol{\mu} \times \mathbf{B} \quad (\text{其中磁偶極矩 } \boldsymbol{\mu} = N I \mathbf{A})$$
    標記引用：[[載流導線在磁場中所受之力]]
*   **磁偶極子之位能 (Potential Energy)**：
    $$U = -\boldsymbol{\mu} \cdot \mathbf{B}$$
    標記引用：[[載流導線在磁場中所受之力]]
*   **必歐-沙伐定律 (Biot-Savart Law)**：電流微元產生磁場之基本關係。
    $$d\mathbf{B} = \frac{\mu_0}{4\pi} \frac{I d\mathbf{l} \times \hat{\mathbf{r}}}{r^2}$$
    標記引用：[[Biot-Savart Law]]
*   **無限長直載流導線之磁場**：
    $$B = \frac{\mu_0 I}{2\pi R}$$
    標記引用：[[Biot-Savart Law]]、[[安培定律]]
*   **圓環形導線圓心之磁場**：
    $$B = \frac{\mu_0 I \phi}{4\pi R} \quad (\text{完整圓環 } \phi=2\pi \implies B = \frac{\mu_0 I}{2R})$$
    標記引用：[[Biot-Savart Law]]
*   **安培定律 (Ampere's Law)**：
    $$\oint \mathbf{B} \cdot d\mathbf{l} = \mu_0 I_{enc}$$
    標記引用：[[安培定律]]
*   **無限長理想螺線管內部磁場**：
    $$B = \mu_0 n I \quad (\text{其中 } n = \frac{N}{l} \text{ 為單位長度匝數})$$
    標記引用：[[安培定律]]
*   **螺線環內部磁場 (Toroid)**：
    $$B = \frac{\mu_0 N I}{2\pi r}$$
    標記引用：[[安培定律]]

## 3. 電磁感應 (Electromagnetic Induction)

*   **磁通量 (Magnetic Flux)**：
    $$\Phi_B = \int \mathbf{B} \cdot d\mathbf{A}$$
    標記引用：[[電磁感應]]
*   **法拉第感應定律 (Faraday's Law)**：
    $$\varepsilon = -N \frac{d\Phi_B}{dt}$$
    標記引用：[[電磁感應]]
*   **動生電動勢 (Motional EMF)**：因導體運動（面積改變）產生之電動勢。
    $$\varepsilon = \int_L (\mathbf{v} \times \mathbf{B}) \cdot d\mathbf{l} \quad (\text{直導線垂直切割時 } \varepsilon = BLv)$$
    標記引用：[[動生電動勢]]
*   **感生電動勢與感應電場 (Induced EMF & Electric Field)**：因磁場時變產生之電動勢。
    $$\varepsilon = \oint_L \mathbf{E}_{ind} \cdot d\mathbf{l} = -\frac{d\Phi_B}{dt}$$
    標記引用：[[感生電動勢]]
*   **馬克士威-法拉第方程式**：時變磁場在空間激發感應電場。
    $$\nabla \times \mathbf{E} = -\frac{\partial \mathbf{B}}{\partial t}$$
    標記引用：[[感生電動勢]]、[[馬克士威方程式]]

## 4. R-L 電路 (R-L Circuits)

*   **充電過程 (電流隨時間變化)**：
    $$i(t) = \frac{\mathcal{E}}{R} \left( 1 - e^{-t/\tau} \right)$$
    標記引用：[[R-L 電路]]
*   **放電過程 (電流隨時間變化)**：
    $$i(t) = I_0 e^{-t/\tau}$$
    標記引用：[[R-L 電路]]
*   **時間常數 (Time Constant)**：
    $$\tau = \frac{L}{R}$$
    標記引用：[[R-L 電路]]
*   **電感器之儲能 (Energy Storage)**：
    $$U_L = \frac{1}{2} L I^2$$
    標記引用：[[R-L 電路]]
*   **磁場能量密度 (Magnetic Energy Density)**：每單位體積儲存之磁能。
    $$u_B = \frac{B^2}{2\mu_0}$$
    標記引用：[[R-L 電路]]

## 5. 電磁振盪與 RLC 電路 (Electromagnetic Oscillations & RLC Circuits)

*   **LC 電路無阻尼自由振盪方程式**：
    $$L \frac{d^2q}{dt^2} + \frac{1}{C}q = 0 \quad \implies \quad \frac{d^2q}{dt^2} + \omega^2 q = 0$$
    標記引用：[[電磁震盪]]
*   **自由振盪之自然角頻率**：
    $$\omega_0 = \frac{1}{\sqrt{LC}}$$
    標記引用：[[電磁震盪]]
*   **LC 電路電荷與電流隨時間變化**：
    $$q(t) = Q_{max} \cos(\omega t + \phi) \quad \text{與} \quad i(t) = -I_{max} \sin(\omega t + \phi)$$
    標記引用：[[電磁震盪]]
*   **LC 電路總能量 (守恆)**：
    $$U = U_E + U_B = \frac{q(t)^2}{2C} + \frac{1}{2} L i(t)^2 = \frac{Q_{max}^2}{2C}$$
    標記引用：[[電磁震盪]]
*   **RLC 電路阻尼振盪方程式**：
    $$L \frac{d^2q}{dt^2} + R \frac{dq}{dt} + \frac{1}{C}q = 0$$
    標記引用：[[電磁震盪]]

## 6. 交流電路 (Alternating Current Circuits)

*   **均方根值 (RMS / Effective Value)**：
    $$V_{rms} = \frac{V_m}{\sqrt{2}} \approx 0.707 V_m \quad \text{及} \quad I_{rms} = \frac{I_m}{\sqrt{2}}$$
    標記引用：[[交流電路]]、[[交流電路中的功率]]
*   **感抗與容抗 (Reactance)**：
    $$X_L = \omega L \quad \text{及} \quad X_C = \frac{1}{\omega C}$$
    標記引用：[[交流電路]]
*   **RLC 串聯電路之總阻抗 (Impedance)**：
    $$Z = \sqrt{R^2 + (X_L - X_C)^2}$$
    標記引用：[[交流電路]]
*   **交流電路相位角 (Phase Angle)**：
    $$\tan \phi = \frac{X_L - X_C}{R}$$
    標記引用：[[交流電路]]
*   **平均功率 (Average Power)**：僅由電阻消耗實功。
    $$P_{av} = I_{rms}^2 R = \varepsilon_{rms} I_{rms} \cos \phi$$
    標記引用：[[交流電路中的功率]]
*   **功率因子 (Power Factor)**：
    $$\cos \phi = \frac{R}{Z}$$
    標記引用：[[交流電路中的功率]]
*   **RLC 串聯電路之共振 (Resonance)**：當 $X_L = X_C$ 時，阻抗最小 ($Z=R$)，電流與功率達峰值。
    $$\omega_d = \omega_0 = \frac{1}{\sqrt{LC}}$$
    標記引用：[[電磁震盪]]、[[交流電路中的功率]]

## 7. 變壓器 (Transformers)

*   **電壓比公式**：與匝數成正比。
    $$\frac{V_p}{V_s} = \frac{N_p}{N_s}$$
    標記引用：[[變壓器]]
*   **電流比公式 (理想變壓器功率守恆)**：與匝數成反比。
    $$\frac{I_p}{I_s} = \frac{N_s}{N_p}$$
    標記引用：[[變壓器]]
*   **阻抗變換比公式 (阻抗匹配)**：
    $$Z_p = \left( \frac{N_p}{N_s} \right)^2 Z_s$$
    標記引用：[[變壓器]]

## 8. 馬克士威方程式組 (Maxwell's Equations)

*   **位移電流 (Displacement Current)**：時變電場產生磁場之等效電流。
    $$I_d = \epsilon_0 \frac{d\Phi_E}{dt}$$
    標記引用：[[馬克士威方程式]]
*   **馬克士威方程式組 (Maxwell's Equations)**：

    | 定律名稱 | 積分形式 | 微分形式 | 物理意義 |
    | :--- | :--- | :--- | :--- |
    | **電場高斯定律** | $\oint_S \mathbf{E} \cdot d\mathbf{A} = \frac{Q}{\epsilon_0}$ | $\nabla \cdot \mathbf{E} = \frac{\rho}{\epsilon_0}$ | 電荷為電場源/匯，電場線有頭有尾。 |
    | **磁場高斯定律** | $\oint_S \mathbf{B} \cdot d\mathbf{A} = 0$ | $\nabla \cdot \mathbf{B} = 0$ | 無磁單極子，磁力線必為封閉曲線。 |
    | **法拉第感應定律** | $\oint_L \mathbf{E} \cdot d\mathbf{l} = -\frac{d\Phi_B}{dt}$ | $\nabla \times \mathbf{E} = -\frac{\partial \mathbf{B}}{\partial t}$ | 時變磁場激發渦旋感應電場。 |
    | **安培-馬克士威定律** | $\oint_L \mathbf{B} \cdot d\mathbf{l} = \mu_0 (I + \epsilon_0 \frac{d\Phi_E}{dt})$ | $\nabla \times \mathbf{B} = \mu_0 \mathbf{J} + \mu_0 \epsilon_0 \frac{\partial \mathbf{E}}{\partial t}$ | 電流與時變電場均可激發磁場。 |

    標記引用：[[馬克士威方程式]]
*   **電荷守恆定律 (Continuity Equation)**：
    $$\nabla \cdot \mathbf{J} + \frac{\partial \rho}{\partial t} = 0$$
    標記引用：[[馬克士威方程式]]

## 9. 電磁波方程與能量傳遞 (EM Wave Equations & Energy Transport)

*   **真空中的電磁波波動方程式**：由馬克士威方程式在真空條件下 ($\rho=0, \mathbf{J}=0$) 導出。
    $$\nabla^2 \mathbf{E} - \mu_0 \epsilon_0 \frac{\partial^2 \mathbf{E}}{\partial t^2} = 0 \quad \text{及} \quad \nabla^2 \mathbf{B} - \mu_0 \epsilon_0 \frac{\partial^2 \mathbf{B}}{\partial t^2} = 0$$
    標記引用：[[電磁波方程式]]
*   **傳播速度 (光速)**：
    $$c = \frac{1}{\sqrt{\mu_0 \epsilon_0}} \approx 3 \times 10^8 \text{ m/s}$$
    標記引用：[[電磁波方程式]]
*   **平面電磁波之振幅關係**：電場與磁場同相，且大小成比例。
    $$\frac{E}{B} = c \quad \text{或} \quad E = cB$$
    標記引用：[[電磁波方程式]]、[[電磁波之能量傳遞]]
*   **絕緣介質中之波速**：
    $$v = \frac{1}{\sqrt{\mu\epsilon}} = \frac{c}{n} \quad (\text{其中折射率 } n = \sqrt{\kappa_e\kappa_m})$$
    標記引用：[[電磁波方程式]]
*   **電磁波總能量密度 ($u$)**：均勻分配於電場與磁場中。
    $$u = u_E + u_B = \varepsilon_0 E^2 = \frac{B^2}{\mu_0} = \sqrt{\frac{\varepsilon_0}{\mu_0}} EB$$
    標記引用：[[電磁波之能量傳遞]]
*   **坡印廷向量 (Poynting Vector)**：描述電磁波之能量流率與方向。
    $$\mathbf{S} = \frac{1}{\mu_0} \mathbf{E} \times \mathbf{B} \quad (S = \frac{EB}{\mu_0} \text{, 單位: } \text{W/m}^2)$$
    標記引用：[[電磁波之能量傳遞]]
*   **電磁波強度 ($I$, 坡印廷向量之時間平均值)**：
    $$I = S_{avg} = \frac{E_m B_m}{2\mu_0} = \frac{E_m^2}{2\mu_0 c} = \frac{1}{2} c \varepsilon_0 E_m^2 = c \varepsilon_0 E_{rms}^2$$
    標記引用：[[電磁波之能量傳遞]]
*   **輻射壓 (Radiation Pressure, $P_{rad}$)**：
    $$P_{rad} = \frac{I}{c} \quad (\text{完全吸收}) \quad \text{或} \quad P_{rad} = \frac{2I}{c} \quad (\text{完全反射})$$
    標記引用：[[電磁波之能量傳遞]]
