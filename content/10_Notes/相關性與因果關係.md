# 相關性與因果關係

| 相關性                    | 因果                 |
| ---------------------- | ------------------ |
| 密切連動，互相影響對方的變化:正相關、負相關 | **原因**和**結果**的明確關係 |
- 因果可為兩個以上因素所形成

>[!NOTE] 相關不蘊涵因果 correlation does not imply causation
>又稱為相關不代表因果，若兩個事物（統計學上會用變數代表）有明顯的相關時（即當一件事出現，另一件事也出現），不一定表示兩者之間有因果關係
>- 相關性包含因果關係

# 虛假關係
在兩個沒有因果關係的事件，可能基於其他未見的干擾因素（confounding factor，或稱潛在變數 lurking variable），顯示出統計學上的相關，讓人很容易猜想「兩個事件有所聯繫」，然而這種聯繫並不能通過更加精細的檢驗

>e.g. 所有喝過水的人都會死，所以喝水會致死
喝過水的人確實死了，但沒有反向證明不喝水不會死，所以兩者是一種偽關係

# 因果推論
- 絕大多數情況因為因素複雜，無法確認因素間的因果關係

## 隨機對照實驗
![[隨機對照實驗示意圖.png|800]]
- 假定排除其他可能引響結果的因素
- 受試者隨機分組，受試者自身不可知曉分組類別
- 暫時假定受試者具有同質性
