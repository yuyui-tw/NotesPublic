# 1. 導論 (Introduction & Background)

**密立根油滴實驗 (Millikan's Oil Drop Experiment)** 是由美國物理學家勞勃·密立根 (Robert Millikan) 與哈維·福萊契 (Harvey Fletcher) 於 1909 年進行的經典實驗。該實驗的主要貢獻在於：
1. **驗證電荷量子化 (Quantization of Charge)**：證實電荷並非連續流體，而是以離散單元的形式存在。
2. **測定基本電荷 (Elementary Charge)**：精確測得 $e \approx 1.602 \times 10^{-19} \text{ C}$，這對後續原子物理（如 [[波爾理論]]）的發展至關重要。

# 2. 核心 (Core Framework)

實驗核心在於觀測微小帶電油滴在重力場與均勻電場中的運動狀態，透過受力平衡來推算油滴所帶電量。

### 關鍵受力模型
- **重力 ($F_g$):** $F_g = mg = \frac{4}{3}\pi r^3 \rho_{oil} g$
- **浮力 ($F_b$):** $F_b = \frac{4}{3}\pi r^3 \rho_{air} g$
- **靜電力 ($F_e$):** $F_e = qE = q\frac{V}{d}$
- **黏滯阻力 ($F_d$):** 遵循 **[[有阻力之自由落體速度推導#1.1 阻力與速度成正比 ($F_d = kv$)|史托克斯定律 (Stokes' Law)]]**：$F_d = 6\pi\eta rv$

### 核心結論
所有觀測到的電荷 $q$ 均符合：
$$q = ne, \quad n \in \mathbb{Z}$$
這表明 $e$ 是自然界中電荷的最小獨立單位。

# 3. 邏輯 (Operational Logic)

推導過程分為兩個觀測階段，以消去未知數（如油滴半徑 $r$）。

![[密立根油滴實驗示意圖.png]]
### 階段一：無電場下的終端速度 (自由沉降)
當電場關閉時，油滴因重力下落，受浮力與空氣阻力達到終端速度 $v_1$：
$$F_g - F_b = F_{d1}$$
$$\frac{4}{3}\pi r^3 (\rho_{oil} - \rho_{air})g = 6\pi\eta rv_1$$
由此可求得油滴半徑 $r$：
$$r = \sqrt{\frac{9\eta v_1}{2(\rho_{oil} - \rho_{air})g}}$$

### 階段二：電場開啟後的終端速度 (受控上升)
施加向上電場 $E$，使油滴克服重力向上運動，達到穩定速度 $v_2$：
$$F_e + F_b = F_g + F_{d2}$$
$$qE = (F_g - F_b) + 6\pi\eta rv_2$$
將階段一的關係式 $(F_g - F_b) = 6\pi\eta rv_1$ 代入：
$$qE = 6\pi\eta rv_1 + 6\pi\eta rv_2 = 6\pi\eta r(v_1 + v_2)$$

### 最終計算
聯立上述方程，可求得單一油滴之帶電量 $q$：
$$q = \frac{6\pi\eta r (v_1 + v_2)}{E}$$
透過統計大量油滴的 $q$ 值並尋找其最大公因數，即可求得基本電荷 $e$。

# 4. 應用與脈絡 (Application & Context)

- **物理意義:** 確定了電子作為基本粒子的特性，並為量子化概念提供了強力的實驗證據。
- **誤差與修正:**
    - **空氣黏滯係數 ($\eta$):** 受溫度影響顯著，需精確校準。
    - **布朗運動:** 極小油滴會受空氣分子隨機撞擊影響軌跡。
    - **庫寧漢修正 (Cunningham correction):** 當油滴半徑與空氣平均自由徑相當時，Stokes' Law 需進行修正以符合微觀流體行為。
