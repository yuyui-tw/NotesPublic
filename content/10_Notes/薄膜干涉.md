# 薄膜干涉 (Thin Film Interference)

薄膜干涉是指光波在薄膜的上下兩個表面反射後，產生的疊加干涉現象。常見的例子包括肥皂泡的彩色花紋、路面油漬的色彩，以及光學鏡片的增透膜。

## 1. 反射波的相位變化 (Phase Shift)

當光在兩個介質的介面上反射時，相位是否發生變化取決於兩側的折射率：

- **硬邊界反射 (Hard Boundary)**：
  - 條件：光由折射率低 (疏) 進入折射率高 (密) 的介質反射（如空氣 $\to$ 玻璃）。
  - 結果：相位發生 **$\pi$ 的突變**，相當於增加了 **$\lambda/2$** 的光程。
- **軟邊界反射 (Soft Boundary)**：
  - 條件：光由折射率高 (密) 進入折射率低 (疏) 的介質反射（如玻璃 $\to$ 空氣）。
  - 結果：相位 **不發生變化**。

---

## 2. 干涉分析法

考慮光垂直（或近乎垂直）入射厚度為 $d$、折射率為 $n$ 的薄膜。光在上下表面反射產生的光程差為：
$$\delta = 2nd$$

最終的干涉效果取決於 **光程差** 與 **兩次反射產生的相位差總和**。

---

## 3. 常見案例分析

### 3.1 疏-密-疏 型 (如：空氣中的肥皂泡或油膜)
- **環境**：$n_{air} < n_{film} > n_{air}$
- **相位差分析**：
  - 上表面反射（疏 $\to$ 密）：有 $\pi$ 相位差。
  - 下表面反射（密 $\to$ 疏）：無相位差。
- **干涉條件**：
  - **建設性干涉 (亮)**：$2nd = (m + \frac{1}{2}) \lambda$
  - **破壞性干涉 (暗)**：$2nd = m \lambda$
  ($m = 0, 1, 2, \dots$)

### 3.2 疏-密-更密 型 (如：玻璃表面的增透膜)
- **環境**：$n_{air} < n_{coating} < n_{glass}$
- **相位差分析**：
  - 上表面反射（疏 $\to$ 密）：有 $\pi$ 相位差。
  - 下表面反射（密 $\to$ 更密）：亦有 $\pi$ 相位差。
- **干涉條件**：
  - **建設性干涉 (亮)**：$2nd = m \lambda$
  - **破壞性干涉 (暗)**：$2nd = (m + \frac{1}{2}) \lambda$
  ($m = 0, 1, 2, \dots$)

---

## 4. 增透膜與增反膜 (Applications)

### 4.1 增透膜 (Non-reflective Coating)
目的是利用 **破壞性干涉** 抵消反射光，從而增加透射光的比例。
- 常用條件：選擇厚度 $d$ 滿足 $2nd = \frac{1}{2} \lambda \implies d = \frac{\lambda}{4n}$。
- 註：此處假設 $n_{air} < n_{coating} < n_{glass}$。

### 4.2 肥皂泡的色彩
由於太陽光包含多種波長，對於特定的薄膜厚度 $d$，只有某些波長的顏色會發生建設性干涉。當厚度隨重力或蒸發改變時，觀察到的顏色也會隨之變化。
- **極薄薄膜 ($d \ll \lambda$)**：當薄膜接近零厚度時，光程差 $2nd \approx 0$，但因一次 $\pi$ 相位差的存在，薄膜頂端通常呈現 **黑色**（全破壞性干涉）。
