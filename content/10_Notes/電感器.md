# 1. 導論 (Introduction & Background)

**電感器 (Inductor)** 是一種能夠將電能以 **磁場 (Magnetic Field)** 形式儲存的被動電子元件。其基本構造通常為捲繞的線圈（螺線管）。當通過線圈的電流發生變化時，根據 [[電磁感應]] 原理，線圈自身會產生感應電動勢來反抗電流的變化。這種物理特性稱為 **電感 (Inductance)**。

在電路中，電感器的作用類似於力學中的「慣性」，它不允許電流發生突變。

# 2. 核心 (Core Framework)

### 2.1 自感與電感係數 (Self-Inductance)
當一個線圈中的電流 $I$ 變化時，穿過自身的磁通量 $\Phi_B$ 也隨之變化，進而產生感應電動勢。
- **定義式**：
  $$L = \frac{N\Phi_B}{I}$$
  其中 $N$ 為線圈匝數，$N\Phi_B$ 稱為 **磁通鏈 (Magnetic Flux Linkage)**。
- **單位**：亨利 (Henry, H)，$1 \text{ H} = 1 \text{ Wb/A} = 1 \text{ V}\cdot\text{s/A}$。
- **決定因素**：電感值 $L$ 僅與線圈的 **幾何形狀**（長度、截面積）、**匝數** 以及內部的 **磁介質** 有關。


> [!NOTE] 推廣
> 由[[感生電動勢#馬克士威-法拉第方程式 (Maxwell-Faraday Equation)|法拉第定律]] $\varepsilon_{L}= -N \frac{d\Phi_{B}}{dt}$
> 又$\varepsilon_{L}=-L \frac{dI}{dt}$，可得長度l、面積A之N匝螺線管$L= \frac{N\Phi_{B}}{I}= \frac{{N\cdot B\cdot A}}{I}= \frac{{\mu_{0}N^{2}A}}{l}$


### 2.2 自感電動勢 (Self-Induced EMF)
根據法拉第感應定律，電感器兩端的感應電動勢 $\varepsilon_L$ 為：
$$\varepsilon_L = -L \frac{dI}{dt}$$
- **負號的物理意義**：遵循 **冷次定律**，感應電動勢的方向恆為「反抗」原電流的變化（並非反抗電流本身，而是反抗其變化率）。

### 2.3 能量儲存 (Energy Storage)
電感器儲存的能量 $U_L$ 儲存於內部的磁場中：
$$U_L = \frac{1}{2} L I^2$$

> [!NOTE] 螺線管(電感器)之磁場能量密度
> - $L = \mu_0 n^2 A l$，單位長度匝數$n=\frac{N}{l}$
> - $B = \mu_0 n I \implies I = \frac{B}{\mu_0 n}$
> - $U = \frac{1}{2} (\mu_0 n^2 A l) \left( \frac{B^2}{\mu_0^2 n^2} \right) = \frac{B^2}{2\mu_0} (A l)$
> - $$u_B = \frac{U}{V=Al} = \frac{B^2}{2\mu_0}$$

# 3. 邏輯 (Operational Logic)

### 3.1 互感現象 (Mutual Inductance)
當兩個線圈靠近時，==其中一個線圈的電流變化會在另一個線圈中產生感應電動勢==：
$$\varepsilon_2 = -M \frac{dI_1}{dt}, \quad \varepsilon_1 = -M \frac{dI_2}{dt}$$
其中 $M$ 為 **互感係數 (Mutual Inductance)**。在理想情況下，$M_{12} = M_{21} = M$。

### 3.2 電感器在電路中的動態行為
在直流電路切換瞬間，電感器的表現如下：
1. **接通瞬間 ($dt \to 0$)**：為了反抗電流從 0 變為有，電感器會產生巨大的反向電動勢，此時 **電感器可視為斷路 (Open Circuit)**。
2. **穩定狀態 ($dI/dt = 0$)**：電流不再變化，感應電動勢為零，此時 **理想電感器可視為短路 (Short Circuit/理想導線)**。
3. **切斷瞬間**：電感器會試圖維持原電流方向，可能在開關處產生電弧（火花）。

### 3.3 與電容器的類比
| 特性 | 電容器 (Capacitor) | 電感器 (Inductor) |
| :--- | :--- | :--- |
| **儲能形式** | 電場 ($U = \frac{1}{2}CV^2$) | 磁場 ($U = \frac{1}{2}LI^2$) |
| **反抗對象** | 反抗電壓變化 ($I = C \frac{dV}{dt}$) | 反抗電流變化 ($\varepsilon = -L \frac{dI}{dt}$) |
| **穩定狀態** | 視為斷路 | 視為短路 |

# 4. 應用與脈絡 (Application & Context)

- **電力轉換**：變壓器 (Transformer) 的核心原理即為 **互感**。
- **濾波與調諧**：
    - **RL 電路**：與電阻組合，用於過濾高頻訊號（電感對高頻電流阻抗較大）。
    - **LC 振盪電路**：與電容組合，用於無線電頻率的發射與接收（調諧電路）。
- **安全設備**：斷路器、感應加熱。
- **相關連結**：
    - [[安培定律]]：用於計算不同幾何形狀（如長直螺線管）的 $B$ 場，進而求出 $L$。
    - [[磁場]]：電感能量儲存的空間本體。
    - [[電磁感應]]：電感現象的底層物理定律。
