# 1. 導論 (Introduction & Background)

**變壓器 (Transformer)** 是一種利用電磁感應（特別是**互感**現象）來改變交流電 (AC) 電壓大小的靜止電氣設備。

### 主要功能
- **升壓 (Step-up)**：使輸出電壓高於輸入電壓，用於遠距離輸電以降低電阻損耗（因電流變小）。
- **降壓 (Step-down)**：使輸出電壓低於輸入電壓，符合終端用電設備的安全與效率需求。

# 2. 核心原理 (Core Principles)

變壓器由繞在同一個鐵心上的兩個（或多個）線圈組成：**初級線圈 (Primary Coil, $N_p$)** 與 **次級線圈 (Secondary Coil, $N_s$)**。

### 互感與法拉第定律
當初級線圈通入交流電時，會在鐵心中產生隨時間變化的磁通量 $\Phi_B$。根據[[電磁感應#法拉第感應定律 (Faraday's Law of Induction)]]，這個磁通量會在兩組線圈中分別產生[[感生電動勢]]：
- 每匝線圈的電動勢相同：$\varepsilon_{turn} = \frac{d\Phi_B}{dt}$
- 初級電壓：$V_p = N_p \frac{d\Phi_B}{dt}$
- 次級電壓：$V_s = N_s \frac{d\Phi_B}{dt}$

由上述可得 **電壓比公式**：
$$\frac{V_p}{V_s} = \frac{N_p}{N_s}$$

# 3. 理想變壓器 (Ideal Transformer)

理想變壓器基於以下假設：
1. **無漏磁 (No Flux Leakage)**：所有磁力線均通過鐵心同時穿過兩個線圈。
2. **無電阻損耗 (No Resistive Loss)**：線圈電阻為零。
3. **無磁滯與渦流損耗 (No Core Losses)**：鐵心損耗為零。

### 功率守恆與電流比
在理想情況下，輸入功率等於輸出功率 ($P_{in} = P_{out}$)：
$$V_p I_p = V_s I_s$$
結合電壓比公式，可導出 **電流比公式**：
$$\frac{I_p}{I_s} = \frac{V_s}{V_p} = \frac{N_s}{N_p}$$
*注意：電壓與匝數成正比，而電流與匝數成反比。*

# 4. 阻抗變換 (Impedance Transformation)

變壓器可以改變負載的表現阻抗，這在電路設計中稱為**阻抗匹配**。

若次級接有一負載 $Z_s = \frac{V_s}{I_s}$，則從初級端看進去的等效阻抗 $Z_p$ 為：
$$Z_p = \frac{V_p}{I_p}$$
代入電壓比與電流比：
$$Z_p = \frac{(N_p/N_s) V_s}{(N_s/N_p) I_s} = \left( \frac{N_p}{N_s} \right)^2 \frac{V_s}{I_s}$$
因此，**阻抗比公式** 為：
$$Z_p = \left( \frac{N_p}{N_s} \right)^2 Z_s$$

# 5. 應用與脈絡 (Application & Context)

- **電力傳輸系統**：
    - 電廠升壓（高壓輸電） $\to$ 變電所降壓 $\to$ 家用變壓器（220V/110V）。
- **阻抗匹配 (Impedance Matching)**：
    - 在音響擴大機與喇叭之間，利用變壓器使負載阻抗與輸出阻抗匹配，以達到最大功率傳輸。
- **隔絕與安全**：
    - **隔離變壓器**：匝數比為 1:1，用於隔離電路，提高安全性。
