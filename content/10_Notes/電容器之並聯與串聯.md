# 電容器之並聯與串聯 (Capacitors in Series and Parallel)

在電路設計中，常需要透過組合多個電容器來達到特定的 **[[電容]]** 值。電容器的組合規律與電阻恰好相反，其物理本質在於改變了電荷累積的有效面積或極板間的有效距離。

---

## 1. 並聯組合 (Parallel Connection)

當電容器的兩端分別連接在相同的兩個節點上時，稱為並聯。

### 物理特性
- **等電壓**：每個電容器兩端的電位差（電壓）相等。
  $$V = V_1 = V_2 = V_3 = \dots$$
- **電荷疊加**：總電荷等於各分路電容器所帶電荷之和。
  $$Q_{tot} = Q_1 + Q_2 + Q_3 + \dots$$

### 等效電容推導
利用電容定義 $Q = CV$：
$$C_p V = C_1 V + C_2 V + C_3 V + \dots$$
約去共有的 $V$，得並聯等效電容 $C_p$：
$$C_p = \sum_{i} C_i = C_1 + C_2 + C_3 + \dots$$

### 結論與直觀理解
1. **等效值**：並聯情況下，等效電容值 **恆大於** 任一個別電容值。
2. **幾何意象**：並聯相當於增加了極板的 **總面積 ($A$)**。由平行板電容公式 $C = \varepsilon_0 \frac{A}{d}$ 可知，面積增大，電容隨之增加。

---

## 2. 串聯組合 (Series Connection)

當電容器首尾相接形成單一路徑時，稱為串聯。

### 物理特性
- **等電荷**：由於靜電感應，串聯電路中每個電容器所帶的電荷量相等。
  $$Q = Q_1 = Q_2 = Q_3 = \dots$$
- **電壓分配**：總電壓等於各電容器兩端電位差之和。
  $$V_{tot} = V_1 + V_2 + V_3 + \dots$$

### 等效電容推導
利用 $V = Q/C$ 代入電壓公式：
$$\frac{Q}{C_s} = \frac{Q}{C_1} + \frac{Q}{C_2} + \frac{Q}{C_3} + \dots$$
約去共有的 $Q$，得串聯等效電容 $C_s$：
$$\frac{1}{C_s} = \sum_{i} \frac{1}{C_i} = \frac{1}{C_1} + \frac{1}{C_2} + \frac{1}{C_3} + \dots$$

### 結論與直觀理解
1. **等效值**：串聯情況下，等效電容值 **恆小於** 任一個別電容值。
2. **幾何意象**：串聯相當於增加了極板間的 **總距離 ($d$)**。由公式 $C = \varepsilon_0 \frac{A}{d}$ 可知，距離增大，電容隨之減少。

---

## 3. 綜合比較與注意事項

### 對比電阻組合
| 配置 | 電容器 ($C$) | 電阻 ($R$) |
| :--- | :--- | :--- |
| **並聯** | $C_p = C_1 + C_2$ (相加) | $1/R_p = 1/R_1 + 1/R_2$ (倒數相加) |
| **串聯** | $1/C_s = 1/C_1 + 1/C_2$ (倒數相加) | $R_s = R_1 + R_2$ (相加) |

### 儲能考量
- 組合電容的總儲存能量 $\mathbf{U}$ 亦可透過等效電容計算：
  $$U_{tot} = \frac{1}{2} C_{eq} V_{tot}^2 = \frac{Q_{tot}^2}{2 C_{eq}}$$
- 詳細儲能原理可參考：**[[電容]]** 中的「儲能特性」章節。
